# exercises · 練習題

讀懂跟寫得出來是兩回事。這裡的題目**專挑那些 ⚠ 陷阱**——因為你不會在
「怎麼寫 `map`」上出錯，你會在「`(:port cfg)` 為什麼是 nil」上卡半天。

## 怎麼用

每一份都是**可以直接跑的檔案**，裡面是一串待補的函式：

```sh
janet exercises/01-資料與比較.janet
```

跑起來會告訴你**第幾題錯了、預期什麼、你給了什麼**。全部答對才會印
`✓ 全部通過`。改一題跑一次，不用一次寫完。

```
✘ 第 3 題：拿掉重複的元素
    預期 @[3 1 2]
    實得 nil
    提示 見 docs/25；順序要照第一次出現
```

卡住了看**提示**（每題都有，指向對應的教學篇）。真的想不出來再看
`solutions/` 底下同名的檔案——但**先自己跑過一次錯的**，看到自己錯在哪比直接看答案有用。

## 為什麼題目長這樣

每題都是**你真的會寫到的東西**（去重、分組、對齊表格、解析一行設定），
而不是「費氏數列」那種練不到語言特性的題目。每題背後至少埋一個 ⚠——
寫錯了會拿到一個**不報錯但答案不對**的結果，那正是 Janet 最會咬人的地方。

答案在 [`solutions/`](solutions/)。它們也都跑得起來，可以直接
`janet exercises/solutions/01-資料與比較.janet` 對照。
