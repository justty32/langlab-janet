# 2-1 · 把東西存起來

上一課（[1-3 · 值有哪幾種](1-3-值有哪幾種.md)）看過 Janet 有哪些值。這課講怎麼把算出來的值留下來給後面用，還有這個名字在哪些地方看得到。學完你就能寫出「先算、再存、後面拿來用」的程式。

## 這是什麼、為什麼

程式跑到一半算出一個東西，通常不會馬上用完就丟，而是想留著，後面幾行再拿出來。留的方法是給它一個名字，這件事叫綁定（把一個名字綁到一個值上）。在 C 或 Python 你會說「宣告變數」，意思差不多。

Janet 把綁定分成兩種。`def` 綁了以後就不能改，`var` 綁了以後可以用 `set` 換成別的值。

為什麼要分兩種？因為程式裡大部分的東西算出來以後就不會再變。用 `def` 寫這種東西，你自己和讀你程式的人一眼就知道「這個名字後面不會被偷改」，找 bug 的時候可以直接跳過它。而且 Janet 會幫你把關，你哪天不小心對它 `set`，程式還沒開始跑就被擋下來。真的需要累加、要當計數器的，才用 `var`。慣例是先寫 `def`，發現非改不可再換成 `var`。

## 動手：def

`def` 後面接名字、再接值。之後寫這個名字，就等於寫那個值。

```janet
(def price 100)
(def total (* price 3))
total   # => 300
```

`(* price 3)` 是「price 乘 3」，前一課講過的前綴寫法。`total` 綁到的是算完的 300，不是那條算式。

## 動手：var 與 set

需要改的東西用 `var` 綁，改的時候用 `set`。下面做一個計數器，加兩次。

```janet
(var count 0)
(set count (+ count 1))
(set count (+ count 1))
count   # => 2
```

`(set count (+ count 1))` 讀成「把 count 換成 count 加 1」。`set` 本身也會回傳新值，所以 REPL 裡打完會看到 1、2。

`var` 一定要給初始值，只寫名字會錯。

```janet
(protect (eval '(var y)))   # => (false "expected at least 2 arguments to var")
```

`protect` 是「把會爆的程式包起來，回傳 (成功嗎 結果)」，第 7 單元細講。這裡外面多包一層 `eval`（把一串被引號擋住、還沒執行的程式碼拿去真的執行），因為這種錯誤在 Janet 讀你程式的階段就會冒出來，不包起來整段就跑不了。

## 動手：對 def 的東西 set 會怎樣

會直接被擋下來，錯誤訊息是 `cannot set constant`。

```janet
(protect (eval '(do (def x 1) (set x 2))))   # => (false "cannot set constant")
```

注意這是 Janet 在看你程式的時候就擋，不是跑到那行才爆。所以就算那行 `set` 放在永遠不會執行的分支裡，整支檔案還是不給過。這是好事，錯的越早越好找。

## 動手：let，暫時的名字

有時候一個名字只在幾行裡用到，用完就不想再看到它。這時用 `let`。中括號裡「名字 值 名字 值」成對寫，後面接要做的事，整個 `let` 的結果是最後一件事的值。

```janet
(let [a 1 b 2]
  (+ a b))   # => 3
```

出了 `let`，`a` 就不存在了。

```janet
(protect (eval '(do (let [a 1] a) a)))   # => (false "unknown symbol a")
```

`let` 裡如果用了跟外面一樣的名字，外面那個會被暫時蓋住，出來後又回來，外面的值沒被動到。這叫 shadowing（遮蔽）。

```janet
(var n 0)
(set n (+ n 1))
n                 # => 1
(let [n 100] n)   # => 100
n                 # => 1
```

## 動手：作用域

作用域（一個名字在哪些地方看得到）在 Janet 很單純。寫在檔案最外層的 `def`，整支檔案都看得到。寫在函式裡的 `def`，只有函式裡看得到。

下面用 `defn` 定義一個函式（`defn` 就是定義函式，第 6 單元細講），裡面 `def` 一個 `inner`。

```janet
(defn f []
  (def inner 5)
  inner)
(f)   # => 5
(protect (eval 'inner))   # => (false "unknown symbol inner")
```

函式外面用 `inner`，Janet 說它不認識這個符號。跟前面一樣，這也是看程式的階段就會擋的錯。

## 動手：同名再 def 一次

同一層再 `def` 一次同樣的名字是允許的，後面的蓋掉前面的。

```janet
(def x 1)
(def x 2)
x   # => 2
```

這在 REPL 裡試東西很方便，寫錯了重打一次就好。但檔案裡別這樣寫，讀的人會搞不清楚現在 `x` 是哪一個。

還有一招：`def` 也能一次拆開一串值：`(def [a b] [1 2])` 之後 `a` 是 1、`b` 是 2。這叫解構，6-3 細講。

## 你會踩的坑

⚠ `set` 一個用 `def` 綁的名字。你會以為只是換個值，跟 Python 的 `x = 2` 一樣。其實是整支檔案直接不給跑，錯誤是 `cannot set constant`。因為 `def` 的意思就是「這名字不會變」，Janet 在讀程式的階段就檢查，真要改就把它改成 `var`。

⚠ 在 `let` 裡改了外面的名字。你會以為 `(let [n 100] ...)` 會把外面的 `n` 變成 100。其實是外面的 `n` 完全沒動，`let` 只是暫時蓋住它。因為 `let` 做的是新綁定，不是 `set`；真要改外面的，就在 `let` 裡面對外面的 `var` 用 `set`。

⚠ 函式裡 `def` 的名字在外面用。你會以為跟 JS 的 `var` 一樣會漏到外面。其實是外面看不到，錯誤是 `unknown symbol`。因為 Janet 的綁定只活在它被寫的那層括號裡，出來就沒了。

## 小練習

1. 用 `def` 綁 `width` 是 4、`height` 是 5，再 `def` 一個 `area` 是兩者相乘，讓 `area` 回傳 20。
2. 用 `var` 做一個 `total` 從 0 開始，用 `set` 連加 10、20、30，最後 `total` 是 60。
3. 頂層先 `(var n 1)`，寫一個 `let` 把 `n` 暫時綁成 99 並回傳它，然後確認外面的 `n` 還是 1。
