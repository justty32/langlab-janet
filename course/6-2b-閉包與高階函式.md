# 6-2b · 閉包與高階函式（續）

接著 [6-2](6-2-閉包與高階函式.md)。前半講了「函式是值」，這半講函式怎麼記住東西：閉包，以及會吐出函式的函式。

## 這是什麼、為什麼

閉包就是一個記得自己出生時周圍變數的函式。函式在另一個函式裡被做出來時，它看得到當時周圍的變數。就算外面那個函式早就跑完了，它還是看得到。

這很好用：你可以做出帶著自己小狀態的函式，不必開一個全域變數給大家共用。

## 動手

### 計數器

```janet
(defn 做計數器 []
  (var n 0)
  (fn [] (++ n)))

(def c1 (做計數器))
(def c2 (做計數器))
(c1)
(c1)
(c1)   # => 3
(c2)   # => 1
```

每叫一次 `做計數器`，就開出一個新的 `n`，再做出一個會把它加一的函式交回來。`c1` 叫了三次得到 3，`c2` 第一次叫得到 1。兩個各有自己的 `n`，互不干擾。

`做計數器` 回傳之後，那個 `n` 沒有消失，因為閉包還抓著它。

### 記住的是變數本身，不是當時的值

```janet
(var x 1)
(def f (fn [] x))
(set x 2)
(f)   # => 2
```

`f` 做出來的時候 `x` 是 1，可是之後把 `x` 改成 2，再叫 `f` 拿到的是 2。

打個比方：閉包身上的便利貼寫的是「第三個抽屜」，不是「抽屜裡的東西是 1」。每次要用時它才去開抽屜看。

比喻不準的地方是：沒有真的抽屜編號。真實的機制是閉包持有那個綁定（名字跟它那一格存放位置的連結）。變數被 `set` 改了，閉包看到的就是新值。

學過 C++ 的話，這很像 lambda 的 `[&]` 抓參考。差別是 C++ 回傳一個抓了區域變數參考的 lambda 會變懸空參考；Janet 有 GC（自動回收記憶體），閉包還抓著那格，它就不會被回收，所以沒有這個問題。

### 吐函式的函式

計數器已經是一個例子。再來一個更直白的：

```janet
(defn 做加法器 [n]
  (fn [x] (+ x n)))

(def 加十 (做加法器 10))
(def 加一 (做加法器 1))
(加十 5)   # => 15
(加一 5)   # => 6
```

`做加法器` 吃一個數字，吐出一個「加上那個數字」的函式。`加十` 記住的 `n` 是 10，`加一` 記住的是 1。這也是高階函式，只是方向相反：它吐函式出來。

## 你會踩的坑

⚠ 在迴圈裡建閉包，要看迴圈變數是不是每圈新的。

```janet
(def gs @[])
(var j 0)
(while (< j 3)
  (array/push gs (fn [] j))
  (++ j))
(map |($) gs)   # => @[3 3 3]
```

`|($)` 是「把拿到的東西當函式叫一次」，所以最後一行把三個閉包各叫一次。

你會以為三個閉包分別記住 0、1、2。其實三個都回 3。因為它們抓的是同一個 `j`，記住的是變數本身。迴圈跑完 `j` 已經是 3，三個一起去看，當然都是 3。

改用 `seq`、`loop` 或 `each` 就沒事，它們每一圈都開一個新的綁定：

```janet
(def fs (seq [i :range [0 3]] (fn [] i)))
(map |($) fs)   # => @[0 1 2]
```

非用 `while` 不可時，在圈內用 `let` 抄一份出來，讓每個閉包抓自己那一份：

```janet
(def gs @[])
(var j 0)
(while (< j 3)
  (let [k j] (array/push gs (fn [] k)))
  (++ j))
(map |($) gs)   # => @[0 1 2]
```

## 小練習

1. 給 `[1 2 3 4 5 6]`，用 `filter` 挑出偶數（`even?` 可以直接用），再用 `map` 把每個平方。應該得到 `@[4 16 36]`。
2. 寫 `做編號機`：叫它一次得到一個函式，那個函式每叫一次就給下一個編號，從 1 開始。兩台編號機要各自數。
3. 用 `reduce` 找出 `[3 9 2 7]` 裡最大的數（提示：函式可以用 `max`，初始值用序列第一個）。
