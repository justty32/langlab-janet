# 10-4 · 巨集：在程式跑之前先改寫程式碼

你一路用的 `when`、`for`、`->`、`try` 都不是內建語法，是巨集（macro，一種在程式跑之前收到你寫的程式碼、改寫成另一段程式碼交回去的函式）。這課教它怎麼運作、怎麼寫一個、怎麼看它改寫成什麼，最後講什麼時候不該寫。

## 這是什麼、為什麼

先回想 1-2 課：Janet 的程式碼就是 tuple。`(+ 1 2)` 是一個三格的 tuple，第一格是 symbol `+`。既然程式碼是資料，就可以用程式去產生它、改它，然後叫 Janet 執行。

為什麼需要這件事？因為函式有個做不到的地方：參數一定先算完才進函式。你想寫一個自己的 `when`，用函式寫是

```janet
(defn my-when-fn [c body] (if c body nil))
(my-when-fn false (print "函式版：還是印了"))   # => nil
# 印出：函式版：還是印了
```

條件是 `false`，但 `print` 照樣跑了，因為它在進函式之前就被算掉了。函式拿到的是「印完之後的回傳值 nil」，不是「印這個動作」。

巨集不一樣：它在編譯期（程式碼還在被讀進來、還沒開始跑的時候）被呼叫，收到的是原封不動的程式碼 tuple，回傳一段新的程式碼，Janet 再拿新的去跑。所以它可以決定某段程式碼要不要跑、跑幾次、包在什麼裡面。

## 動手：程式碼就是資料

```janet
(type '(+ 1 2))   # => :tuple
(type (first '(+ 1 2)))   # => :symbol
(eval '(+ 1 2))   # => 3
(eval (tuple '* 6 7))   # => 42
```

`'` 是引用（quote，「這段不要執行，當資料給我」）。引起來的 `(+ 1 2)` 就是個普通 tuple，可以 `first`、可以用 `tuple` 自己拼一個，`eval` 再叫它跑。巨集做的事就是回傳這種 tuple。

## 動手：quasiquote 拼程式碼

用 `tuple` 一格一格拼很累。`~` 是準引用（quasiquote，「整段當資料，但逗號的地方要算」）：

```janet
(def x 5)
'(a b ,x)   # => (a b (unquote x))
~(a b ,x)   # => (a b 5)
~(f ,;[1 2 3])   # => (f 1 2 3)
~(f [1 2 3])   # => (f [1 2 3])
```

`'` 裡的逗號只是個符號。`~` 裡的 `,x` 會把 `x` 的值填進去。`,;` 是填進去並攤平：一個 array 變成三個獨立的格子。這三個符號就是寫巨集的全部工具。

## 動手：寫一個 my-when

```janet
(defmacro my-when [c & body]
  ~(if ,c (do ,;body)))
(my-when false (print "巨集版：不會印"))   # => nil
(my-when true 1 2 3)   # => 3
(macex1 '(my-when (> 3 1) (print "a") (print "b")))   # => (if (> 3 1) (do (print "a") (print "b")))
```

`defmacro` 長得跟 `defn` 一樣，差別是它收到的 `c` 是 tuple `false`（還沒算）、`body` 是剩下那些程式碼。它回傳 `~(if ,c (do ,;body))`：條件填進 `if`，body 攤平進 `do`。`macex1` 是看展開結果的工具（macro-expand 一層），寫巨集卡住時第一件事就是用它看到底生出什麼。內建的 `when` 展開出來一模一樣，你可以 `(macex1 '(when x (foo)))` 對照。

## 動手：臨時變數要用 with-syms

巨集裡自己 `let` 一個變數，會跟使用者的變數撞名：

```janet
(defmacro bad-swap [a b] ~(let [tmp ,a] (set ,a ,b) (set ,b tmp)))
(var p 1) (var q 2)
(bad-swap p q)
[p q]   # => (2 1)
(var tmp 10) (var other 20)
(macex1 '(bad-swap tmp other))   # => (let [tmp tmp] (set tmp other) (set other tmp))
(protect (eval (macex1 '(bad-swap tmp other))))   # => (false "cannot set constant")
```

換 `p`、`q` 沒事；使用者的變數剛好也叫 `tmp` 就展開成 `(let [tmp tmp] ...)`，`let` 裡的 `tmp` 是常數，`set` 就炸，錯誤訊息完全不會提到撞名。`with-syms` 生一個保證不撞的名字：

```janet
(defmacro good-swap [a b]
  (with-syms [t] ~(let [,t ,a] (set ,a ,b) (set ,b ,t))))
(var tmp 10) (var other 20)
(pp (macex1 '(good-swap tmp other)))
# 印出：(let [_00000Z tmp] (set tmp other) (set other _00000Z))
(good-swap tmp other)
[tmp other]   # => (20 10)
```

`t` 變成 `_00000Z` 這種沒人會寫的名字（尾巴每次不同）。巨集裡只要有自己的變數，就用 `with-syms`。

## 什麼時候不該寫巨集

能用函式做到的，就用函式。巨集只在「參數不能先算」（`when`、`and`、`with` 這種要控制跑不跑的）或「要造新語法」時才出手。理由有三個：函式可以當值傳給 `map`，巨集傳過去只會拿到一堆程式碼 tuple（`(map my-when [true false])` 回的是 `@[(if true (do)) (if false (do))]`）；函式的錯誤訊息指到你的程式碼，巨集的錯誤指到展開後的東西；函式一眼看得懂，巨集要 `macex1` 才知道發生什麼。寫之前先問自己：這件事真的要延後求值嗎？

## 你會踩的坑

⚠ 你會以為巨集的參數跟函式一樣是算好的值。其實是原始程式碼。因為 `(defmacro add-macro [a b] (+ a b))` 遇到 `(add-macro 1 2)` 拿到兩個數字沒事，遇到 `(add-macro (+ 1 1) 2)` 拿到的 `a` 是 tuple `(+ 1 1)`，`+` 就炸 `could not find method :+ for <tuple ...>`。巨集要回傳程式碼 `~(+ ,a ,b)`，讓算這件事留到執行期。

⚠ 你會以為 `;` 是註解（Lisp 家族都是）。其實是 `;` 在 Janet 是攤平運算子，`(print "a") ; (print "b")` 會炸 `splice can only be used in function parameters and data constructors`。因為 Janet 的註解是 `#`。錯誤訊息不會提到「你以為這是註解」。
