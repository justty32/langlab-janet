# 6-4 · match

程式常常收到「不知道是哪一種」的資料：可能是 `[:add 1 2]`，可能是 `[:neg 5]`，也可能是一個字典。這課教 `match`，它一次做兩件事：先看資料長什麼樣子，對上了再把裡面的東西拆出來取名字。學完你能用幾行寫出「看到哪種指令就做哪件事」的程式。

## 這是什麼、為什麼

C 沒有這個東西，Python 要到 3.10 才有 `match` 語句。所以先從你已經會的講起。

5-1 教過 `case`：拿一個值，跟幾個常值一個一個比「等不等於」。`match` 是它的進化版，比的不是「等不等於」，而是「長得像不像」。像的話，順便把裡面的東西拆出來取名字。這種寫法叫模式比對（match；拿一個值去比「形狀」）。

6-3 教過解構，兩者很像，差在把握有多少：

- 解構是「我確定它就是這個形狀，直接拆」。形狀不對也照拆，拆不到的變 nil。
- `match` 是「我不確定它是哪一種形狀，一種一種試，對上了才拆」。

寫法是一個值，後面接一串「模式 結果」成對排好。`match` 從上往下試，第一個對上的模式，就回傳它後面那個結果；後面的不再看。

## 動手

### 最小的例子：常值與 `_`

```janet
(match 0 0 "zero" _ "other")   # => "zero"
(match 5 0 "zero" _ "other")   # => "other"
```

第一行拿 0 去比，第一個模式就是 `0`，相等，回 `"zero"`。第二行拿 5 去比，`0` 對不上，往下試 `_`。`_` 是「什麼都吃」，所以回 `"other"`。

到這裡它跟 `case` 幾乎一樣。`_` 的角色就是 `case` 最後那個預設值，習慣上放在最後一個。

### tuple 模式：比形狀，順便取名字

真正的威力從這裡開始。模式可以寫成一個 tuple（一串放進去就不能改的值）：

```janet
(match [:add 1 2] [:add a b] (+ a b) [:neg x] (- x))   # => 3
(match [:neg 5]   [:add a b] (+ a b) [:neg x] (- x))   # => -5
```

第一行，值是 `[:add 1 2]`。第一個模式 `[:add a b]` 的意思是：「第 0 格要等於 `:add`，第 1 格叫它 `a`，第 2 格叫它 `b`」。對得上，於是 `a` 是 1、`b` 是 2，結果算出 3。

第二行，值是 `[:neg 5]`。第 0 格是 `:neg`，不等於 `:add`，第一個模式落空。第二個模式 `[:neg x]` 對上，`x` 是 5，回 -5。

規則只有一條，記住就好：模式裡的 keyword（冒號開頭、代表自己的名字，像 `:add`）、數字、字串是常值，要跟值相等才算中；裸的名字（像 `a`、`x`）是綁定，那一格放什麼都行，放的東西就取這個名字。名字只在那一個結果裡能用，出了這個分支就不見了。

### 字典模式：只比你列出來的鍵

模式也能寫成字典：

```janet
(match {:kind :dog :age 3} {:kind k} k)   # => :dog
```

模式 `{:kind k}` 的意思是：「值裡要有 `:kind` 這個鍵，它的值叫 `k`」。值另外還有 `:age 3`，模式沒提到，就不管它。

這叫子集比對：只檢查模式列出來的鍵，多的鍵不影響。反過來，模式列了但值裡沒有的鍵，就對不上：

```janet
(match {:kind :dog} {:kind k :age a} a _ :no)   # => :no
```

這裡模式要 `:age`，值裡沒有，所以落到 `_`。

鍵對應的值也可以寫常值，這樣就是「這個鍵必須等於這個值」：

```janet
(match {:kind :dog} {:kind :cat} :cat {:kind k} k)   # => :dog
```

第一個模式要求 `:kind` 等於 `:cat`，對不上；第二個模式只要有 `:kind` 就行，對上了。

### 守衛：形狀對了，再多檢查一個條件

有時候光看形狀不夠，你還想說「而且它要是字串」。這時用守衛（match 裡多加一個條件），寫成 `(名字 條件)`：

```janet
(match "hi" (s (string? s)) (string "str " s) _ :other)   # => "str hi"
(match 42   (s (string? s)) (string "str " s) _ :other)   # => :other
```

`(s (string? s))` 分兩步：先把整個值綁成 `s`，再算 `(string? s)`。條件是真才算中。第一行 `"hi"` 是字串，中了；第二行 42 不是，條件是假，於是往下試 `_`。

因為是先綁再檢查，條件裡可以直接用剛取的名字。條件寫什麼都可以，只要它回真或假。
