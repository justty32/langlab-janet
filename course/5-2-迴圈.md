# 5-2 · 迴圈

同一件事要做很多遍，就要迴圈。Janet 給你好幾種：走過一個容器、數數字、條件成立就一直做，還有一個能一口氣疊好幾層的 `loop`。學完這課，你能挑對的那一種，也知道想「收集結果」時該用 `seq`。

## 這是什麼、為什麼

你熟的 C 迴圈長 `for (i = 0; i < 3; i++)`，Python 是 `for x in xs`。Janet 把這些拆成幾個各管一件事的形式：

- `each`：把容器裡的值一個一個拿出來。對應 Python 的 `for x in xs`。
- `for`：從某個數數到某個數。對應 Python 的 `for i in range(0, 3)`。
- `while`：條件為真就一直跑。跟 C 的 `while` 一樣。
- `loop`：一個小 DSL（專門為一件事設計的迷你語言），在一個方括號裡寫「走什麼、怎麼過濾」。
- `seq`：寫法跟 `loop` 一樣，但會把每一圈的結果收成 array。對應 Python 的 list comprehension。

前四個都是拿來「做事」的，本身回 `nil`。只有 `seq` 會交回一個有用的值。

## 動手

### each：走過容器的每個值

```janet
(each x [10 20 30]
  (print x))
# 印出：10、20、30 各一行
```

`(each 名字 容器 身體)`：每一圈把一個值綁到 `x`，再跑身體。array、tuple、字串都能走。

### eachp：走 table 的鍵和值

```janet
(eachp [k v] {:apple 3 :pear 5}
  (print k " 有 " v " 個"))
# 印出：apple 有 3 個、pear 有 5 個（順序不保證）
```

`eachp` 的 p 是 pairs（成對）。每一圈拿到 `[鍵 值]`，用 `[k v]` 直接拆成兩個名字。struct 和 table 的鍵沒有固定順序，別依賴印出來的先後。

### for：數數字

```janet
(for i 0 3
  (print i))
# 印出：0、1、2
```

`(for i 起 迄 身體)` 從 0 數到 3，但不含 3。這叫半開區間：含頭不含尾，跟 Python 的 `range(0, 3)` 一樣。

### while：條件成立就繼續

```janet
(var i 0)
(while (< i 3)
  (print i)
  (++ i))
# 印出：0、1、2
i   # => 3
```

`while` 不管計數，所以要自己用 `var` 開一個能改的變數，每圈改它。`(++ i)` 是 `(set i (+ i 1))` 的簡寫。忘了改，條件永遠為真，就是無窮迴圈。

### loop：一個方括號寫完整件事

形狀固定是：

```
(loop [名字 :動詞 對象  ...  :條件詞 運算式] 身體)
```

`:range`、`:in` 這些 keyword 叫動詞，決定「走什麼」。最常用四個：

```janet
(loop [i :range [0 3]] (print i))          # 印出：0、1、2（半開）
(loop [x :in [:a :b]] (print x))           # 印出：a、b
(loop [[k v] :pairs {:a 1}] (print k v))   # 印出：a1
(loop [i :range [0 6] :when (even? i)]
  (print i))                               # 印出：0、2、4
(loop [x :in [1 2]] x)                     # => nil
```

`:range [起 迄]` 數數字、`:in 容器` 拿值、`:pairs 容器` 拿 `[鍵 值]`、`:when 條件` 只讓條件為真的那圈跑身體。`:when` 是過濾，不是中止：不合的跳過，後面照走。最後一行看到 `loop` 永遠回 `nil`。

寫兩組綁定，就是兩層巢狀迴圈，前面那組在外層：

```janet
(loop [x :range [0 2]  y :in [:a :b]]
  (print x y))
# 印出：0a、0b、1a、1b
```

### seq：同樣的寫法，收成 array

```janet
(seq [i :range [0 6] :when (even? i)] i)   # => @[0 2 4]
(seq [x :in [1 2 3]] (* x x))              # => @[1 4 9]
```

方括號裡的寫法跟 `loop` 一字不差，差別是每圈身體的值會被收進一個新 array 交給你。想收成 table（能改的字典）就用 `tabseq`，身體寫「鍵 值」兩個：

```janet
(def sq (tabseq [x :in [1 2 3]] x (* x x)))
(sq 3)   # => 9
(length sq)   # => 3
```

想收集結果時，別寫 `loop` 再在裡面 `array/push`，直接用 `seq`。想半路跳出迴圈用 `break`，下一課細講。

## 你會踩的坑

⚠ each 走字串拿到數字

你會以為 `(each c "ab" (print c))` 印出 `a`、`b`。其實印的是 `97`、`98`。因為 Janet 的字串是一串 byte（位元組，0 到 255 的數字），走過去拿到的就是每個 byte 的數值。要變回字元用 `(string/from-bytes c)`。

```janet
(seq [c :in "ab"] c)                       # => @[97 98]
(seq [c :in "ab"] (string/from-bytes c))   # => @["a" "b"]
```

⚠ :range 給負步長，靜默回空

你會以為 `:range [3 0 -1]` 從 3 倒數到 1。其實一圈都不跑，也不報錯。因為 `:range` 的第三格步長只收正數。要倒著走改用 `:down`：

```janet
(seq [i :range [3 0 -1]] i)   # => @[]
(seq [i :down [3 0]] i)       # => @[3 2 1]
```

⚠ :range 不含尾

你會以為 `:range [1 3]` 會走到 3。其實只到 2。因為它跟 `for` 一樣是半開區間。要含尾用 `:range-to`：

```janet
(seq [i :range [1 3]] i)      # => @[1 2]
(seq [i :range-to [1 3]] i)   # => @[1 2 3]
```
