# 1-3 · 值有哪幾種

前兩課你已經會跑程式、會讀括號。這課認識括號裡放的「東西」本身：數字、字串、keyword、symbol、nil、true／false。學完你看到任何一個值，都能說出它是哪一種，也知道 Janet 怎麼判斷真假。

## 這是什麼、為什麼

每個值都有一個型別（它是哪一種東西）。型別決定它能拿來做什麼：數字能相加，字串能印出來，標籤能拿來分類。

Janet 內建一個動作 `type`，丟一個值給它，它告訴你這個值是哪一種。這課每介紹一種值，都會用 `type` 看一次。

## 動手：數字

```janet
(type 42)     # => :number
(type 3.14)   # => :number
(/ 7 2)       # => 3.5
(= 3 3.0)     # => true
```

整數和小數在 Janet 是同一種型別，都叫 number。所以 `(/ 7 2)` 得到 `3.5`，不會像 C 那樣截斷成 `3`。`3` 和 `3.0` 也被當成同一個值。

`type` 回來的 `:number` 前面有個冒號，它本身也是一種值，下面馬上講。

## 動手：字串

```janet
(type "hello")   # => :string
(print "你好，Janet")
# 印出：你好，Janet
```

字串就是雙引號包起來的一段文字，中文也可以。它是給人看的資料。字串的招式很多，單元 4 再慢慢講。

## 動手：keyword

```janet
:abc          # => :abc
(type :abc)   # => :keyword
```

keyword（冒號開頭的標籤）長得像 `:abc`、`:red`、`:done`。求值（把式子算成一個值）時它就是它自己，不會變成別的東西。

它的用途是當標籤：表示狀態（`:done`）、選項名（`:verbose`）、之後的字典欄位名。剛剛 `type` 回的 `:number`、`:string` 也都是 keyword。可以把它想成貼在東西上的名牌。比喻不準的地方是：名牌可以撕下來改寫，keyword 做出來就不會變。

## 動手：symbol

```janet
'abc          # => abc
(type 'abc)   # => :symbol
```

symbol（一個名字）是你在程式碼裡寫、沒有冒號也沒有引號的那種字，例如 `print`、`+`。Janet 看到 symbol，會去查「這個名字綁到什麼」，再拿查到的東西來用。`+` 這個名字就綁著加法。

那 `abc` 呢？它沒綁到任何東西，直接打會出錯：

```text
repl:1:> abc
repl:1:1: compile error: unknown symbol abc
```

想看 symbol 本身、不要去查它，就在前面加一個單引號：`'abc`。單引號的意思是「這個名字原樣給我，別查」。初學階段你很少需要自己寫 `'abc`，知道 symbol 就是「名字」就夠了。怎麼幫名字綁東西是下一課的事。

## 動手：nil 與 true／false

```janet
(type nil)     # => :nil
(type true)    # => :boolean
(type false)   # => :boolean
```

nil（代表「沒有東西」的值）用來表示「這裡沒有值」，例如去找一個不存在的東西，常常拿回 nil。true／false 就是是與否，比大小的結果就是它們：`(< 1 2)` 得到 `true`。

## 動手：什麼算真、什麼算假

`if` 的用法是 `(if 條件 成立時 不成立時)`，單元 5 會細講，這裡先拿它來測真假。

```janet
(print (if 0 "真" "假"))
# 印出：真
(print (if "" "真" "假"))
# 印出：真
(print (if nil "真" "假"))
# 印出：假
(print (if false "真" "假"))
# 印出：假
```

規則只有一句：只有 nil 和 false 是假，其他全部是真。0 是真，空字串是真，之後會學到的空容器也是真。

## 你會踩的坑

⚠ 0 和空字串是真的

你會以為：`(if 0 ...)`、`(if "" ...)` 會走「假」那邊，Python、JS 都是這樣。

其實是：兩個都走「真」那邊。

因為：Janet 只把 nil 和 false 當假，不看數字是不是 0、字串是不是空的。要判斷「是不是 0」就明講 `(= x 0)`，要判斷「是不是空字串」就明講 `(= s "")`。

⚠ keyword 跟字串長得像，但不相等

你會以為：`:abc` 和 `"abc"` 寫的都是 abc，應該相等。

其實是：

```janet
(= "abc" :abc)            # => false
(= "abc" (string :abc))   # => true
```

因為：一個是 string，一個是 keyword，型別不同，`=` 直接判不相等。要比就先用 `string` 把 keyword 轉成字串。

## 小練習

1. 猜猜 `(type (/ 6 2))` 會回什麼？再猜 `(/ 6 2)` 本身是多少？用 `janet -e` 驗證。
2. 用 `if` 測 `(if 0.0 "真" "假")` 和 `(if :false "真" "假")`，各印出什麼？為什麼？
3. `(type (type 1))` 會回什麼？

容器（tuple、array 那些一次裝很多值的東西）這課先不碰，單元 3 講。答案在 `examples/course/1-3.janet` 最後。
