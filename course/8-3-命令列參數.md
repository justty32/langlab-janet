# 8-3 · 命令列參數

你寫了一支小工具，想這樣跑：`janet tool.janet --name Bob a.txt`。使用者打在後面的那些字，程式怎麼拿到？這課先講最原始的拿法，再請 spork 的 argparse 幫你把 `--name`、`-v` 這些東西整理成一張表，順便免費送你 `--help`。

## 這是什麼、為什麼

命令列參數（command-line arguments）就是你在終端機打 `janet 腳本檔 ...` 時，腳本檔名後面那一串字。作業系統會用空白把它們切開，一個一個交給程式，而且**全部都是字串**，`3` 也是 `"3"`。

Janet 把這串字放在一個叫 `:args` 的動態綁定裡。動態綁定（dynamic binding）你先當成「程式一啟動就放好的全域設定值」，用 `(dyn :args)` 讀出來。`*args*` 只是 `:args` 的別名，兩種寫法拿到的是同一個東西。

自己拆 `--name Bob` 很煩：有短寫 `-n`、有長寫 `--name`、有的要帶值、有的可以重複給、還要自己排一份 `--help`。`spork/argparse` 就是幫你做這堆雜事的。

## 動手

### 最原始的拿法：dyn *args*

把下面存成 `args.janet`，用兩種方式跑。

```janet
(print (string/format "%j" (dyn *args*)))
(defn main [& args]
  (print "main 收到：" (string/format "%j" args)))
```

```
$ janet args.janet
@["args.janet"]
main 收到：("args.janet")
$ janet args.janet 3 hello --x
@["args.janet" "3" "hello" "--x"]
main 收到：("args.janet" "3" "hello" "--x")
```

第 0 格永遠是腳本檔名，使用者打的從第 1 格開始。如果你有定義 `main`，Janet 跑完整支檔會自動呼叫它，把同一串參數塞進去（給 `main` 的是 tuple，`dyn` 拿到的是 array，內容一樣）。

### 請 argparse 幫你解析

```janet
(import spork/argparse :as ap)
(def res
  (ap/argparse "示範：跟人打招呼"
    :args ["demo" "-n" "Alice" "--name" "Bob" "--upper" "-vv" "a.txt" "b.txt"]
    "name"    {:kind :accumulate :short "n" :help "名字，可重複給"}
    "upper"   {:kind :flag       :short "u" :help "轉大寫"}
    "verbose" {:kind :multi      :short "v" :help "多給幾次多囉嗦幾分"}
    "level"   {:kind :option     :short "l" :default "1" :help "等級"}
    :default  {:kind :accumulate :help "檔名"}))
(res "name")      # => @["Alice" "Bob"]
(res "upper")     # => true
(res "verbose")   # => 2
(res "level")     # => "1"
(res :default)    # => @["a.txt" "b.txt"]
```

`ap/argparse` 第一個參數是給人看的一句說明，後面每兩個一組：選項名字串、規格 struct。它回傳一張 table，用選項名字串取值；不帶 `-` 的那些字（這裡是兩個檔名）收在特殊的 key `:default` 底下。

`:args [...]` 這一行是餵一串假的參數進去，第 0 格當程式名。課文要能自動測試才這樣寫；真的程式把這行拿掉，它就自己去讀 `(dyn :args)`。

### 四種 kind

| `:kind` | 意思 | 拿到的型別 | 例 |
|---|---|---|---|
| `:flag` | 開關，有給就是 `true` | boolean | `--upper` → `true` |
| `:multi` | 開關可重複給，算次數 | 數字 | `-vv` → `2` |
| `:option` | 帶一個值，給多次取最後一次 | 字串 | `-l 5 -l 9` → `"9"` |
| `:accumulate` | 帶值，可重複，收成 array | array | `-n A -n B` → `@["A" "B"]` |

### 沒給的選項會拿到什麼

```janet
(import spork/argparse :as ap)
(def res
  (ap/argparse "示範" :args ["demo"]
    "upper"  {:kind :flag}
    "level"  {:kind :option :default "1"}
    :default {:kind :accumulate}))
(res "upper")     # => nil
(res "level")     # => "1"
(res :default)    # => nil
```

沒給的開關是 `nil` 不是 `false`，沒給位置參數時 `:default` 也是 `nil` 不是空 array。要拿來 `each` 之前先 `(or (res :default) @[])` 補成空的。

### --help 免費送，出錯也自動印說明

```janet
(import spork/argparse :as ap)
(def res
  (ap/argparse "示範：跟人打招呼" :args ["demo" "--help"]
    "name" {:kind :option :short "n" :help "名字"}))
# 印出：usage: demo [option] ...（接著是每個選項的說明）
res   # => nil
```

使用者打 `--help`、打了不認識的選項、`:option` 後面漏掉值、`:required true` 的選項沒給，四種情況 argparse 都會自己印 usage 然後回傳 `nil`。所以真程式的標準寫法是解析完接一句 `(unless res (os/exit 1))`：拿到 `nil` 就直接結束，說明已經印過了。

### 值都是字串，要數字自己轉

```janet
(import spork/argparse :as ap)
(def res
  (ap/argparse "示範" :args ["demo" "-l" "5"]
    "level" {:kind :option :short "l" :map scan-number}))
(res "level")           # => 5
(+ 1 (res "level"))     # => 6
```

`:map 函式` 會在取到值之後套一次那個函式。`scan-number` 把字串變數字，轉不了會回 `nil`。

### 真的接上命令列

範例檔最後一段沒有 `:args`，讀的是真的命令列。試試看：

```
$ janet examples/course/8-3.janet -n Bob --upper x.txt
$ janet examples/course/8-3.janet --help
```

不帶參數也能跑，因為每個選項都有預設值或允許不給。

## 你會踩的坑

⚠ **兩個 `:default`**。你會以為規格裡的 `:default "1"` 和最外層的 `:default {...}` 是同一件事，其實是兩回事：規格裡的 `:default` 是「這個選項沒給時的預設值」，最外層那個 `:default` 是一個特殊的選項名，用來收所有不帶 `-` 的位置參數。因為 argparse 就是拿 `:default` 這個 keyword 當位置參數的名字，跟預設值撞名純屬巧合。

⚠ **`:option` 拿到的是字串**。你會以為 `-l 5` 拿到的是數字 5，其實是 `"5"`，因為命令列送進來的全是字串，argparse 不知道你要什麼型別。`(+ 1 (res "level"))` 會炸，要嘛 `:map scan-number`，要嘛取出來再轉。

⚠ **單獨一個 `-` 會被默默吃掉**。你會以為照 unix 慣例打 `-` 代表「讀 stdin」，argparse 會把它當位置參數收進 `:default`，其實整個不見了，也不報錯：`:args ["demo" "a" "-"]` 解析後 `:default` 只剩 `@["a"]`。因為 argparse 看到開頭是 `-` 就當作旗標，後面沒名字就跳過。要支援得自己從 `(dyn :args)` 撿回來，寫法見「想更深」。

## 小練習

1. 寫一個 `repeat` 工具：`--count`／`-c` 是次數（預設 `"1"`，用 `:map scan-number`），位置參數是要印的字，印 count 次。用 `:args` 餵 `["demo" "-c" "3" "hi"]` 測。
2. 加一個 `--quiet`／`-q` 開關，給了就一行都不印，只回傳會印的那些行組成的 array。
