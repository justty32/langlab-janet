# 6-1 · 函式與參數

前五個單元你已經一直在呼叫別人寫好的函式。這課換你自己寫：怎麼取名字、怎麼收參數，還有參數可以省、可以不定個數、可以用名字指定。學完你就能把重複的程式碼收成一個名字，以後只叫名字。

## 這是什麼、為什麼

函式（一段動作取個名字，以後用名字叫它）在 Janet 用 `defn` 定義。它跟 Python 的 `def`、C 的函式是同一個概念，差在兩件事：參數表用 `[]` 包，而且沒有 `return`，函式裡最後算出來的那個值就是回傳值（5-3 講過）。

參數（函式定義時留的空位）有好幾種收法。C 只有「幾個就是幾個」，Python 有預設值、`*args`、`**kwargs`。Janet 也有對應的東西，只是長相不同：`&opt`、`&`、`&named`。下面一種一種來，每種先講什麼情況會需要它。

## 動手：最基本的 defn

```janet
(defn 平方 [x] (* x x))
(平方 7)   # => 49
```

`defn` 後面依序是名字、參數表、本體。本體可以好幾行，最後一個運算式的值就是回傳值。呼叫時跟內建函式一樣，`(名字 引數)`，引數（呼叫時實際塞進去的值）照位置對上參數。

兩個以上的參數就在 `[]` 裡並排寫：

```janet
(defn 矩形面積 [寬 高] (* 寬 高))
(矩形面積 3 4)   # => 12
```

## 動手：可以省略的參數 `&opt`

情境：寫一個打招呼函式，稱呼可有可無。有人只給名字，有人名字加「老師」。Python 你會寫 `title=None`。Janet 在參數表裡放 `&opt`，它後面的參數都可以不給，沒給就是 `nil`：

```janet
(defn 打招呼 [名字 &opt 稱呼]
  (if 稱呼
    (string "你好，" 名字 " " 稱呼)
    (string "你好，" 名字)))
(print (打招呼 "小明"))
# 印出：你好，小明
(print (打招呼 "小明" "老師"))
# 印出：你好，小明 老師
```

用一個回傳 tuple（一串放進去就不能改的值）的小函式看得更清楚，省掉的那格真的是 `nil`：

```janet
(defn a [x &opt y] [x y])
(a 1)     # => (1 nil)
(a 1 2)   # => (1 2)
```

## 動手：預設值要用 `default`

情境：省略時不想拿到 `nil`，想拿到一個預設值，像「逾時秒數沒給就當 30」。Janet 的 `&opt` 本身沒有寫預設值的地方，要在本體第一行用 `default`：

```janet
(defn 等待 [工作 &opt 秒數]
  (default 秒數 30)
  [工作 秒數])
(等待 :download)     # => (:download 30)
(等待 :download 5)   # => (:download 5)
```

`(default 秒數 30)` 的意思是「`秒數` 如果是 `nil`，就把它設成 30」。它看的是值是不是 `nil`，不是「呼叫的人有沒有傳」，這點在坑那節會再講。

## 動手：收不定個數的 `&`

情境：加總函式，呼叫的人想給幾個數字就給幾個。Python 用 `*args`。Janet 在參數表裡放 `&`，後面接一個名字，多出來的引數全部收進那個名字，收成一個 tuple：

```janet
(defn 加總 [& 數字] (reduce + 0 數字))
(加總 1 2 3)   # => 6
(加總)         # => 0
```

`&` 前面可以先放必要參數。剩下的才進 tuple，一個都沒剩就是空 tuple：

```janet
(defn c [x & 其餘] [x 其餘])
(c 1 2 3)   # => (1 (2 3))
(c 1)       # => (1 ())
```
