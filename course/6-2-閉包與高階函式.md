# 6-2 · 閉包與高階函式

上一課你學會用 `defn` 做函式。這課換個角度看：函式本身也是一個值，可以存起來、傳來傳去。學完你能用 `map`、`filter`、`reduce` 一行處理一整串資料，也會做出「記得自己狀態」的小函式。

## 這是什麼、為什麼

在 C 裡，函式跟變數是兩種東西。Janet 不分：函式跟數字、字串一樣是值，只是這個值可以被呼叫。

有了這點，就能寫高階函式（吃函式或吐函式的函式）。為什麼要它？想想「走過一串發票」這件事。走過去的迴圈每次都長一樣，不一樣的只有「對每張發票做什麼」。高階函式把走訪的部分寫好，「做什麼」留給你用一個函式交進去。你不用再每次手寫迴圈。

## 動手

### fn：沒有名字的函式

```janet
(def 加倍 (fn [x] (* x 2)))
(加倍 21)   # => 42
(print (type 加倍))
# 印出：function
```

`(fn [參數] 本體)` 做出一個函式，但不幫它取名字。這裡用 `def` 把它存進 `加倍` 這個名字，之後就跟平常一樣呼叫。

其實上一課的 `(defn 加倍 [x] ...)` 就是 `(def 加倍 (fn [x] ...))` 的簡寫。`defn` 等於 `def` 加上 `fn`。

函式既然是值，也能放進 array：

```janet
(def 步驟 @[(fn [x] (+ x 1)) (fn [x] (* x 10))])
((get 步驟 0) 5)   # => 6
((get 步驟 1) 5)   # => 50
```

`(get 步驟 0)` 拿出第一個函式，外面再包一層括號就是呼叫它。注意兩層括號：內層「拿出來」、外層「叫它」。

### 把函式當引數傳進去

```janet
(defn 做兩次 [f x] (f (f x)))
(做兩次 (fn [x] (* x 3)) 2)   # => 18
```

`做兩次` 就是一個高階函式：它不知道要做什麼，只負責「做兩次」。你傳進一個「乘三」的函式，2 乘兩次三得到 18。

### map：每一個都做同一件事

生活例子：每張發票都加上 5% 的稅。

```janet
(map (fn [金額] (/ (* 金額 105) 100)) [100 200 40])   # => @[105 210 42]
```

`(map 函式 序列)` 把函式套在每一個元素上，結果收成一個新的 array（所以印出來有 `@`）。原本的 tuple 沒被改動。

### filter：只留下符合條件的

生活例子：從一疊發票挑出超過 100 元的。

```janet
(filter (fn [金額] (> 金額 100)) [50 120 300 80])   # => @[120 300]
```

你給的函式回真，那個元素就留下；回假就丟掉。結果一樣是 array。

### reduce：一疊東西併成一個值

生活例子：把一疊收據加總成一個數字。

```janet
(reduce + 0 [120 45 300])   # => 465
```

參數順序是 `(reduce 函式 初始值 序列)`。它從初始值 0 開始，拿 `(+ 0 120)`，再拿結果去 `(+ 120 45)`，一路累積到最後。`+` 本身就是函式，直接傳進去就好。

換成自己寫的函式也行，第一個參數是「目前累積到的值」，第二個是「下一個元素」：

```janet
(reduce (fn [累積 x] (+ 累積 x)) 0 [1 2 3])   # => 6
```

### `|`：短寫的函式

`(fn [x] ...)` 寫多了很煩。Janet 有個縮寫：`|` 後面接一個 form（一組括號），裡面用 `$` 代表參數。

```janet
(map |(* $ 2) [1 2 3])         # => @[2 4 6]
(filter |(> $ 100) [50 120])   # => @[120]
```

`|(* $ 2)` 跟 `(fn [x] (* x 2))` 完全一樣，只是少打幾個字。

要兩個以上參數時用 `$0`、`$1`；想把剩下的全收起來用 `$&`：

```janet
(|(+ $0 $1) 3 4)   # => 7
(|$& 1 2 3)        # => (1 2 3)
```

## 你會踩的坑

⚠ `|` 只吃緊接著的一個 form。

你會以為 `|(print $) (* $ 2)` 是一個做兩件事的短函式。其實只有 `(print $)` 屬於函式，`(* $ 2)` 被留在外面，而外面沒有 `$` 這個名字，整支檔案直接報 `unknown symbol $`。因為 `|` 的規則就是「把後面那一個 form 包成函式」，多的它不管。

要做好幾件事就回去用 `fn`，或在 `|` 後面自己包一層 `(do ...)`。
