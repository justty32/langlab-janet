# 6-3 · 執行緒巨集與解構

寫久了你會發現兩種很煩的程式碼：一種是括號一層包一層，要從最裡面往外讀；另一種是一直寫 `(get x 0)`、`(get x 1)` 把容器裡的東西一個個掏出來。這課教兩個專治它們的寫法。學完你能把一串處理步驟寫成由上往下讀，也能一行把容器拆成好幾個名字。

## 這是什麼、為什麼

先講名字。執行緒巨集（threading macro）聽起來像多執行緒、並行，其實跟那些完全無關。這裡的「thread」是「穿線」的意思：把一筆資料像穿針一樣，依序穿過一串函式。它只是把巢狀括號攤平的一種寫法。

看一個三層巢狀的例子。你想對 5 先加 3、再乘 2、最後加 1：

```janet
(inc (* (+ 5 3) 2))   # => 17
```

要讀懂它，你得先找到最裡面的 `(+ 5 3)`，再往外一層一層看。步驟順序跟閱讀順序是反的。

同一件事用 `->` 寫：

```janet
(-> 5 (+ 3) (* 2) inc)   # => 17
```

讀法變成：拿 5，加 3，乘 2，加 1。兩段程式碼是同一件事，算出來都是 17，只是寫法不同。`->` 是巨集（在程式跑之前先把你寫的程式碼改寫成另一段程式碼的東西），它在背後幫你把第二種改寫回第一種。

另一個主角是解構（destructuring），放在[續篇](6-3b-執行緒巨集與解構.md)講。

## 動手

### `->`：塞進第一個參數

`->` 把前一步的結果，塞進下一個呼叫的第一個參數位置。所以 `(-> 5 (+ 3))` 會變成 `(+ 5 3)`。

某一步只有一個函式名、沒有括號時（像上面的 `inc`），它等於 `(inc 前一步結果)`。

```janet
(-> "hello" string/ascii-upper (string "!"))   # => "HELLO!"
```

這段先把 `"hello"` 變大寫，再塞進 `(string "!")` 的第一個位置，變成 `(string "HELLO" "!")`，所以驚嘆號接在後面。

### `->>`：塞進最後一個參數

`->>` 長得很像，差別只在塞的位置：它塞進最後一個參數。

```janet
(->> [1 2 3 4] (map inc) (filter even?))   # => @[2 4]
```

展開後是 `(filter even? (map inc [1 2 3 4]))`。每個數加 1 得到 2 3 4 5，再留下偶數，剩 2 和 4。

為什麼要有兩個？因為函式有兩種習慣。`map`、`filter`、`reduce` 這種處理一串資料的函式，習慣把資料放在最後；`get`、`string/...` 這種對著一個東西操作的函式，習慣把那個東西放在最前。所以慣例是：資料處理的串接用 `->>`，對一個東西連續操作用 `->`。

### `-?>`：遇到 nil 就停

一串 `get` 往下挖時，中間某層不存在就會拿到 nil，下一步對 nil 做事可能直接炸。`-?>` 會在任何一步拿到 nil 時停下來，整串回 nil。

```janet
(-?> nil (get :a))                     # => nil
(-?> {:a {:b 7}} (get :a) (get :b))    # => 7
(-?> {:a 1} (get :x) (+ 1))            # => nil
```

第三行 `(get :x)` 拿到 nil，後面的 `(+ 1)` 就不跑了。換成普通的 `->`，它會真的去算 `(+ nil 1)` 然後拋錯。

還有一個 `as->`，讓你自己指定塞在哪：`(as-> 5 $ (+ $ 1) (* $ $))` 回 36，`$` 放哪就塞哪。兩種預設位置都不合用時才需要它。

## 你會踩的坑

⚠ 選錯 `->` 和 `->>` 不會報錯，會安靜算出另一個答案。

你會以為這兩行只是寫法不同，結果一樣：

```janet
(-> 2 (- 10))    # => -8
(->> 2 (- 10))   # => 8
```

其實一個是 -8、一個是 8。因為 `->` 把 2 塞到第一個位置，算的是 `(- 2 10)`；`->>` 塞到最後，算的是 `(- 10 2)`。減法、除法、`get`、`string/find` 這種參數順序有意義的函式都會中招。

不確定時，用 `macex1` 看它展開成什麼。注意要在前面加 `'`，讓 Janet 把那段當資料交給你，而不是直接執行：

```janet
(macex1 '(-> 2 (- 10)))    # => (- 2 10)
(macex1 '(->> 2 (- 10)))   # => (- 10 2)
```

印出來的就是真正會被執行的那段程式碼，一眼就看得出 2 被塞到哪。
