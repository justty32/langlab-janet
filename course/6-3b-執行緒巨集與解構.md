# 6-3b · 執行緒巨集與解構（續）

上一篇講完執行緒巨集，這篇講另一個主角：解構。最後把兩個合起來用一次。

## 這是什麼、為什麼

假設你有一個點 `[3 4]`，想算它離原點距離的平方。不用解構會這樣寫：

```janet
(def pt [3 4])
(+ (* (get pt 0) (get pt 0)) (* (get pt 1) (get pt 1)))   # => 25
```

一堆 `(get pt 0)`、`(get pt 1)`，讀的人還得記住 0 是 x、1 是 y。

解構（destructuring）是一次把容器裡的東西拆成好幾個名字。你在要取名字的位置，直接寫出容器的形狀，Janet 就照形狀對號入座。

## 動手

### 拆 tuple 或 array

```janet
(def [a b] [1 2])
[a b]   # => (1 2)
```

左邊寫 `[a b]`，右邊是 `[1 2]`，於是 `a` 是 1、`b` 是 2。

想要「第一個單獨拿，剩下的打包」就用 `&`：

```janet
(def [a & rest] [1 2 3 4])
[a rest]   # => (1 (2 3 4))
```

### 拆 struct 或 table

字典用字典的形狀拆。`{:x x}` 的意思是「把鍵 `:x` 的值放進名字 `x`」：

```janet
(def {:x x :y y} {:x 1 :y 2})
[x y]   # => (1 2)
```

左邊是鍵、右邊是你要取的名字，兩邊不必同名，`{:x px}` 也可以。

### 巢狀也行

形狀可以一層套一層：

```janet
(def [x [y z]] [1 [2 3]])
[x y z]   # => (1 2 3)
```

### 函式參數和 each 裡也能拆

不只 `def`，`let`、`var`、函式參數、`each` 的名字位置都能寫形狀：

```janet
(defn f [[a b] {:k k}] [a b k])
(f [1 2] {:k 9})   # => (1 2 9)
```

`f` 的第一個參數是一個 tuple，直接拆成 `a`、`b`；第二個是字典，拆出 `:k`。

走訪字典時很常用。`pairs` 會給出一對對 `[鍵 值]`，`each` 當場拆開：

```janet
(each [k v] (pairs {:a 1}) (print k " = " v))
# 印出：a = 1
```

## 你會踩的坑

⚠ 值不夠時補 nil，不報錯。

你會以為形狀對不上時 Janet 會抱怨：

```janet
(def [x y z] [1 2])
[x y z]   # => (1 2 nil)
```

其實它安靜地把 `z` 設成 nil。因為解構只負責「有就拿、沒有就給 nil」，字典拆不存在的鍵也一樣。所以解構不能拿來檢查資料形狀對不對，要檢查就自己用 `assert` 或 `if` 判斷。

⚠ 解構字串拿到的是數字。

你會以為 `(def [c1 c2] "ab")` 會拿到 `"a"` 和 `"b"`：

```janet
(def [c1 c2] "ab")
[c1 c2]   # => (97 98)
```

其實拿到的是 97 和 98。因為 Janet 的字串是一串 byte（位元組），拆出來的每一格是 byte 的數值，跟 `(get "ab" 0)` 回 97 是同一條規則。

## 兩個一起用

它們很常一起出現：先用 `->>` 把資料處理好，再用解構拿出想要的幾個。

```janet
(def [first-big second-big]
  (->> [5 3 8 1 9 2] (filter |(> $ 2)) sort))
[first-big second-big]   # => (3 5)
```

`->>` 那段留下大於 2 的數再排序，得到 `@[3 5 8 9]`；左邊的 `[first-big second-big]` 只取前兩個。
