# 8-1 · 讀寫檔案

程式跑完，記憶體裡的東西就沒了。想留下來，就要寫進檔案；下次再讀回來。
這課教你讀寫檔案：先學最常用的兩個函式，再學一行一行慢慢讀的做法。

## 這是什麼、為什麼

Janet 讀寫檔案有兩種做法。

第一種是整檔一次搞定：`slurp` 把整個檔案讀進來，`spit` 把一段文字整個寫出去。
你寫設定檔、存 JSON、讀小文字檔，九成都用這兩個就夠了。

第二種是先「打開」檔案，拿到一個 file handle（代表「一個開著的檔案」的值，
像是拿在手上的一本書），再用它一次讀一行、或分好幾次寫。檔案很大、
或你要邊讀邊處理的時候才需要它。這部分在續篇 [8-1b](8-1b-讀寫檔案.md)。

下面每段程式碼都把檔案寫在暫存目錄 `/tmp/janet-course-8-1` 裡，跑完就刪掉，
不會弄髒你的資料夾。

## 動手：spit 寫、slurp 讀

```janet
(def tmp (string (or (os/getenv "TMPDIR") "/tmp") "/janet-course-8-1"))
(os/mkdir tmp)
(def p (string tmp "/hello.txt"))
(spit p "hello\n")   # => nil
(slurp p)            # => @"hello\n"
(os/rm p)
(os/rm tmp)
```

前三行準備路徑：`os/getenv` 讀環境變數 `TMPDIR`，沒設就用 `/tmp`；
`os/mkdir` 建出資料夾。

`(spit 路徑 內容)` 把內容寫進檔案，回傳 `nil`。檔案不存在會自動建；
已經存在就整個蓋掉，舊內容不見。

`(slurp 路徑)` 把整個檔案讀回來。注意結果前面有個 `@`：它是 buffer
（可以改的字串），不是一般的字串。這個差別等一下會咬你，先記著。

最後兩行 `os/rm` 刪檔、再 `os/rm` 刪掉已經空了的資料夾，把現場清乾淨。

## 動手：在檔尾接著寫

`spit` 預設是整個蓋掉。想在後面接著寫（像記 log），第三個參數給 `:ab`：

```janet
(def tmp (string (or (os/getenv "TMPDIR") "/tmp") "/janet-course-8-1"))
(os/mkdir tmp)
(def p (string tmp "/log.txt"))
(spit p "第一行\n")
(spit p "第二行\n" :ab)
(print (slurp p))
# 印出：
# 第一行
# 第二行
(os/rm p)
(os/rm tmp)
```

`:ab` 是 keyword（冒號開頭、當標籤用的值），意思是 append（附加）＋ binary（二進位）。
為什麼要多那個 `b`，續篇講 Windows 換行時會說；現在先記「附加就寫 `:ab`」。

## 動手：檔案不在時怎麼辦

`slurp` 讀不到檔案會直接拋錯（程式中斷並丟出錯誤訊息），不會回 `nil`：

```janet
(def tmp (string (or (os/getenv "TMPDIR") "/tmp") "/janet-course-8-1"))
(def p (string tmp "/沒有這個檔.txt"))
(first (protect (slurp p)))   # => false
(os/stat p)                   # => nil
(try (slurp p) ([_] "default"))   # => "default"
```

`protect` 把錯誤接住，回一個 tuple：第一格 `false` 代表出錯了。

要避免出錯有兩種寫法。一是先問 `os/stat`：它查檔案的資訊，檔案不在就回 `nil`，
所以可以 `(if (os/stat p) (slurp p) 預設值)`。二是直接讀，用 `try` 接住錯誤，
出錯就改用預設值，最後一行就是這樣。

兩種都行。`try` 版比較穩，因為「先檢查再讀」中間檔案還是有可能被別人刪掉。

## 你會踩的坑

⚠ slurp 回來的東西跟字串比，永遠不相等

你會以為：寫進去 `"hi\n"`，讀回來 `(= "hi\n" (slurp p))` 應該是 `true`。

其實是：`false`。

因為：`slurp` 回的是 buffer，`"hi\n"` 是字串，兩個是不同型別，`=` 直接判不相等。
先用 `string` 轉一次就好：

```janet
(def tmp (string (or (os/getenv "TMPDIR") "/tmp") "/janet-course-8-1"))
(os/mkdir tmp)
(def p (string tmp "/hi.txt"))
(spit p "hi\n")
(= "hi\n" (slurp p))            # => false
(= "hi\n" (string (slurp p)))   # => true
(os/rm p)
(os/rm tmp)
```

要拿讀回來的內容當 table 的鍵、或拿去比較，都先 `string` 一下。
