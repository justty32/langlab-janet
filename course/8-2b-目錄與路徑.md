## 動手：用 spork/path 組路徑

路徑看起來就是字串，很多人直接用 `string` 把目錄和檔名黏起來。這樣會出事：Linux 用 `/` 分隔，Windows 用 `\`；前一段尾巴有斜線、後一段開頭也有斜線時，還會黏出兩個斜線。

`spork/path` 是專門處理這些的函式庫。`import` 之後用 `path/` 開頭的函式：

```janet
(import spork/path)
(path/join "a" "b" "c.txt")          # => "a/b/c.txt"
(string "out/" "/data.txt")          # => "out//data.txt"
(path/join "out/" "/data.txt")       # => "out/data.txt"
```

`path/join` 會用當前系統的分隔符接起來（上面是 Linux 的結果，Windows 會是 `"a\\b\\c.txt"`），多餘的斜線也會幫你收掉。自己用 `string` 接，兩個斜線就原樣留著。

拆路徑也有現成的：

```janet
(import spork/path)
(path/basename "a/b/c.txt")          # => "c.txt"
(path/dirname "a/b/c.txt")           # => "a/b/"
(path/ext "a/b/c.txt")               # => ".txt"
(path/ext "a.tar.gz")                # => ".gz"
(path/ext "Makefile")                # => nil
(path/abspath? "a/b")                # => false
(print (path/abspath "x"))
# 印出：目前工作目錄接上 /x，例如 /home/you/janet-lab/x
```

`basename` 是最後一段檔名，`dirname` 是前面的目錄，`ext` 是副檔名，`abspath` 把相對路徑展開成從根目錄開始的絕對路徑。

## 動手：小工具，把 .txt 的行數加總

把兩半課的東西串起來：列目錄、挑出 `.txt`、組出完整路徑、逐行數、加總。

```janet
(import spork/path)
(def tmp (string (or (os/getenv "TMPDIR") "/tmp") "/janet-course-8-2"))
(os/mkdir tmp)
(spit (path/join tmp "a.txt") "1\n2\n3\n")
(spit (path/join tmp "b.txt") "x\ny\n")
(spit (path/join tmp "note.md") "skip\n")

(defn count-lines [p]
  (with [f (file/open p :rb)]
    (var n 0)
    (while (file/read f :line) (++ n))
    n))

(defn txt-total [dir]
  (var total 0)
  (each name (sort (os/dir dir))
    (when (= ".txt" (path/ext name))
      (+= total (count-lines (path/join dir name)))))
  total)

(txt-total tmp)                      # => 5

(each name (os/dir tmp) (os/rm (path/join tmp name)))
(os/rm tmp)
```

`a.txt` 三行、`b.txt` 兩行，合計 5；`note.md` 副檔名不對，被跳過。`count-lines` 用的是 8-1 教過的 `with` 加 `file/read :line`。清理時也順手用了 `os/dir`：把目錄裡每個名字接回完整路徑再刪，最後刪空目錄。

## 你會踩的坑

⚠ **把 os/dir 的結果直接拿去開檔**

你會以為 `(os/dir "data")` 給的是能直接 `slurp` 的路徑。其實它只給 `"a.txt"` 這種名字。因為 `os/dir` 只回報目錄裡的項目名稱，所以要 `(path/join "data" name)` 接回去，不然會跑去目前工作目錄找檔案。

⚠ **以為 os/dir 會走整棵樹**

你會以為子目錄裡的檔案也會列出來。其實 `os/dir` 只看一層。因為它對應的是作業系統「讀一個目錄」的那個動作，要整棵樹得自己遞迴，或用 `spork/sh` 的 `sh/list-all-files`。

⚠ **拿 os/rm 刪整個目錄**

你會以為 `os/rm` 像 `rm -rf`。其實目錄裡還有東西時它拋錯 `Directory not empty`。因為它只做最基本的刪除，要自己由內往外清空。

⚠ **拿 os/mkdir 一次建好幾層**

你會以為 `(os/mkdir "x/y/z")` 會把三層都建出來。其實上層不存在就拋錯：

```janet
(protect (os/mkdir "no-such-8-2/deep"))  # => (false "No such file or directory: no-such-8-2/deep")
```

因為它只建最後一層。要一層一層呼叫，或改用 `spork/sh` 的 `sh/create-dirs` 一次建好。

⚠ **path/dirname 和 path/ext 的細節**

你會以為 `(path/dirname "a/b/c.txt")` 是 `"a/b"`、`path/ext` 回 `"txt"`。其實是 `"a/b/"`（尾巴帶斜線）和 `".txt"`（帶點）。因為 spork 就是這樣定義的；拿 `path/ext` 比對時記得寫 `".txt"`。

## 小練習

1. 寫 `(ensure-file p text)`：`p` 不存在才用 `spit` 寫入 `text`，已存在就不動。回傳 `true` 表示有寫、`false` 表示沒寫。
2. 寫 `(sizes dir)`：回一個 table，鍵是 `dir` 底下每個**檔案**的名字，值是它的大小（`:size`）。子目錄要跳過。
