# 1-1 · 裝好，跑起來

這課只做一件事：讓你能把 Janet 程式跑起來。學完你會三種跑法：開一個視窗邊打邊看、跑一支存好的檔案、在命令列丟一行進去算。後面每一課都會用到這三招。

## 這是什麼、為什麼

Janet 是一個小小的程式語言，整個語言就是一支叫 `janet` 的執行檔。你寫的程式交給它，它讀進去、照著做。

這台機器已經裝好了，`janet` 放在 `~/.local/bin`，那個目錄已經在 PATH 裡，所以開任何終端機都能直接打 `janet`。怎麼裝的這課不講，想知道的去看課尾的連結。

同一支 `janet` 有三種用法。第一種是 REPL（打一行、馬上看結果的互動視窗），適合試東西。第二種是跑一支 `.janet` 檔，適合寫好要留下來的程式。第三種是 `janet -e`，在命令列直接給它一行程式，適合隨手算一下。

## 動手

### 先確認它在

```sh
janet -v
```

會印出版本號 `1.41.2-0fea20c`。有印出來就代表裝好了。

### 開 REPL，算第一個式子

在終端機打 `janet`，按 Enter，會看到：

```text
Janet 1.41.2-0fea20c linux/x64/gcc - '(doc)' for help
repl:1:>
```

第一行是版本說明。第二行 `repl:1:>` 是提示字元，意思是「我在 REPL 裡，這是你的第 1 次輸入，請打」。

現在打 `(+ 1 2)` 按 Enter：

```text
repl:1:> (+ 1 2)
3
repl:2:>
```

Janet 把 `(+ 1 2)` 算成 `3` 印給你，然後提示字元變成 `repl:2:>`，等你打下一個。`(+ 1 2)` 這種一組括號包起來的東西，我們叫它式子（一組括號包起來、可以被算出一個值的東西）。Janet 剛剛做的事叫求值（把式子算成一個值）。括號為什麼長這樣，下一課專門講，這課先照抄就好。

之後課文裡不會每次都貼整段 REPL 畫面，會改用這種寫法標出結果，`# =>` 後面就是它算出來的值：

```janet
(+ 1 2)   # => 3
```

REPL 會自動把每個式子的結果印出來，這是它跟另外兩種跑法最大的不同，等一下會再遇到。

### 沒打完，它會等你

一個式子可以拆成好幾行打。括號還沒關起來，Janet 就知道你還沒打完：

```text
repl:2:> (+ 1
repl:3:(> 2)
3
```

注意第二行的提示字元多了一個 `(`，變成 `repl:3:(>`。這是在提醒你「還有一個括號沒關」。補上 `)` 之後它才開始算。

### 離開 REPL

兩種方法都可以。按 Ctrl-D，或者打 `(quit)`：

```text
repl:2:> (quit)
nil
```

`(quit)` 後面那個 `nil` 是 `(quit)` 自己算出來的值，REPL 照慣例印出來，不用理它，印完就回到終端機了。

### 跑一支檔案

用編輯器建一支 `hello.janet`，內容兩行：

```janet
(print "hello, Janet")
(print (+ 1 2))
# 印出：hello, Janet
# 印出：3
```

`print` 的意思是「把這個東西印到螢幕上」。存檔後在終端機跑：

```sh
janet hello.janet
```

```text
hello, Janet
3
```

Janet 從檔案第一行做到最後一行，做完就結束，不會留在 REPL 裡。這課配套的範例檔也是這樣跑：

```sh
janet examples/course/1-1.janet
```

### 一行求值：`janet -e`

不想開 REPL、也不想建檔，只想算一下，就用 `-e`：

```sh
janet -e '(print (+ 1 2))'
```

會印出 `3`。外面那層單引號是給 shell 看的，讓整串程式當成一個參數交給 `janet`。

## 你會踩的坑

⚠ `janet -e` 和跑檔案不會自動印結果。

你會以為 `janet -e '(+ 1 2)'` 會印出 `3`。其實什麼都沒印，直接結束。因為自動印結果是 REPL 專屬的服務；跑檔案和 `-e` 只會印你用 `print` 叫它印的東西。所以在檔案裡寫 `(+ 1 2)` 也一樣安靜，要看到結果就包一層 `print`。

⚠ 提示字元一直是 `(>`，怎麼按 Enter 都沒反應。

你會以為 REPL 當掉了。其實它在等你把括號關起來。因為少打一個 `)` 時，Janet 認為式子還沒結束，就一直等。補上 `)` 按 Enter 就好。

⚠ 忘了打括號，結果怪怪的。

你會以為打 `+ 1 2` 會得到 `3`。其實 REPL 會印出三行：`<function +>`、`1`、`2`。因為沒有括號，Janet 把 `+`、`1`、`2` 當成三個各自獨立的東西，一個一個算給你看。要它「拿 1 和 2 去加」，就得包成 `(+ 1 2)`。

## 小練習

1. 開 REPL，算 `(* 6 7)`（`*` 是乘法），看它印什麼，然後用 `(quit)` 離開。
2. 寫一支 `me.janet`，印出你的名字，再印出 `(+ 100 23)` 的結果。用 `janet me.janet` 跑它。
3. 不開 REPL、不建檔，用一行指令印出 `(* 6 7)` 的結果。

答案在 `examples/course/1-1.janet` 最後面。
