# 5-1 · 條件

程式常常要「看情況做不同的事」：分數夠就及格、沒給名字就用預設。這課教 Janet 裡做選擇的幾種寫法，`if`、`when`、`cond`、`case`，還有 `and`／`or` 的一個好用習慣。學完你能讓程式依條件走不同的路，也能幫函式參數補預設值。

## 這是什麼、為什麼

每一種寫法都在回答同一個問題：這個條件算真還是算假？所以先把「什麼算真」講清楚。

Janet 的規則很短：只有 `nil`（「沒有值」）和 `false` 是假，其他全部是真。`0` 是真，空字串 `""` 是真，空陣列 `@[]` 也是真。

再來是一個跟 C、Python 不同的地方。在 Janet 裡 `if` 不是「敘述」，是運算式（會算出一個值的東西）。`if` 選了哪條路，那條路算出的值就是整個 `if` 的值，所以你可以直接把它存起來。後面每一種條件寫法都一樣，都會回值。

## 動手：什麼算真

```janet
(if 0 "yes" "no")      # => "yes"
(if "" "yes" "no")     # => "yes"
(if @[] "yes" "no")    # => "yes"
(if nil "yes" "no")    # => "no"
(if false "yes" "no")  # => "no"
```

前三個都走了「真」那條路。想問「是不是空的」「是不是零」，要自己明講：

```janet
(empty? "")    # => true
(empty? @[])   # => true
(zero? 0)      # => true
(not 0)        # => false
```

`empty?` 問容器或字串是不是空的，`zero?` 問數字是不是 0，`not` 把真假反過來。`(not 0)` 是 `false`，因為 `0` 本來就是真。

## 動手：if

寫法是 `(if 條件 真的時候做這個 否則做這個)`：

```janet
(def x (if (even? 4) :even :odd))
x                       # => :even
(if (> 3 5) :big)       # => nil
```

`even?` 問是不是偶數，4 是，所以 `if` 算出 `:even`，存進 `x`。第二行只寫了「真的時候」那一格，條件 `(> 3 5)` 是假，又沒有「否則」可走，`if` 就回 `nil`。

⚠ `if` 的兩格各只能放一個運算式。想在一邊做好幾件事，用下面的 `when`，或用 `(do 甲 乙)` 把它們包成一個。

## 動手：when 與 unless

只關心一邊的時候用 `when`：條件真，就依序做裡面所有的運算式，回最後一個的值；條件假就回 `nil`。`unless` 反過來，條件假才做。

```janet
(when (> 5 3)
  (print "big")
  :done)                # => :done
(when (< 5 3) :done)    # => nil
(unless (nil? 1) :has)  # => :has
```

第一段會先印出 `big`，再回 `:done`。`nil?` 問是不是 `nil`，`1` 不是，所以 `unless` 會做。

## 動手：cond，一串條件

條件不只兩種時用 `cond`。它是一串「條件 結果」兩兩一對，由上往下看，第一個條件為真的那對贏。最後單獨一格、沒有配對的，就是「以上都不是」：

```janet
(defn sign [n]
  (cond
    (< n 0)   :neg
    (zero? n) :zero
    :pos))
(sign -2)   # => :neg
(sign 0)    # => :zero
(sign 9)    # => :pos
(cond false :a)   # => nil
```

最後一行：沒有一個條件中，也沒有「以上都不是」，`cond` 回 `nil`，不會報錯。

## 動手：case，拿一個值比常值

如果每個條件都是「這個值等不等於某個東西」，用 `case` 比較省字。它拿第一個參數，用 `=` 跟後面的常值一個一個比，像 C 的 `switch`：

```janet
(case :cat :dog "woof" :cat "meow" "unknown")   # => "meow"
(case :fox :dog "woof" :cat "meow" "unknown")   # => "unknown"
(case :fox :dog "woof")                         # => nil
```

同樣，最後單獨一格是「以上都不是」，沒有又都不中就回 `nil`。

如果值有結構，你想把裡面的東西拆出來（例如 `[:add 1 2]`），那是 `match` 的工作，6-4 會講。

## 動手：and 與 or 回的是值本身

你可能以為 `and`／`or` 只會回 `true` 或 `false`。不是，它們回的是參數中的某一個值：

```janet
(and 1 2 3)        # => 3
(and 1 false 3)    # => false
(or nil false 7)   # => 7
(or nil false)     # => false
```

`and` 從左看到右，碰到第一個假值就回它；全部是真就回最後一個。`or` 碰到第一個真值就回它；全部是假就回最後一個。

這帶出一個很常見的寫法：`(or 使用者給的值 預設值)`。使用者有給就用他的，沒給（是 `nil`）就用預設：

```janet
(defn greet [&opt name]
  (string "hi, " (or name "guest")))
(greet "Ann")   # => "hi, Ann"
(greet)         # => "hi, guest"
```

`&opt` 的意思是「後面這個參數可以不給，不給就是 `nil`」，6-1 會細講。

## 你會踩的坑

⚠ **用 0 或空的東西當假。**
你會以為 `(if (length xs) ...)` 在 `xs` 是空的時候會走「否則」。其實它永遠走「真」那條路，因為 `(length xs)` 算出 `0`，而 `0` 在 Janet 是真。要寫 `(if (empty? xs) ...)`。

⚠ **拿 case 比陣列。**
你會以為 `(case @[1 2] @[1 2] :hit :miss)` 會中。其實它回 `:miss`，因為 `case` 用 `=` 比，而 array 這種可以改的東西，`=` 比的是「是不是同一個物件」，不是內容（3-3 講過）。所以 `case` 只拿來比 keyword、數字、字串、tuple；`(case [1 2] [1 2] :hit :miss)` 用 tuple 就會中。

⚠ **or 的預設值蓋掉 false。**
你會以為 `(or 使用者給的值 true)` 在使用者傳 `false` 時會保留 `false`。其實它回 `true`，因為 `false` 也是假，`or` 會跳過它。參數本身可能是 `false` 時，改用 `(if (nil? x) 預設 x)`。

## 小練習

1. 寫 `(grade score)`：90 以上回 `:A`，60 以上回 `:pass`，其他回 `:fail`。
