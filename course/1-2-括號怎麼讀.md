# 1-2 · 括號怎麼讀

第一次看 Janet 程式，最先嚇到人的是滿滿的括號。這課教你怎麼讀它們。學完你能看著一串巢狀括號，從最裡面一層一層算出答案，也知道括號沒對上時 Janet 會怎麼抱怨。

## 這是什麼、為什麼

Janet 是 Lisp 家族的語言。Lisp 的程式碼全部長成同一個樣子：

```text
(動作 東西 東西 ...)
```

一組括號包起來的東西叫式子（一組括號包起來、可以被算出一個值的東西）。括號裡第一個位置放動作，後面放參數（丟給動作的東西）。Janet 拿到式子就把它算出來，這件事叫求值（把式子算成一個值）。

你熟的寫法是 `1 + 2`，加號夾在中間。Lisp 把加號搬到最前面，再用括號包起來，寫成 `(+ 1 2)`。

為什麼要這樣？因為這樣就沒有運算子優先順序要背。`1 + 2 * 3` 要先乘還是先加，你得記規則。在 Janet 裡，你想先算哪個，就把哪個包進自己的括號，結構寫在臉上。另一個好處是整個語言只有一種句型，加法、呼叫函式、定義東西，全都是 `(動作 東西 東西)`。

你之後還會看到 `[1 2 3]` 和 `{:a 1}` 這種方括號、大括號。它們是資料，單元 3 會講，這課只管圓括號。

## 動手：最簡單的式子

```janet
(+ 1 2)   # => 3
(- 10 4)  # => 6
(* 3 6)   # => 18
```

讀法固定：先看第一個位置知道要做什麼，再看後面拿什麼來做。`(- 10 4)` 讀成「減，10 和 4」，也就是 10 減 4。

## 動手：一個動作吃好幾個參數

加號不限兩個參數，後面要接幾個都可以：

```janet
(+ 1 2 3)        # => 6
(+ 1 2 3 4 5)    # => 15
(* 2 3 4)        # => 24
(- 10 4 1)       # => 5
```

`(- 10 4 1)` 是從 10 開始，依序減掉 4 和 1。其他語言要寫 `1 + 2 + 3 + 4 + 5`，這裡加號只寫一次。

## 動手：巢狀怎麼用眼睛讀

拿一個你熟的算式：`(1 + 2) * (10 - 4)`。答案是 3 乘 6，等於 18。換成 Janet 寫法：

```janet
(* (+ 1 2) (- 10 4))   # => 18
```

讀巢狀的訣竅是：從最裡面、沒有再包括號的那幾組開始算，算完就用答案取代它，一路往外。

第一步，找最裡層。`(+ 1 2)` 和 `(- 10 4)` 裡面都沒有別的括號，先算它們：

```janet
(+ 1 2)    # => 3
(- 10 4)   # => 6
```

第二步，把答案填回原位。原本的式子變成 `(* 3 6)`：

```janet
(* 3 6)    # => 18
```

外層只剩一個乘號和兩個數字，答案 18，跟整串一起算的結果一樣。Janet 自己求值也是這個順序：要算外面的動作，得先把每個參數算出來。再來一個三層的，`20 - 2 * (3 + 4)`：

```janet
(- 20 (* 2 (+ 3 4)))   # => 6
(+ 3 4)                # => 7
(* 2 7)                # => 14
(- 20 14)              # => 6
```

第一行是整串，後面三行是一層一層拆開的樣子。眼睛不必從左讀到右，找到最深的那組括號，從那裡往外剝就好。

## 動手：註解

`#` 後面到行尾都是註解（寫給人看、Janet 會跳過的文字）。就算寫在式子中間，Janet 也直接略過：

```janet
# 這整行都是註解
(+ 1 2 # 這裡也可以寫
   3)   # => 6
```

## 動手：換行和縮排只是給人看的

Janet 只看括號，不看換行也不看空白多寡。下面兩種寫法完全一樣：

```janet
(* (+ 1 2) (- 10 4))   # => 18
(*
  (+ 1 2)
  (- 10 4))            # => 18
```

式子一長，大家習慣把參數拆成好幾行、往內縮，讓人一眼看出誰是誰的參數。縮排對 Janet 沒有意義，這點跟 Python 不同。

## 動手：括號沒對上會怎樣

在 REPL（打一行、馬上看結果的互動視窗）裡，括號還沒關完，Janet 會等你打完：

```text
repl:1:> (* (+ 1 2)
repl:2:(> (- 10 4))
18
repl:3:> (+ 1 2))
3
repl:3:8: parse error: unexpected closing delimiter )
```

第二行提示字元多了一個 `(`，意思是「還有一個左括號沒關」。補上右括號，它才開始算。第三行多打一個 `)`，前面的 `(+ 1 2)` 照樣算出 3，多出來那個右括號被報錯。

在檔案裡，少了右括號就整段不跑。用 `eval-string`（把一段文字當程式碼跑）加 `protect`（接住錯誤、不讓程式停掉）實測：

```janet
(protect (eval-string "(+ 1 2"))    # => (false "unexpected end of source, ( opened at line 1, column 1")
(protect (eval-string "(+ 1 2))"))  # => (false "unexpected closing delimiter )")
```

第一個是「檔案讀完了，第 1 行第 1 欄開的 `(` 還沒關」。第二個是「多了一個右括號」。錯誤訊息會告訴你那個括號從哪裡開始，順著行號欄號去找。

## 你會踩的坑

⚠ 你會以為可以照數學習慣寫 `(1 + 2)`。
其實 Janet 會把第一個位置的 `1` 當成動作，然後報一個看不太懂的錯：

```janet
(protect (eval-string "(1 + 2)"))   # => (false "1 expects 1 argument, got 2")
```

因為括號裡第一個位置永遠是動作，沒有例外。數字放在動作位置有特別的用途（單元 3 講），所以錯誤訊息才長這樣。記住：動作一定寫最前面。

⚠ 你會以為縮排對了程式就對了。
其實 Janet 完全不看縮排，只數括號。
因為換行和空白對它都一樣，縮排漂亮但少一個 `)`，照樣跑不動。
