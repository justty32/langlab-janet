# 3-1 · 四個容器

前兩個單元你存的都是單一個值：一個數字、一個字串。這課講「一次裝很多個值」的東西。Janet 只有四種，學完你看到 `[`、`@[`、`{`、`@{` 就知道手上拿的是哪一種、能不能改。

## 這是什麼、為什麼

裝很多個值的東西，程式語言通常叫「容器」。Python 有 list 和 dict，JS 有陣列和物件。Janet 也是這兩類，但每一類各分「能改」和「不能改」兩個版本，所以總共四個：

| 長相 | 名字 | 白話 |
|------|------|------|
| `[1 2 3]` | tuple（一串固定的值，放進去就不能改） | 一串固定的 |
| `@[1 2 3]` | array（一串可以改的值） | 一串可改的 |
| `{:a 1}` | struct（一組固定的鍵值對，放進去就不能改） | 一組鍵值固定的 |
| `@{:a 1}` | table（一組可以改的鍵值對） | 一組鍵值可改的 |

「一串」就是照順序排的一排東西，用位置找。「一組鍵值對」就是用名字找東西，像通訊錄用人名找電話。

規則只有一條：**`@` 開頭的是可變的**。可變（mutable）的意思是放進去以後還能加、還能換；不可變（immutable）的意思是放進去以後就定了，想改只能重新做一個。`@` 在整個 Janet 都是這個意思，後面碰到 `@""`（可改的字串）也一樣。

為什麼要分兩套？因為程式裡大部分資料其實不需要改：設定值、對照表、函式回傳的一筆結果。用不可變的版本，就不用擔心誰在你背後偷改。真的要一直往裡面加東西（例如一筆一筆收集結果），才用 `@` 那個版本。

## 動手

### 建出來、看型別

```janet
(def 一串固定的 [1 2 3])
(def 一串可改的 @[1 2 3])
(def 一組固定的 {:name "小明" :age 30})
(def 一組可改的 @{:name "小明" :age 30})
(type 一串固定的)   # => :tuple
(type 一串可改的)   # => :array
(type 一組固定的)   # => :struct
(type 一組可改的)   # => :table
```

`type` 會告訴你手上是哪一種。鍵值對的鍵這裡用 keyword（1-3 講過的 `:name` 那種），這是 Janet 最常見的寫法，字串、數字也能當鍵。

### 印出來長什麼樣

```janet
(pp [1 2 3])
# 印出：(1 2 3)
(pp @[1 2 3])
# 印出：@[1 2 3]
(pp {:a 1})
# 印出：{:a 1}
(pp @{:a 1})
# 印出：@{:a 1}
```

⚠ tuple 印出來是小括號 `(1 2 3)`，但你寫的時候要用中括號 `[1 2 3]`。因為小括號在 Janet 是「呼叫」（1-2 講過），`(1 2 3)` 會被當成「拿 1 當函式來呼叫」。印出來用小括號只是 Janet 的顯示習慣，記住它就好。

### 用函式建

字面寫法最常用，但值是算出來的時候，四個容器各有同名函式：

```janet
(tuple 1 (+ 1 1) 3)   # => (1 2 3)
(array 1 2 3)         # => @[1 2 3]
(struct :a 1)         # => {:a 1}
(table :a 1)          # => @{:a 1}
```

`struct` 和 `table` 的參數是「鍵 值 鍵 值」輪流排，要幾對就接幾對。

### 拿一個出來、數有幾個

最簡單的取法是把容器當函式呼叫。一串的給位置，位置從 0 數起；一組的給鍵：

```janet
(def 水果 ["apple" "banana" "guava"])
(水果 0)   # => "apple"
(水果 2)   # => "guava"
(def 人 @{:name "小明" :age 30})
(人 :age)   # => 30
(length 水果)   # => 3
(length 人)     # => 2
```

`length` 四種都吃：一串的回有幾個值，一組的回有幾對。拿東西還有 `get`、`get-in` 等等更多寫法，下一課再講。

### 不可變的真的改不了

```janet
(def 可改 @[1 2 3])
(array/push 可改 4)   # => @[1 2 3 4]
可改   # => @[1 2 3 4]
(def 固定 [1 2 3])
(first (protect (array/push 固定 4)))   # => false
```

`array/push` 是在尾巴加一個值，它直接改 `可改` 本身，不是做一份新的。對 tuple 做同樣的事會直接報錯（`protect` 是把錯誤接住的包裝，7-1 會細講；這裡 `first` 拿出來的 `false` 就是「炸了」）。錯誤訊息會說 `expected array, got <tuple 0x...>`，翻成白話是「我要的是 array，你給我 tuple」。

## 你會踩的坑

⚠ 你會以為 `[1 2 3]` 跟 `@[1 2 3]` 只差一個符號、應該通用。其實是兩個不同型別，很多函式只收其中一種（`array/push` 只收 array）。因為 Janet 用型別來保證「不可變的東西真的不會被改」，不是靠約定。

⚠ 你會以為 `{:a 1}` 像 JS 的物件，之後可以隨手 `obj.b = 2`。其實 struct 是定死的，要能加鍵請一開始就寫 `@{:a 1}`。因為 struct 是給「固定資料」用的，設計上就是不讓你加。

⚠ 你會以為鍵值對會照你寫的順序排。其實 `(keys @{:a 1 :b 2 :c 3})` 印出來是 `@[:b :a :c]`，順序跟你寫的不一樣。因為 struct 和 table 是用鍵的雜湊值（hash，把鍵算成一個數字）來擺位置的，本來就沒有「第幾個」的概念。要順序就用 tuple 或 array。
