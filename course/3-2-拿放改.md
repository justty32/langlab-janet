# 3-2 · 拿、放、改

上一課認識了四個容器。這課講日常操作：從裡面拿一個值、放一個值進去、把某個值改掉、在尾巴加或拿掉。學完你就能用 Janet 處理一份清單或一張表。

## 這是什麼、為什麼

不管什麼語言，容器就是這三件事：拿（讀）、放（寫）、改（讀了再寫回去）。Janet 把這三件事做成幾個小函式，名字很短：`get` 拿、`put` 放、`update` 改。一串的和一組的用同一套函式，差別只在你給的是位置還是鍵。

兩件事先記住。第一，位置從 0 數起，第一個是 0、第二個是 1，跟 C／Python／JS 一樣。第二，拿不到的時候 Janet 通常回 `nil`（1-3 講過的「什麼都沒有」），不會報錯。這跟 Python 的 `KeyError`、JS 的 `undefined` 都不太一樣，後面會講它的好處和它的坑。

## 動手

### 拿：`get` 和「把容器當函式叫」

```janet
(def 分數 @[90 85 77])
(get 分數 0)   # => 90
(分數 1)       # => 85
(def 人 @{:name "Ann" :age 30})
(get 人 :name)   # => "Ann"
(人 :age)        # => 30
```

`(get 容器 鍵)` 和 `(容器 鍵)` 做的事一樣，第二種短，多數人寫第二種。四種容器都能這樣拿。

### 拿不到會怎樣

```janet
(def 分數 @[90 85 77])
(get 分數 10)   # => nil
(get 分數 -1)   # => nil
(def 人 @{:name "Ann"})
(get 人 :email)   # => nil
(get 人 :email "none")   # => "none"
```

超出範圍、鍵不存在，`get` 都回 `nil`。第三個參數是預設值：拿不到就給你這個。

⚠ Janet 沒有負索引。`(get 分數 -1)` 不是「最後一個」，是 `nil`。要最後一個用 `(last 分數)`。

### 一定要拿到：`in`

```janet
(def 分數 @[90 85 77])
(in 分數 1)   # => 85
(first (protect (in 分數 10)))   # => false
```

`in` 跟 `get` 差在拿不到時的反應：`get` 回 `nil`，`in` 直接報錯，訊息是 `expected integer key for array in range [0, 3), got 10`，白話是「這個 array 的合法位置是 0 到 2，你給 10」。你確定東西一定要在、不在就是 bug，用 `in`；不在是正常情況（例如選填欄位），用 `get`。

### 放：`put`

```janet
(def 人 @{:name "Ann"})
(put 人 :age 30)   # => @{:age 30 :name "Ann"}
(put 人 :age 31)   # => @{:age 31 :name "Ann"}
(def 分數 @[90 85 77])
(put 分數 0 100)   # => @[100 85 77]
(put 人 :age nil)   # => @{:name "Ann"}
```

`put` 直接改容器本身，然後把容器回給你（所以 `# =>` 顯示的是整個容器；鍵的順序跟你放的不同，3-1 講過為什麼）。鍵已經有就覆寫，沒有就新增。最後一行是刪除的寫法：把值放成 `nil` 等於把這個鍵拿掉。Janet 的容器裡不會存 `nil` 這個值，所以「值是 nil」和「沒這個鍵」是同一回事。

### 改：`update`

```janet
(def 人 @{:name "Ann" :age 30})
(update 人 :age inc)   # => @{:age 31 :name "Ann"}
(update 人 :age |(* $ 2))   # => @{:age 62 :name "Ann"}
```

「拿出來、算一下、放回去」太常見，所以有 `update`：第三個參數是一個函式，Janet 把舊值餵給它，把它回傳的值放回去。`inc` 是加一。`|(* $ 2)` 是「拿到的東西乘 2」的簡寫，6-2 會細講，這裡先當成一個小函式看。

### 尾巴加、尾巴拿：`array/push`、`array/pop`

```janet
(def 待辦 @[])
(array/push 待辦 "buy milk")
(array/push 待辦 "laundry")
(length 待辦)   # => 2
(array/pop 待辦)   # => "laundry"
(length 待辦)   # => 1
(array/pop @[])   # => nil
```

`array/push` 在尾巴加一個，`array/pop` 把尾巴那個拿掉並回給你。空的 array 去 pop 回 `nil`，不會報錯。這兩個只對 array 有用，名字前面的 `array/` 就是在提醒你。

### 多層的容器：`get-in`、`put-in`

```janet
(def 設定 @{:db @{:host "localhost" :port 5432}})
(get-in 設定 [:db :port])   # => 5432
(get-in 設定 [:db :user])   # => nil
(get-in 設定 [:cache :size])   # => nil
(put-in 設定 [:db :user] "admin")
(get-in 設定 [:db :user])   # => "admin"
```

容器裡面裝容器很常見（設定檔、JSON 都是）。`get-in` 給一串鍵，一層一層往下鑽；中途哪一層不存在就回 `nil`，不會炸。`put-in` 一樣一路鑽下去放，中間缺的層會自動幫你建 table。

## 你會踩的坑

⚠ 你會以為 `(get 設定 :db :port)` 是拿兩層。其實第三個參數是預設值，這句是「拿 `:db`，拿不到才回 `:port`」，拿得到就回整包 `:db`。因為 `get` 的簽名就是 `(get 容器 鍵 預設值)`，它只認一個鍵。把容器當函式叫也一樣只收一個鍵，`(設定 :db :port)` 會直接報錯「called with 2 arguments, possibly expected 1」。要鑽兩層寫 `get-in`。

⚠ 你會以為 `put` 到超出長度的位置會報錯。其實 `(put @[1 2 3] 5 9)` 會得到 `@[1 2 3 nil nil 9]`，中間自動補 `nil`。因為 array 會自動長大，`put` 只負責把那格填上。要在尾巴加東西用 `array/push`，不要自己算位置。

⚠ 你會以為 `get` 回 `nil` 是「找不到」，所以可以用它判斷鍵存不存在。其實鍵存在但值是 `false` 的話 `get` 也回假值。因為 `nil` 和 `false` 都是假（1-3）。要問「有沒有這個鍵」用 `(has-key? 表 鍵)`。

## 小練習

1. 建一個 `@{:count 0}`，用 `update` 讓 `:count` 加三次 1，最後印出它。
2. 建一個空 array，`push` 三個名字進去，再 `pop` 一個，印出剩下的長度。
3. 建一個兩層的 table `@{:user @{:name "Bob"}}`，用 `get-in` 拿名字，再用 `put-in` 加上 `:email`。
