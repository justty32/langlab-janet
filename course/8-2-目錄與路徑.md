# 8-2 · 目錄與路徑

上一課你學會讀寫一個檔案的內容。這課往外走一層：檔案在不在？多大？目錄裡有哪些東西？怎麼建目錄、刪檔案？還有一件很重要的事：路徑該怎麼組才不會出錯。

學完你能寫一支小工具，走過一個目錄，把裡面每個 `.txt` 的行數加起來。

## 這是什麼、為什麼

讀寫內容是「打開檔案之後」的事。但很多時候你得先問檔案系統（作業系統管檔案與目錄的那一層）幾個問題：這個檔存在嗎？它是檔案還是目錄？這個目錄底下有誰？

Janet 把這些操作放在 `os/` 開頭的函式裡：`os/stat` 查資訊、`os/dir` 列目錄、`os/mkdir` 建目錄、`os/rm` 刪東西。組路徑則交給 spork（Janet 官方的擴充函式庫）裡的 `spork/path`。

下面每段示範都在暫存目錄裡建東西、跑完自己清掉，不會弄髒你的專案。

## 動手：os/stat 查檔案資訊

`os/stat` 給它一個路徑，它回一個 table（可以改的鍵值字典），裝著這個檔案的各種資訊。檔案不存在就回 `nil`。

```janet
(def tmp (string (or (os/getenv "TMPDIR") "/tmp") "/janet-course-8-2"))
(os/mkdir tmp)
(def f (string tmp "/a.txt"))
(spit f "hello\n")

(sort (keys (os/stat f)))
# => @[:accessed :blocks :blocksize :changed :dev :gid :inode :int-permissions :mode :modified :nlink :permissions :rdev :size :uid]
(os/stat f :size)          # => 6
(os/stat f :mode)          # => :file
(os/stat tmp :mode)        # => :directory
(print (os/stat f :modified))
# 印出：一個很大的數字，是「1970 年到修改當下」過了幾秒

(os/rm f)
(os/rm tmp)
```

第二個參數給一個 keyword，就只拿那一項，不用整包拿回來再挑。最常用的三項是 `:size`（位元組數，`"hello\n"` 是 6 個）、`:mode`（`:file` 檔案、`:directory` 目錄、`:link` 捷徑）、`:modified`（最後修改時間）。

### 「存不存在」就用 os/stat

Janet 沒有 `file/exists?` 這種函式。標準寫法是看 `os/stat` 回不回 `nil`：

```janet
(os/stat "no-such-8-2.txt")          # => nil
(os/stat "no-such-8-2.txt" :size)    # => nil

(defn exists? [p] (truthy? (os/stat p)))
(defn dir? [p] (= :directory (os/stat p :mode)))
(exists? "no-such-8-2.txt")          # => false
(dir? (or (os/getenv "TMPDIR") "/tmp"))  # => true
```

`truthy?` 把「有值」變成 `true`、`nil` 變成 `false`，這樣 `exists?` 回的就是乾淨的布林值。

## 動手：建目錄、刪東西

`os/mkdir` 建一層目錄，成功回 `true`。目錄已經在了，它回 `false`，不會拋錯。所以「確保某個目錄存在」直接呼叫就好，不用先檢查。

`os/rm` 刪檔案，或刪空的目錄。

```janet
(def tmp (string (or (os/getenv "TMPDIR") "/tmp") "/janet-course-8-2"))
(os/mkdir tmp)                       # => true
(os/mkdir tmp)                       # => false
(os/mkdir (string tmp "/sub"))       # => true
(spit (string tmp "/sub/x.txt") "1")

(def r (protect (os/rm (string tmp "/sub"))))
(r 0)                                # => false
(print (r 1))
# 印出：Directory not empty: 後面接 sub 的完整路徑

(os/rm (string tmp "/sub/x.txt"))
(os/rm (string tmp "/sub"))
(os/rm tmp)
(os/stat tmp)                        # => nil
```

目錄裡還有東西時 `os/rm` 會拋錯，要先把裡面清空，由內往外刪。`protect`（把錯誤接住、包成 `[成功與否 結果]` 回來）在 7-1 教過。

## 動手：os/dir 列目錄

`os/dir` 回一個 array，裝著目錄底下每個項目的**名字**。

```janet
(def tmp (string (or (os/getenv "TMPDIR") "/tmp") "/janet-course-8-2"))
(os/mkdir tmp)
(spit (string tmp "/b.txt") "b")
(spit (string tmp "/a.txt") "a")
(os/mkdir (string tmp "/sub"))
(spit (string tmp "/sub/deep.txt") "d")

(sort (os/dir tmp))                  # => @["a.txt" "b.txt" "sub"]

(os/rm (string tmp "/sub/deep.txt"))
(os/rm (string tmp "/sub"))
(os/rm (string tmp "/a.txt"))
(os/rm (string tmp "/b.txt"))
(os/rm tmp)
```

注意三件事。回來的只有名字，沒有前面的目錄，要讀檔得自己把目錄接回去。它不往下鑽，`sub` 裡的 `deep.txt` 沒出現。順序由作業系統決定，不保證照字母排，所以上面先 `sort` 再看。

## 動手：os/cwd 與 os/which

```janet
(print (os/cwd))
# 印出：你現在所在的目錄，例如 /home/you/janet-lab
(print (os/which))
# 印出：linux（Linux 上實測；別的系統會不同）
```

`os/cwd` 是目前工作目錄（相對路徑從哪裡算起）。`os/which` 告訴你跑在哪個作業系統上，回的是 keyword，會是 `:linux`、`:macos`、`:windows` 之類，要寫「Windows 上改走另一條路」時用得到。
