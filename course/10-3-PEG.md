# 10-3 · PEG：用規則拆字串

要從 `"port=8080"` 這種字串裡把名字跟數字拆出來，別的語言你會寫正則表達式。Janet 內建的是 PEG（Parsing Expression Grammar，一套用小積木拼出來的比對規則）。這課從「比對一個數字」開始，一步一步加到解析整份 `key=value` 設定檔。

## 這是什麼、為什麼

正則是一串密碼般的符號（`^(\w+)=(\d+)$`），寫得出來、一個月後讀不懂，而且解不了巢狀結構。PEG 做同一件事，但規則是用 Janet 的資料寫的：一個 tuple 就是一條規則，規則裡可以放規則，還可以取名字互相引用。所以它可讀、可組合、可以直接在比對的同時把字串轉成數字。

用法只有一個函式：`(peg/match 規則 字串)`。從字串開頭開始比，成功回傳一個 array（裡面是你要它抓的東西），失敗回 `nil`。

規則要用 `~` 引起來。`~` 的意思是「這個 tuple 是資料，不要當程式碼執行」，細節下一課巨集會講，這課先記住規則前面加 `~`。

## 動手：從一個數字開始

```janet
(peg/match "42" "42")   # => @[]
(peg/match "42" "43")   # => nil
(peg/match ~(range "09") "7")   # => @[]
(peg/match ~(range "09") "x")   # => nil
```

字串本身就是規則，意思是「剛好是這幾個字」。`(range "09")` 是「0 到 9 之間的一個字元」。成功但回 `@[]` 是因為你還沒叫它抓任何東西，空 array 只代表「比對過了」。

```janet
(peg/match ~(some (range "09")) "123abc")   # => @[]
(peg/match ~(<- (some (range "09"))) "123abc")   # => @["123"]
(peg/match ~(* (<- (some (range "09"))) -1) "123abc")   # => nil
(peg/match ~(* (<- (some (range "09"))) -1) "123")   # => @["123"]
```

`some` 是「一個或多個」。`<-` 是抓取（capture，把比對到的那段字串放進結果 array）。注意第一行比到 `123` 就算成功了，後面的 `abc` 沒人管；要求「整串都要符合」得用 `*`（依序，全部都要過）接一個 `-1`（到字串結尾）。

抓到的是字串，想直接變數字用 `/`：抓到的東西丟給後面的函式，函式回什麼就放什麼。逗號是「這裡放真的 Janet 函式」：

```janet
(peg/match ~(/ (<- (some (range "09"))) ,scan-number) "123")   # => @[123]
```

## 動手：拼成 key=value

```janet
(def word ~(<- (some (range "az"))))
(def num ~(/ (<- (some (range "09"))) ,scan-number))
(peg/match ~(* ,word "=" ,num -1) "port=8080")   # => @["port" 8080]
(peg/match ~(* ,word "=" ,num -1) "port=abc")   # => nil
```

規則是資料，所以可以 `def` 起來再用逗號塞進大規則裡。規則長了就改用具名文法：一個 struct，key 是規則名，`:main` 是入口，規則之間用名字互相引用：

```janet
(def kv ~{:key (<- (some (+ (range "az") "_")))
          :num (/ (<- (some (range "09"))) ,scan-number)
          :main (* :key "=" :num -1)})
(peg/match kv "max_conn=10")   # => @["max_conn" 10]
```

`+` 是「擇一」，由左到右試，第一個成功的算數。這裡 key 允許小寫字母或底線。

整份多行設定檔，每行一對，用 `group` 把每對包成自己的 array，最後 `from-pairs` 變 table：

```janet
(def lines ~{:key (<- (some (+ (range "az") "_")))
             :val (<- (some (if-not "\n" 1)))
             :pair (group (* :key "=" :val))
             :main (* (some (* :pair (? "\n"))) -1)})
(peg/match lines "host=example.com\nport=8080")   # => @[@["host" "example.com"] @["port" "8080"]]
(from-pairs (peg/match lines "host=example.com\nport=8080"))   # => @{"host" "example.com" "port" "8080"}
```

`1` 是「任何一個字元」，`(if-not "\n" 1)` 是「不是換行的任何字元」，`(? x)` 是「有沒有都行」。

## 常用積木

| 寫法 | 意思 |
|------|------|
| `"abc"`、`1`、`-1` | 剛好這串字、任一字元、字串結尾 |
| `(range "az" "AZ")`、`(set "aeiou")` | 範圍內一字元、集合中一字元 |
| `(* a b)`、`(+ a b)` | 依序全過、擇一 |
| `(some p)`、`(any p)`、`(? p)` | 一或多、零或多、零或一 |
| `(<- p)`、`(/ p f)`、`(group p)` | 抓字串、抓了轉換、抓了打包 |
| `(to p)`、`(if-not p q)` | 一直吃到 p 之前、不是 p 才吃 q |

除了 `peg/match` 還有三個：找位置、找全部位置、全部取代。

```janet
(peg/find ~(some (range "09")) "abc123")   # => 3
(peg/find-all "a" "banana")   # => @[1 3 5]
(string (peg/replace-all ~(some (range "09")) "#" "a1b22c333"))   # => "a#b#c#"
```

`peg/replace-all` 回的是 buffer，要字串就包一層 `string`。

## 你會踩的坑

⚠ 你會以為比對成功會回 `true`，失敗回 `false`。其實是成功回 array（可能是空的 `@[]`），失敗回 `nil`。因為結果 array 裝的是抓到的東西，沒抓就是空的，而空 array 在 Janet 是真值。判斷成敗用 `(nil? 結果)`。

⚠ 你會以為忘了 `~` 頂多比不到。其實是直接炸 `bad slot #0, expected number, got "09"`。因為沒有 `~` 的 `(range "09")` 就是呼叫 Janet 內建的 `range` 函式（它要的是數字），根本沒走到 PEG。

⚠ 你會以為用 `'` 引規則跟 `~` 一樣。其實是逗號不會挖洞，`,scan-number` 會被當成兩個字面的 symbol 塞進結果。因為 `'` 是純引用、什麼都不執行；只有 `~` 允許逗號把函式放進去。規則裡有逗號一律用 `~`。

⚠ 你會以為 `(+ "ab" "abc")` 會挑最長的那個。其實是 `"ab"` 先成功就結束，後面的 `c` 剩著。因為 `+` 是有序選擇、不回頭。長的、具體的放前面。
