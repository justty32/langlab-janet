# 6-1b · 函式與參數（續）

接 [6-1](6-1-函式與參數.md)。這篇講用名字指定的參數、函式的說明文字，然後是這課的坑與練習。

## 動手：用名字指定的 `&named`

情境：連線設定有主機、埠號、逾時，呼叫的人常常只想改其中一個。照位置傳，第三個要給就得先給第二個。Python 用關鍵字引數解決，Janet 用 `&named`：它後面的參數呼叫時要寫成 `:名字 值`，順序隨便，沒給的是 `nil`：

```janet
(defn 連線 [主機 &named port timeout] [主機 port timeout])
(連線 "example.com" :port 80)                # => ("example.com" 80 nil)
(連線 "example.com" :timeout 5 :port 443)    # => ("example.com" 443 5)
(連線 "example.com")                         # => ("example.com" nil nil)
```

`:port` 是 keyword（冒號開頭、代表自己的名字），在這裡當「標籤」用，後面跟著的才是值。`&named` 的每個參數各自變成一個變數，本體裡直接用 `port`、`timeout`。

還有一個近親 `&keys`，把所有 `:名字 值` 收成一個 struct（不能改的字典）。你不打算自己用、只想原封不動轉手給下一個函式時才用它：

```janet
(defn 轉手 [x &keys 其他] [x 其他])
(轉手 1 :port 80 :host "h")   # => (1 {:host "h" :port 80})
```

## 動手：docstring

在參數表前面放一個字串，那就是 docstring（函式的說明文字）。2-3 教過的 `(doc 名字)` 會把它印出來，而且 Janet 會自動把呼叫長相接在最前面：

```janet
(defn 加一 "把數字加一。" [x] (+ x 1))
(doc 加一)
# 印出：
#     function
#     eval on line 1, column 1
#
#     (加一 x)
#
#     把數字加一。
```

要寫的函式只在檔案內部用、不想被 `import` 的人看到，就把 `defn` 換成 `defn-`，其他寫法一樣。這在單元 9 拆檔時會用到。

## 你會踩的坑

⚠ `default` 補的是 `nil`，不是「沒傳」。你會以為只有省略參數時才會被補預設值。其實呼叫的人明確傳 `nil` 也會被補成預設值。因為 `default` 就只是一句「這變數是 `nil` 就設成某值」，它分不出 `nil` 是省略來的還是傳進來的：

```janet
(defn 等待 [工作 &opt 秒數] (default 秒數 30) [工作 秒數])
(等待 :download nil)   # => (:download 30)
```

⚠ 引數個數錯是編譯期錯誤。你會以為呼叫時少給參數會像 Python 一樣在跑到那行時炸，用 `try` 或 `protect` 接得住。其實 Janet 在編譯那個呼叫的當下就擋下來，錯誤訊息是 `compile error`，`protect` 包在外面也沒用。因為 `defn` 定義出來的函式，編譯器知道它要幾個參數，呼叫寫死了幾個引數它就直接比對。跑一下這行：

```sh
janet -e '(defn a [x &opt y] [x y]) (protect (a))'
# error: <function a> expects at least 1 argument, got 0
```

只有引數個數要到執行時才知道的呼叫（像 `apply` 把一個 tuple 攤開當引數）才會變成執行期錯誤，這時 `protect` 就接得住：

```janet
(defn a [x &opt y] [x y])
(protect (apply a []))        # => (false "<function a> called with 0 arguments, expected 2")
(protect (apply a [1 2 3]))   # => (false "<function a> called with 3 arguments, expected 2")
```

順帶一提那句 `expected 2`：`y` 明明可以省，訊息卻寫 2。它報的是最多能收幾個，別讀成「非給兩個不可」。

## 小練習

1. 寫 `(問候 名字 &opt 語言)`，`語言` 沒給就當 `:zh`；`:zh` 回 `"你好，名字"`，`:en` 回 `"Hello, 名字"`。
2. 寫 `(最大 第一個 & 其餘)`，至少要一個數字，回傳所有數字裡最大的（提示：`max` 也收不定個數，可以 `apply`）。
3. 寫 `(做便當 主菜 &named 飯量 辣度)`，`飯量` 沒給就 `:normal`、`辣度` 沒給就 0，回傳一個 struct `{:main 主菜 :rice 飯量 :spicy 辣度}`。

答案在 `examples/course/6-1.janet` 最後。
