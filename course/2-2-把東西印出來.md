# 2-2 · 把東西印出來

寫程式的第一件事，就是把東西印到螢幕上看看對不對。Janet 印東西的函式有好幾個，差別只在三件事：要不要換行、要不要格式化、容器（array 或 table 這類裝很多值的東西）印出來長什麼樣。這課學完，你會知道什麼時候該用哪一個，也會避開兩個幾乎每個人都踩過的坑。

## 這是什麼、為什麼

在 C 你用 `printf`，在 Python 用 `print`，在 JS 用 `console.log`。Janet 把這幾種用途拆成不同的函式，名字都很短。先看一張對照表，後面再一個一個講。

| 函式 | 有格式字串？ | 尾端換行？ | 印容器時 |
|------|------|------|------|
| `print` | 沒有 | 有 | 只印位址 |
| `prin` | 沒有 | 沒有 | 只印位址 |
| `printf` | 有 | 有 | 看動詞 |
| `prinf` | 有 | 沒有 | 看動詞 |
| `pp` | 固定用 `%p` | 有 | 印內容 |

記法：名字裡有 t 的（prin**t**、prin**t**f）會換行，沒有 t 的（prin、prinf）不會。

## 動手：print 與 prin

`print` 把所有參數逐個接起來印出，最後補一個換行。參數之間不加空格，keyword 印出來沒有冒號，nil 印出來是空的。

```janet
(print "x" "y" 1 nil :k)
# 印出：xy1k
```

`prin` 完全一樣，只是尾端不換行。要自己控制什麼時候換行就用它，最後呼叫一次不帶參數的 `(print)` 補換行。

```janet
(prin "a")
(prin "b")
(print)
# 印出：ab
```

## 動手：printf 與 prinf

`printf` 吃一個格式字串（裡面用 % 開頭的記號當佔位，後面的參數會依序填進去），跟 C 的 printf 很像。這些 % 開頭的記號叫動詞（決定那個位置要把值轉成什麼樣子的代號），常用的有 `%d` 整數、`%f` 浮點數、`%.2f` 小數兩位、`%x` 十六進位、`%5d` 靠右補到五格、`%-5d` 靠左補到五格。

```janet
(printf "%d %f %x %.2f %5d|%-5d|" 42 3.5 255 3.14159 7 7)
# 印出：42 3.500000 ff 3.14     7|7    |
```

`prinf` 是不換行的版本。注意 `printf` 自己會換行，所以格式字串結尾不用再寫 `\n`，寫了會多一行空白。

兩個動詞比 C 嚴格。`%d` 給小數會直接報錯，`%s` 只收字串、symbol、keyword、buffer，給數字也報錯。要印數字就用 `%d`、`%f`，或後面會講的 `%j`。

```janet
(protect (printf "%d" 3.7))   # => (false "can not convert number 3.7 to 64 bit signed integer")
(protect (printf "%s" 42))   # => (false "bad slot #1, expected string, symbol, keyword or buffer, got 42")
```

## 動手：string/format 與 string

`string/format` 跟 `printf` 用一樣的格式字串，差別是它不印，而是把組好的字串回傳給你。要先組字串再拿去做別的事（存檔、丟給另一個函式）就用它。

```janet
(string/format "%s scored %.2f" "Al" 3.14159)   # => "Al scored 3.14"
```

不需要格式的話，`string` 更省事，什麼型別都能直接接起來。

```janet
(string "id=" 42 " ok=" true)   # => "id=42 ok=true"
```

字串本身還有很多可講的，第 4 單元再細說。

## 動手：%s、%q、%j 差在哪

這是本課的重點。`%s` 是「給人看」的原樣，字串印出來就是字本身。`%q` 和 `%j` 是「Janet 自己看得懂的寫法」，字串會帶引號，array 會帶 `@[`，就像你在原始碼裡寫它的樣子。

```janet
(string/format "%s" "hi")     # => "hi"
(string/format "%q" "hi")     # => "\"hi\""
(string/format "%j" @[1 2])   # => "@[1 2]"
(string/format "%j" 42)       # => "42"
```

第二行回傳的字串裡真的含有引號，所以 `%j` 格式看起來是 `"\"hi\""`。

`%q` 和 `%j` 都印在一行，差別在碰到「Janet 讀不回去的東西」時怎麼辦，例如函式。`%q` 照樣印，用 `<cfunction print>` 這種樣子帶過；`%j` 堅持印出來的東西一定要能讀回去，所以直接報錯。還有一個 `%p`，是漂亮排版，內容長時會縮排換行，給人讀巢狀資料用。

```janet
(string/format "%q" @[1 print])   # => "@[1 <cfunction print>]"
(protect (string/format "%j" @[1 print]))   # => (false "could not print to jdn format")
```

⚠ `%j` 的 j 不是 JSON。它印的是 Janet 語法，keyword 有冒號、array 有 `@`，JSON 讀不了。真正的 JSON 在 4-3。

## 動手：pp

`pp` 是 pretty print，等於 `(printf "%p" x)`。要看一個容器裡裝了什麼，這是最省事的方法。

```janet
(pp @[1 2 3])
# 印出：@[1 2 3]
(pp @{:a 1})
# 印出：@{:a 1}
```

順帶兩句。`(print)` 不帶參數就只印一個換行。前面加 x 的版本要多給一個輸出目標，`(xprint stderr "oops")` 會印到錯誤輸出而不是標準輸出。

## 你會踩的坑

⚠ 用 print 印 array，看到的是位址。

你會以為 `(print @[1 2 3])` 會印出 `@[1 2 3]`。其實印出來是型別名加一串記憶體位址，像 `<array 0x5652605679A0>`。因為 `print` 對每個參數只做一件事，就是「轉成字串」，而容器轉成字串的結果就長那樣，內容不在裡面。要看內容，用 `pp`，或在 `printf`／`string/format` 裡用 `%q`、`%j`。

```janet
(print @[1 2 3])
# 印出：<array 0x...>（位址每次不同）
(pp @[1 2 3])
# 印出：@[1 2 3]
```

⚠ 中文在 `%q`、`%j`、`pp` 底下變成一串 `\xE4`。

你會以為 `(pp "你好")` 會印出帶引號的中文。其實印出來是 `"\xE4\xBD\xA0\xE5\xA5\xBD"`，每個 byte 一段。因為這幾個動詞的承諾是「印出來的東西 Janet 要能原封不動讀回去」，為了這個承諾，非 ASCII 的 byte 一律改寫成逃逸序列。這不是壞掉。給人看的輸出一律用 `print` 或 `%s`。

```janet
(print (string/format "%j" "你好"))
# 印出："\xE4\xBD\xA0\xE5\xA5\xBD"
(print "你好")
# 印出：你好
```
