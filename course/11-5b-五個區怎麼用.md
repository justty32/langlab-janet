# 11-5b · 五個區怎麼用

接 [11-5](11-5-接下來去哪.md)。這篇一區一區講：它是什麼、什麼時候去。最後給三個具體的下一步。

## 動手：docs/，查資料

`docs/` 有九十多篇筆記，每篇一個主題。它跟這門課講的是同一批東西，差在寫法：課程一次講一件事，docs 一篇塞滿一個主題的所有細節和 ⚠。沒上過課直接讀會被 ⚠ 淹沒；上完課再去看，每個 ⚠ 你都知道在講什麼。

從目錄 [docs/README.md](../docs/README.md) 進去。跟課程接得上的幾組：

- 32～40 是「寫熟之後才會踩到」的語言細節。例如 [32 條件與模式比對](../docs/32-條件與模式比對.md) 把 6-4 的 `match` 講得更完整，[34 讀錯誤訊息](../docs/34-讀錯誤訊息.md) 接 7-3。
- 43～46 是從 C／Lua／Go／Python 過來的逐條對照，入口是 [從別的語言過來 · 索引](../docs/從別的語言過來-索引.md)。你熟哪個語言就讀哪組，會發現課程裡某些「怪」其實有對應。
- 07～17 是主題篇：REPL、巨集、fiber、PEG、ev、HTTP。單元 10 每課結尾都有指過去。

腦中想的是「我要做 X」而不是「這屬於哪一章」時，看 [怎麼做 X](../docs/怎麼做-X.md)，它按任務排，每列給你該讀哪篇、該跑哪支、該抄哪段。

## 動手：reference/，查全

docs 講觀念，只挑重要的函式講。[reference/](../reference/README.md) 相反，它回答「這個領域到底有哪些函式」。例如字串到底有哪些 `string/*`，這裡一份清單全列，每個附簽名和一句說明。

Janet 內建的部分是對著 `root-env`（Janet 啟動時所有內建名字所在的那張表）逐一核過的，不會漏。spork 是第三方庫，會改版，這裡只收常用的，要最全的去官方。

## 動手：cheatsheets/，速查

[cheatsheets/](../cheatsheets/README.md) 是七頁速查表，每頁一眼掃完：核心、資料與 IO、PEG、並行、C 互通、env 與符號、地雷。忘了寫法時比翻 docs 快。

其中 [cheatsheets/地雷.md](../cheatsheets/地雷.md) 最值得收藏。程式的行為讓你想不通時先去那頁找，所有實測過的坑都集中在那裡，每條標了是 docs 哪一篇。

## 動手：snippets/，抄

[snippets/](../snippets/README.md) 回答「我要做 X，抄哪段」：重試加逾時、讀設定檔、印中文對齊的表格、正確讀寫 CSV、並行跑一批工作。每支獨立、可以直接跑，跑法寫在檔頭。

做完 todo 之後可以看 `cli-skeleton.janet`，它是一支真工具的完整接線：參數、設定、日誌、錯誤、exit code。你會發現它跟 todo 的骨架很像，多了日誌與設定檔那幾層。

## 動手：exercises/，練

[exercises/](../exercises/README.md) 的題目專挑 ⚠ 陷阱。每份是一串待補的函式，跑起來告訴你第幾題錯、預期什麼、你給了什麼，還附一條提示指向對應的 docs 篇：

```sh
janet exercises/01-資料與比較.janet
# ✘ 第 1 題：內容相同的 array
#     預期 (true false)
#     實得 (:還沒寫 :還沒寫)
#     提示 docs/02：可變容器的 = 比身分，要比內容用 deep=
# （中略）
# 過 0 題，錯 6 題
```

第 1 題考的就是 3-3 的「可變容器的 `=` 比身分」。解答在 `exercises/solutions/`，先自己錯一次再看。

## 動手：想做 AI agent

docs/47 系列七篇（[47](../docs/47-llm-api-是什麼.md)～47g）從零教你寫一個會用工具的 AI agent。全部離線可跑：範例自己在同一個行程裡起一台假伺服器，不用金鑰、不用網路。

47 開頭第一句就把核心講完了：呼叫 LLM API 就是送一個 HTTP POST，你送一份 JSON 過去，對方回一份 JSON。沒有連線、沒有 session，每次都要把整段對話重送一遍。然後 [47d](../docs/47d-自己寫-agent-loop.md) 講 agent 本體，它就是一個 while 迴圈：問模型，模型要用工具就去執行，把結果餵回去，再問，直到它不再要工具為止。

學完想直接用，成品在 [modules/agent/](../modules/agent/README.md)。

## 你會踩的坑

⚠ 你會以為 docs 是課程的「進階版」，應該從 00 讀到 47。其實 docs 除了 00～06 以外每篇都是獨立的，沒有順序。因為它是查資料用的：遇到問題時從目錄或「怎麼做 X」跳進某一篇，讀完就回去寫程式。

⚠ 你會以為 exercises 跑完 exit 0 就代表全對。其實全錯也是 exit 0。因為它把「第幾題錯」印給人看，沒有拿 exit code 當結果；要看最後一行是不是「✓ 全部通過」。
