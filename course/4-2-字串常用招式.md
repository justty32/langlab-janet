# 4-2 · 字串常用招式

這課是一份工具箱：切、接、找、換、去空白、看開頭結尾、對齊排版。學完你能把一行 `"10, 20, 30"` 拆開、算完、再拼回去。最後講一件 Janet 特有的事：`length` 數的是 byte，一個中文字算三個。

## 這是什麼、為什麼

字串處理的函式全部姓 `string/`，像 `string/split`、`string/trim`。名字跟其他語言差不多，但參數順序有一條 Janet 自己的規矩：要找的東西放前面，被處理的字串放最後。所以是 `(string/split "," "a,b,c")`，不是 Python 那個 `"a,b,c".split(",")` 的順序。這條規矩到單元 6 講 `->>` 時會看到好處，現在先記住。

## 動手

### 切開、接回

```janet
(string/split "," "a,b,c")   # => @["a" "b" "c"]
(string/split "," "a,,c")   # => @["a" "" "c"]
(string/join @["a" "b" "c"] ", ")   # => "a, b, c"
```

`split` 回一個 array（3-1 的可變陣列），連續兩個逗號中間會給你空字串。`join` 反過來：陣列在前、接合用的字串在後。

`join` 只收文字，數字要先變字串：

```janet
(protect (string/join [1 2] "-"))   # => (false "item 0 of parts is not a byte sequence, got 1")
(string/join (map string [1 2 3]) "-")   # => "1-2-3"
```

`map` 把 `string` 套到每個元素上（6-2 細講），先當成「全部轉成字串」看。

### 找、換

```janet
(string/find "lo" "hello")   # => 3
(string/find "z" "hello")   # => nil
(string/replace "a" "X" "banana")   # => "bXnana"
(string/replace-all "a" "X" "banana")   # => "bXnXnX"
```

`find` 回第一次出現的位置（從 0 數），找不到回 nil，所以直接放進 `if` 就能判斷「有沒有包含」。`replace` 只換第一個，全換要 `replace-all`。

### 去空白、看頭尾

```janet
(string/trim "  hi \n")   # => "hi"
(string/triml " hi ")   # => "hi "
(string/has-prefix? "http://" "http://x.com")   # => true
(string/has-suffix? ".janet" "main.janet")   # => true
```

`trim` 兩邊都去，`triml`／`trimr` 只去左或右。`has-prefix?` 也是「要找的放前面」：先寫開頭，再寫整串。

### 切片、大小寫、重複

```janet
(string/slice "hello" 1 3)   # => "el"
(string/slice "hello" 2)   # => "llo"
(string/slice "hello" 0 -2)   # => "hell"
(string/ascii-upper "abc")   # => "ABC"
(string/repeat "ab" 3)   # => "ababab"
```

`slice` 含頭不含尾。負數從尾巴數，但 -1 代表「最尾端」（最後一個字的後面），所以 `-2` 才是切掉一個字，這點跟 Python 不同。`ascii-upper` 名字裡的 ascii 是誠實的：它只動英文字母。

### 對齊排版

```janet
(string/format "%-6s|%2d" "apple" 3)   # => "apple | 3"
(string/format "%5.2f" 3.14159)   # => " 3.14"
(string/format "%d%%" 50)   # => "50%"
```

跟 C 的 printf 一樣：數字是寬度，`-` 靠左，`.2` 小數兩位，`%%` 印一個百分號。印表格對齊就靠這個。

### 字串變數字

```janet
(scan-number "42")   # => 42
(scan-number "3.5")   # => 3.5
(scan-number "abc")   # => nil
(protect (+ 1 "2"))   # => (false "could not find method :+ for 1 or :r+ for \"2\"")
```

`split` 出來的都是字串，要算數得先 `scan-number`。它不拋錯，不是數字就回 nil，方便你先檢查。

### 串起來用

```janet
(def line "  10, 20, 30  ")
(def parts (string/split "," (string/trim line)))   # => @["10" " 20" " 30"]
(def nums (map scan-number (map string/trim parts)))   # => @[10 20 30]
(sum nums)   # => 60
```

先去外圍空白、切開、每段再去空白、轉數字、加總。真實的資料處理大多就是這幾步的排列組合。

## 你會踩的坑

⚠ 一個中文字不是一格。
你會以為 `(length "你好")` 是 2。其實是 6。因為 Janet 的字串是一串 byte（位元組），`length` 數的是 byte，中文在 UTF-8 裡一個字佔三個 byte。

```janet
(length "hello")   # => 5
(length "你好")   # => 6
(string/bytes "你")   # => (228 189 160)
(get "hello" 0)   # => 104
```

`string/bytes` 把那三個 byte 攤開給你看。用索引取字串的一格，拿到的也是 byte 的數值（104 是 h 的 ASCII 碼），不是 `"h"`。

⚠ 切在字的中間會切壞。
你會以為 `(string/slice "你好" 0 1)` 拿到 `"你"`。其實拿到三分之一個字，印出來是亂碼。因為 slice 也按 byte 切，要 `(string/slice "你好" 0 3)` 才是完整的一個字。`string/reverse` 同理，中文一反就碎。`split`、`find`、`replace` 這些拿整段去比對的招式不受影響，用中文當分隔符沒問題。

```janet
(print (string/slice "你好" 0 3))
# 印出：你
(string/find "好" "你好")   # => 3
```

要按「字」處理中文，走 PEG（10-3）或 [snippets/utf8-strings.janet](../snippets/utf8-strings.janet)。

⚠ 參數順序反了不會報錯。
你會以為 `(string/split "a,b,c" ",")` 會切。其實回 `@[","]`。因為 Janet 把第一個參數當分隔符、第二個當被切的字串，你反過來寫，它就拿 `"a,b,c"` 去切 `","`，切不到，整串原樣回給你。結果怪怪的又沒報錯時，先看順序。

## 小練習

1. 把 `"the quick fox"` 每個字改成大寫再用空格接回去，得到 `"THE QUICK FOX"`。
2. 判斷 `"main.janet"` 是不是以 `.janet` 結尾，是就印 `是 Janet 檔`。
3. 把 `"甲、乙、丙"` 用 `、` 切開，印出有幾項（答案是 3，不是 6）。
