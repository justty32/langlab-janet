## 展開巨集（3 個）

| 函式 | 簽名 | 說明 |
|------|------|------|
| `macex1` | `(macex1 x &opt on-binding)` | 展開**一層**就停 |
| `macex` | `(macex x &opt on-binding)` | 一路展開到沒有巨集為止 |
| `gensym` | `(gensym)` | 回一個全執行期唯一的 symbol，巨集裡用來防撞名 |

差別一眼就看得出來：

```janet
(macex1 ~(when 1 (when 2 3)))   # => (if 1 (do (when 2 3)))
(macex ~(when 1 (when 2 3)))    # => (if 1 (do (if 2 (do 3))))
(macex1 ~(-> 1 (+ 2)))          # => (+ 1 2)
(macex1 ~(def- x 1))            # => (def x :private 1)
```

⚠ 展開結果裡的函式是**值**不是名字，印出來長 `<function +>`、`<cfunction not>`：

```janet
(macex1 ~(toggle x))            # => (set x (<cfunction not> x))
```

`gensym` 回的 symbol 長 `_000013` 這樣（數字是執行期計數器，每次都不同），
所以 `(= (gensym) (gensym))` 一定是 `false`。要一次拿好幾個就用 `with-syms`。

## 求值（5 個）

| 函式 | 簽名 | 說明 |
|------|------|------|
| `eval` | `(eval form &opt env)` | 吃**已經剖析好的資料** |
| `eval-string` | `(eval-string str &opt env)` | 吃字串，內部就是剖析 ＋ `eval` |
| `compile` | `(compile ast &opt env source lints)` | 只編譯不執行，回一支**零參數函式** |
| `run-context` | `(run-context opts)` | 把「讀 → 剖析 → 編譯 → 執行 → 回報」整條線拆開給你換掉 |
| `dofile` | `(dofile path &named …)` | 跑一個檔，回它的 env table |

```janet
(eval ~(+ 1 2))                  # => 3
(eval-string "(+ 1 2)")          # => 3
((compile ~(+ 1 2)))             # => 3
```

⚠ `compile` **編不過時不丟錯**，而是回一個表：

```janet
(get (compile ~(fn)) :error)     # => "expected at least 1 argument to function literal"
```

裡面還有 `:line` `:column`。想在 `nil` 之外給定綁定，就自己做一個 env：

```janet
(eval-string "a" (let [e (make-env)] (put e 'a @{:value 42}) e))   # => 42
```

### `run-context` 的鉤子

`opts` 常用的幾個鍵：`:chunks`（回呼，把下一段原始碼推進 buffer，回 `nil` 代表結束）、
`:env`、`:source`、`:on-status`（每個 top-level form 求值完叫一次，拿到 fiber 與值）、
`:on-compile-error`、`:on-parse-error`、`:evaluator`、`:expander`、`:parser`、`:read`。
回傳的是 env。REPL、`dofile`、`require` 全都是它包出來的。

```janet
(def 收 @[]) (def xs @["(+ 1 2)" "(* 3 4)"]) (var i 0)
(run-context {:env (make-env) :source :demo
              :chunks (fn [buf _] (when (< i (length xs)) (buffer/push buf (xs i) "\n") (++ i)))
              :on-status (fn [f v] (array/push 收 v))})
(array/slice 收)                  # => @[3 12]
```

⚠ 不給 `:chunks` 時預設是 `getline`，會**去讀 stdin**——在測試或腳本裡忘了給就會卡住。

## 剖析（2 個）

| 函式 | 說明 |
|------|------|
| `parse` | `(parse str)` 只回**第一個**值 |
| `parse-all` | `(parse-all str)` 回一個 array，全部的值 |

```janet
(parse "(+ 1 2) (* 3 4)")        # => (+ 1 2)
(parse-all "(+ 1 2) (* 3 4)")    # => @[(+ 1 2) (* 3 4)]
```

⚠ `(parse "")` **丟錯** `no value`，不是回 `nil`。要邊讀邊剖析、要錯誤位置、
要做 REPL，用 [`parser/*`](巨集工具與求值b-parser-與-module.md)。

## 組譯（2 個）

| 函式 | 說明 |
|------|------|
| `disasm` | `(disasm func &opt field)` 把一支 Janet 函式拆回組語表示 |
| `asm` | `(asm assembly)` 反過來，從組語做出函式 |

`field` 可以只問一項：`:arity` `:min-arity` `:max-arity` `:vararg` `:structarg`
`:namedargs` `:bytecode` `:source` `:name` `:slotcount` `:symbolmap` `:constants`
`:sourcemap` `:environments` `:defs`。

```janet
(disasm (fn [x] x) :arity)             # => 1
(disasm (fn [x &opt y] x) :min-arity)  # => 1
(disasm (fn [x & r] x) :vararg)        # => true
(disasm (fn foo [x] x) :name)          # => "foo"
(disasm (fn [x] (+ x 1)) :slotcount)   # => 2
```

⚠ `disasm` **只吃 `:function`**，餵 cfunction（`(disasm gensym)`）會丟錯。

## 環境（2 個）

`(make-env &opt parent)` 做一張新的 env table，繼承 `parent` 的綁定但不污染它；
`(curenv &opt n)` 拿當下的 env，等同 `(fiber/getenv (fiber/current))`。
兩個都回 `:table`。env 的結構、`fiber/setenv`、動態變數見 [12b](../docs/12b-切換-env.md)。
