## 怎麼判定一個名字是哪一種

三行就問得出來：

```janet
(get root-env 'if)                      # => nil
(get (get root-env 'when) :macro)       # => true
(get (get root-env 'map) :macro)        # => nil
```

| 結果 | 是什麼 | 能不能當值傳 |
|------|--------|-------------|
| `root-env` 查不到 | **特殊形式**，編譯器直接展開 | **不能**。`(map if …)` 連編譯都過不了 |
| 查得到且 `:macro` 為真 | **巨集**，編譯期展開成別的程式碼 | **不能**。要傳得包一層 `(fn [x] (when x …))` |
| 查得到但 `:macro` 是 `nil` | **函式**（`:function` 或 `:cfunction`）| 可以 |

`(type (get root-env 'when))` 回 `:table`——那是**綁定的描述表**（`:value` `:doc` `:macro`…），
不是值本身；值要 `(get (get root-env 'when) :value)`。

## 特殊形式（13 個）

`root-env` 裡**一個都沒有**，但 `(doc if)` 查得到——它只印一行 `special form` 和
`(if ...)`，沒有參數說明，要看細節得去 <https://janet-lang.org/docs/specials.html>。

| 名 | 形狀 | 說明 |
|----|------|------|
| `def` | `(def name [meta…] value)` | 不可重新 `set` 的綁定；回傳 value |
| `var` | `(var name [meta…] value)` | 可以 `set` 的綁定 |
| `set` | `(set name value)` | 只能改 `var`；回傳新值 |
| `fn` | `(fn [name] [args] & body)` | 函式字面值 |
| `do` | `(do & body)` | 開一個新作用域，回最後一個值 |
| `upscope` | `(upscope & body)` | 跟 `do` 一樣依序求值，但 **`def` 會留在外層作用域** |
| `if` | `(if c 真 [假])` | 只有 `nil`／`false` 算假 |
| `while` | `(while c & body)` | 一律回 `nil` |
| `break` | `(break [值])` | 跳出最內層迴圈或函式 |
| `quote` | `(quote x)`，讀法 `'x` | 不求值，直接拿到那份資料 |
| `quasiquote` | `(quasiquote x)`，讀法 `~x` | 樣板引用，裡面可以挖洞 |
| `unquote` | `(unquote x)`，讀法 `,x` | 在 `quasiquote` 裡挖一個洞求值 |
| `splice` | `(splice x)`，讀法 `;x` | 把序列攤進外層的呼叫或資料構造 |

```janet
(do (def x 1) (upscope (def y 2)) (+ x y))   # => 3
(+ ;[1 2])                                   # => 3
[;[1 2] 3]                                   # => (1 2 3)
~(a ,(+ 1 2) b)                              # => (a 3 b)
~[1 ,;[2 3] 4]                               # => [1 2 3 4]
```

⚠ `unquote` 和 `splice` **離開對的位置就報錯**，不是靜默無效：

```janet
(protect (eval-string "(unquote 1)"))   # => (false "cannot use unquote here")
```

`(splice [1 2])` 單獨寫會回 `splice can only be used in function parameters and data
constructors, it has no effect here`。

## 定義（9 個巨集 ＋ 2 個函式）

| 名 | 展開成／說明 |
|----|-------------|
| `defn` `defn-` | 定義函式；`-` 版加 `:private` |
| `defmacro` `defmacro-` | 定義巨集（`:macro true`）|
| `varfn` | 定義成 `var` 的函式，之後可以整支換掉 |
| `def-` `var-` | `(def x :private …)` 的簡寫 |
| `defdyn` | 宣告一個動態變數名，給 `setdyn`／`dyn` 用（見 [40](../docs/40-內建動態變數.md)）|
| `defglobal` `varglobal` | ⚠ **函式不是巨集**：`(defglobal 'gg 7)` 名字要自己引用起來 |
| `default` | `(default a 1)` = 「`a` 是 `nil` 才給預設」，給 `&opt` 參數收尾用 |

```janet
(defmacro m [x] ~(+ ,x 1)) (m 2)             # => 3
(do (defn f [&opt a] (default a 9) a) (f))   # => 9
(macex1 ~(def- x 1))                         # => (def x :private 1)
```

## 綁定（3 個）

| 名 | 說明 |
|----|------|
| `let` | `(let [b1 v1 …] & body)`；支援解構 |
| `with-syms` | `(with-syms [a b] & body)`，每個名字綁一個 `gensym`，寫巨集時防撞名 |
| `with-vars` | `(with-vars [v1 x1 …] & body)`，**暫時**改既有的 `var`，離開時還原 |

⚠ `with-vars` 的名字**必須是已經存在的 `var`**，它不會幫你宣告：

```janet
(do (var q 0) (with-vars [q 9] q))     # => 9
(do (var q 0) (with-vars [q 9] q) q)   # => 0
```

## 編譯期（5 個）

| 名 | 說明 |
|----|------|
| `comptime` | 在**編譯期**求值，把結果當常數嵌進去 |
| `compif` | 編譯期選一邊，另一邊**完全不編譯** |
| `compwhen` | 同上，沒有 else；假的時候整段消失（回 `nil`）|
| `as-macro` | `(as-macro ,某巨集 & args)`，把一個**值**當巨集展開；寫巨集產生巨集呼叫時用 |

```janet
(comptime (+ 1 2))          # => 3
(compif (= 1 1) :yes :no)   # => :yes
(compwhen (= 1 2) :yes)     # => nil
```

`chr` 也在這一組：`(chr "a")` 在編譯期就變成 `97`。
