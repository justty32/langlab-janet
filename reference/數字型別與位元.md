## 位元運算（7 個）

| 函式 | 簽名 | 說明 |
|------|------|------|
| `band` | `(band & xs)` | and。沒參數回 `-1`（全 1）|
| `bor` | `(bor & xs)` | or。沒參數回 `0` |
| `bxor` | `(bxor & xs)` | xor。沒參數回 `0` |
| `bnot` | `(bnot x)` | 反相 |
| `blshift` | `(blshift x & shifts)` | 左移，位移量是 `shifts` 的**總和** |
| `brshift` | `(brshift x & shifts)` | **算術**右移，保留符號 |
| `brushift` | `(brushift x & shifts)` | **邏輯**右移，當成無號數處理 |

```janet
(band 0xF0 0x3C)     # => 48
(bor 0xF0 0x0F)      # => 255
(bxor 0xF0 0x3C)     # => 204
(bnot 0)             # => -1
(blshift 1 4)        # => 16
(brshift 256 4 4)    # => 1
(brshift -8 1)       # => -4
```

⚠ **這一組全部是 32 位元**，不是 Janet 平常那個 53 位元精度的 double：

```janet
(blshift 1 31)       # => -2147483648
(blshift 1 32)       # => 1
```

左移 31 位就翻成負數，移 32 位等於沒移（位移量對 32 取模）。要 64 位元的位移
得先轉 `int/s64`／`int/u64`。

⚠ `brushift` 把 `x` 當**無號**數看，餵負數直接丟錯
`value -8 out of range for 32-bit unsigned integers`；`brshift` 才吃負數。
⚠ 餵小數也會丟錯（`(band 1.5 2)` → `value 1.5 out of range for 32-bit signed integers`），
不是靜默取整。

## 64 位元整數（4 個）

| 函式 | 說明 |
|------|------|
| `int/s64` | `(int/s64 value)` 有號 64 位元，型別 `:core/s64` |
| `int/u64` | `(int/u64 value)` 無號 64 位元，型別 `:core/u64` |
| `int/to-number` | 轉回普通 number；**超出 ±2^53 會丟錯** |
| `int/to-bytes` | `(int/to-bytes value &opt endianness buffer)` 寫成 8 個 byte |

參數可以是數字，也可以是**字串**——超過 double 精度的值只能用字串給：

```janet
(type (int/s64 1))                       # => :core/s64
(string (int/u64 "18446744073709551615")) # => "18446744073709551615"
(int/to-number (int/s64 "9007199254740")) # => 9007199254740
(int/to-bytes (int/s64 258) :be)         # => @"\0\0\0\0\0\0\x01\x02"
(int/to-bytes (int/s64 258) :le)         # => @"\x02\x01\0\0\0\0\0\0"
```

`endianness` 給 `:le`／`:be`，不給就用這台機器的位元組序；不給 `buffer` 就回新的。

⚠ **算術運算子會把結果留在 64 位元型別裡**，不會退回普通數字：

```janet
(type (+ (int/s64 1) 1))   # => :core/s64
(type (* (int/u64 3) 2))   # => :core/u64
```

⚠ 這種值 `%j`／`pp` 印不出來（`could not print to jdn format`），要看數值得
`(string x)` 或 `(int/to-number x)`。
⚠ `(int/s64 1.5)` 丟錯，不會幫你取整。

## 相等與 hash（5 個）

| 函式 | 說明 |
|------|------|
| `=` | 值相等；可變型別（array／table／buffer）比的是**身分** |
| `not=` | `(not= & xs)` 「有任何兩個不相等」就是真 |
| `deep=` | 可變型別也比結構。**慢很多** |
| `deep-not=` | `deep=` 的反面 |

```janet
(= @[1] @[1])                  # => false
(deep= @[1 @[2]] @[1 @[2]])    # => true
(not= 1 2)                     # => true
(deep-not= @[1] @[2])          # => true
```

⚠ `=` 對 64 位元整數**認型別**，`deep=` 也一樣：

```janet
(= (int/s64 5) 5)              # => false
(= (int/s64 5) (int/s64 5))    # => true
(deep= (int/s64 5) 5)          # => false
```

`hash` 也在這一組：`(hash x)` 回一個整數，同一個行程裡同值同 hash，
但**跨行程不保證一樣**，不要存進檔案。

## 比較（10 個）

| 一組 | 成員 | 怎麼比 |
|------|------|--------|
| 原始 | `<` `<=` `>` `>=` | 只看數字大小，**跨型別一律當不相等**；吃多個參數，檢查整串是否單調 |
| 多型 | `compare<` `compare<=` `compare>` `compare>=` `compare=` | 先看有沒有 `compare` 方法，沒有才退回原始比較子 |
| 三向 | `compare` `cmp` | 回 `-1`／`0`／`1` |

```janet
(<= 1 1 2)          # => true
(>= 3 3 1)          # => true
(compare< 1 2 3)    # => true
(compare "a" "b")   # => -1
(cmp 1 2)           # => -1
(cmp :a :b)         # => -1
```

⚠ `compare` 和 `cmp` 不一樣：`cmp` 要求「完全同型別」才可能回 `0`，
`compare` 會走多型那條路，所以拿它去比 `int/s64` 跟普通數字是**相等**的：

```janet
(compare (int/s64 5) 5)   # => 0
(= (int/s64 5) 5)         # => false
```

想讓自己的型別參與排序，就在 prototype 上放一個 `compare` 方法，
`compare<` 那一家會找到它（見 [36 排序與比較](../docs/36-排序與比較.md)）。

## 算術（5 個）

`inc` `dec` 就是 `+1`、`-1`。`/` 是**真除法**，`div` 是**地板除**（往負無窮取整，
沒參數回 `1`）。⚠ `mod` 與 `%` 在負數時**不一樣**：`mod` 跟除數同號，`%` 跟被除數同號。

```janet
(inc 5)      # => 6
(dec 5)      # => 4
(/ 7 2)      # => 3.5
(div 7 2)    # => 3
(div -7 2)   # => -4
(mod -7 2)   # => 1
(% -7 2)     # => -1
```
