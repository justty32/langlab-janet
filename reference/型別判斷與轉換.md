# 型別 ・ 判斷與轉換

[← reference 索引](README.md)

對應教學：[38 型別全表](../docs/38-型別全表.md)、[13 symbol/keyword/字串](../docs/13-symbol-keyword-字串.md)。

> `root-env` 裡以 `?` 結尾、不帶 `/` 的判斷函式**剛好 37 個**，這裡全收。

## `(type x)` 的 19 種回傳值

| 分層 | 值 |
|------|-----|
| 單值 | `:nil` `:boolean` `:number` |
| byte 序列 | `:string` `:buffer` `:symbol` `:keyword` |
| 索引容器 | `:tuple` `:array` |
| 字典容器 | `:struct` `:table` |
| 可呼叫 | `:function`（Janet 寫的）`:cfunction`（C 寫的）|
| 執行 | `:fiber` |
| abstract | `:core/file` `:core/peg` `:core/rng` `:core/s64` `:core/u64` … |

⚠ `(type nil)` 是 `:nil`，不是「沒有型別」。**`core/` 前綴＝abstract type**。

## 傘狀判斷（一個罩一整組）

| 函式 | 罩住 |
|------|------|
| `bytes?` | string、buffer、**symbol、keyword** ⚠ 後兩個常出乎意料 |
| `indexed?` | tuple、array |
| `dictionary?` | struct、table |
| `lengthable?` | 上面全部八個（＝`(length x)` 不會爆）|
| `abstract?` | 所有 `:core/…` |

## 逐型別判斷（一對一）

`nil?` `boolean?` `number?` `string?` `buffer?` `symbol?` `keyword?`
`tuple?` `array?` `struct?` `table?` `function?` `cfunction?` `fiber?`

⚠ **沒有 `callable?`**。要「真的是函式」寫 `(or (function? f) (cfunction? f))`；
但「能放在呼叫位置」還包含 `bytes?`／`indexed?`／`dictionary?`——
資料結構被呼叫時是**索引自己**（`("abc" 1)` → `98`）。

## 數字判斷

| 函式 | 意思 |
|------|------|
| `int?` | ⚠ 問的是「**塞得進 32-bit 有號整數**嗎」。`(int? 1.0)` 是 `true`、`(int? 3000000000)` 是 `false` |
| `nat?` | 同上再加「非負」；`(nat? 0)` 為真 |
| `nan?` | 是不是 NaN。⚠ NaN **連自己都不等於自己**，只能用這個判斷 |
| `zero?` `one?` `pos?` `neg?` `even?` `odd?` | 顧名思義 |

要問「數學上是不是整數」用 `(= x (math/floor x))`，不是 `int?`。

## 真假與集合

| 函式 | 意思 |
|------|------|
| `true?` `false?` | 是不是**恰好**那個布林值 |
| `truthy?` | 除了 `nil`／`false` 以外都是真（`0`、`""`、`@[]` 全是真）|
| `empty?` | 長度為 0。⚠ 對數字／nil 會**報錯**，先問 `lengthable?` |
| `any?` | 回**第一個真值**；全假時回 `false` |
| `every?` | 全真時回**最後一個值**（不是 `true`）；有假值就回那個假值 |
| `has-key?` | 有沒有那個**鍵**。⚠ 見下方「字典存不了 nil」|
| `has-value?` | 有沒有那個**值** |
| `idempotent?` | 這個值「編譯後求值等於自己」嗎（寫巨集時才用得到）|

## 轉換

| 從 → 到 | 怎麼做 |
|---------|--------|
| 任何值 → 顯示字串 | `(string/format "%q" x)`；⚠ **中文會被逃逸**，給人看用 `%s` |
| 任何值 → 人話描述 | `(describe x)` |
| 字串 → 數字 | `(scan-number s)`——失敗回 **`nil`** 不拋錯；空字串也回 `nil` |
| 數字／任何 → 字串 | `(string x)`（`string` 吃任何東西並串接）|
| string ↔ symbol ↔ keyword | `(symbol s)` `(keyword s)` `(string sym)`；⚠ 沒有 keyword→symbol 的直接函式，經過 string |
| buffer → string | `(string buf)`；⚠ buffer 跟 string **內容一樣也不相等** |
| 可變 ↔ 不可變 | `(freeze x)` / `(thaw x)`——**遞迴**；table↔struct、array↔tuple、buffer→string |
| 容器互轉 | `(array ;xs)` `(tuple ;xs)` `(table ;kvs)` `(struct ;kvs)` `(buffer s)` |
| 字典 → 清單 | `(keys d)` `(values d)` `(pairs d)` `(kvs d)`；⚠ 順序是 **hash 序** |
| 數字 → 64 位元 | `(int/s64 x)` `(int/u64 x)`；印出來要用 `(string x)`，`%j` 印不出 abstract type |

### ⚠ 字典**存不了 `nil` 值**

```janet
(def t @{:a 1})
(put t :a nil)
(has-key? t :a)   # => false
(keys t)          # => @[]
(length t)        # => 0
```

**把值設成 `nil` 等於刪掉那個鍵**，字面值 `{:a nil}` 也一樣（`keys` 是 `@[]`）。
所以「用 `nil` 當一個有意義的值存進字典」做不到——要區分「沒有這個鍵」與
「有這個鍵但值是空的」，得自己挑一個哨兵值（例如 `:null`，`spork/json` 就是這樣做的）。

⚠ **Janet 不做隱式轉型**：`(+ 1 "1")` 報
`could not find method :+ for 1 or :r+ for "1"`——運算子對非數字會去找該型別的方法。

## 進位字面值

`8r644`（八進位）`16rFF`（十六進位）`2r1010`（二進位）`1_000_000`（底線分隔）`1e3`

⚠ **沒有 `0o644`／`0644` 這種寫法**——前者 parse 不過，後者是**十進位 644**。
