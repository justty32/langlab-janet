# 容器操作 ・ 全部 37 個

[← reference 索引](README.md)

`array/*` 15 ＋ `table/*` 11 ＋ `struct/*` 5 ＋ `tuple/*` 6。
對應教學：[02 資料結構](../docs/02-資料結構.md)、[02b prototype](../docs/02b-方法與-prototype.md)、
[35 拷貝與凍結](../docs/35-拷貝與凍結.md)、[22 原型與方法](../docs/22-原型與方法.md)。

> 這一份是**型別專屬**的操作。通用的 `map`／`filter`／`get-in`／`merge` 那些在
> [序列與集合](序列與集合.md) 三份裡。對著 `root-env` 逐一核過，37 個一個不漏。

## `array/*`（15 個）

### 增刪

| 函式 | 簽名 | 說明 |
|------|------|------|
| `array/push` | `(array/push arr & xs)` | 推到尾端；**原地改**並回傳 `arr` |
| `array/pop` | `(array/pop arr)` | 拿掉並回傳最後一個 |
| `array/peek` | `(array/peek arr)` | 看最後一個，**不動它** |
| `array/insert` | `(array/insert arr at & xs)` | 插在 `at`；`at` 可為負 |
| `array/remove` | `(array/remove arr at &opt n)` | 從 `at` 拿掉最多 n 個 |
| `array/concat` | `(array/concat arr & parts)` | ⚠ **原地改 `arr`**；序列攤平一層，**單一值也吃** |
| `array/join` | `(array/join arr & parts)` | 同上，但 ⚠ **只吃序列**——餵單一值報 `expected indexed type` |
| `array/fill` | `(array/fill arr &opt value)` | 全部換成同一個值 |
| `array/clear` | `(array/clear arr)` | 長度歸零（容量留著）|

### 建立與容量

| 函式 | 說明 |
|------|------|
| `array/new` | `(array/new capacity)` 空的但先預留容量 |
| `array/new-filled` | `(array/new-filled count &opt value)` 先填滿 |
| `array/ensure` | `(array/ensure arr capacity growth)` 確保容量夠 |
| `array/trim` | 容量縮到剛好等於長度 |
| `array/weak` | `(array/weak capacity)` **弱參照**陣列——裡面的東西照樣可被 GC |

### 切片

`(array/slice arrtup &opt start end)`——⚠ **回新的 array**，吃負索引，
而且**吃 tuple 也吃 array**。這是 array 的**淺**拷貝寫法（見 [35](../docs/35-拷貝與凍結.md)）。

## `table/*`（11 個）

### 建立與拷貝

| 函式 | 說明 |
|------|------|
| `table/new` | `(table/new capacity)` 預留容量 |
| `table/clone` | ⚠ **淺**拷貝——內層還是同一個物件 |
| `table/clear` | 清空並回傳 |
| `table/to-struct` | `(table/to-struct tab &opt proto)` 轉不可變。⚠ **只有一層**（內層 array 還是 array），要深的用 `freeze` |

### prototype（Janet 全部的 OOP）

| 函式 | 說明 |
|------|------|
| `table/setproto` | `(table/setproto tab proto)` 掛原型，回傳 `tab` |
| `table/getproto` | 拿原型，沒有回 `nil` |
| `table/proto-flatten` | 把整條原型鏈壓成一張表 |
| `table/rawget` | ⚠ **不走原型鏈**查值——`get` 會走 |

### 弱參照

`table/weak`（鍵值都弱）`table/weak-keys` `table/weak-values`
——做快取時才用得到；一般情況用普通 table。

## `struct/*`（5 個）

| 函式 | 說明 |
|------|------|
| `struct/with-proto` | `(struct/with-proto proto & kvs)` 建一個帶原型的 struct |
| `struct/getproto` | 拿原型 |
| `struct/proto-flatten` | 壓平原型鏈 |
| `struct/rawget` | 不走原型鏈查值 |
| `struct/to-table` | `(struct/to-table st &opt recursive)` 轉可變。⚠ `recursive` 指的是**原型鏈**，不是巢狀內容——內層照樣是不可變的 |

⚠ struct 的原型**印不出來**：`(struct/with-proto {:b 2} :a 1)` 印出來是 `{:a 1}`，
但 `(s :b)` 查得到 `2`。實務上很少用，要做物件請用 table。

## `tuple/*`（6 個）

| 函式 | 說明 |
|------|------|
| `tuple/slice` | `(tuple/slice arrtup &opt start end)` 取子序列 |
| `tuple/join` | 接起來成一個新 tuple |
| `tuple/brackets` | `(tuple/brackets & xs)` 造一個**方括號** tuple |
| `tuple/type` | 回 `:parens` 或 `:brackets`——**同樣是 tuple，但源碼寫法記得住** |
| `tuple/sourcemap` | 拿原始碼位置（行、列）|
| `tuple/setmap` | 設原始碼位置 |

```janet
(tuple/type '(1 2))              # => :parens
(tuple/type '[1 2])              # => :brackets
(tuple/type (tuple/brackets 1 2))# => :brackets
(tuple/type [1 2])               # => :parens   ⚠ 沒 quote 的話，
                                 #    [1 2] 被求值成一個「執行期新建的」tuple，記號沒了
```

⚠ `tuple/type` 與 `tuple/brackets` 是給**寫巨集**的人用的：
`(a b)` 與 `[a b]` 在 Janet 裡都是 tuple，但編譯器對前者當「呼叫」、後者當「資料」，
所以巨集產生程式碼時要選對（見 [08 巨集](../docs/08-巨集-macro.md)）。
`sourcemap` 那兩個則是錯誤訊息能報出行號的原因（見 [34](../docs/34-讀錯誤訊息.md)）。

## 沒有的

**沒有 `array/sort`／`table/merge` 這種型別專屬版**——排序是通用的 `sort`／`sorted`
（[36](../docs/36-排序與比較.md)），合併是 `merge`（[序列與集合c](序列與集合c-字典與組合.md)）。
**深拷貝**也沒有專屬函式，用 `(thaw (freeze x))`（[35](../docs/35-拷貝與凍結.md)）。
