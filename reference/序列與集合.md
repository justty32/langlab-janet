# 序列與集合 ・ 轉換／篩選／聚合

[← reference 索引](README.md)

這份窮舉 Janet 內建處理序列（array／tuple／string／buffer）與字典（table／struct）的函式，本檔收「轉換」「篩選與尋找」「聚合」三節；切割與重排在 [序列與集合b-切割與重排.md](序列與集合b-切割與重排.md)；字典、組合函式、走訪在 [序列與集合c-字典與組合.md](序列與集合c-字典與組合.md)。對應教學是 docs/25-序列工具.md，那篇講怎麼用、這裡查全部有什麼。全部函式皆以 `janet -e` 實測於 1.41.2。

## 轉換

| 函式 | 簽名 | 說明 |
|---|---|---|
| `map` | `(map f ind & inds)` | 對每個元素套 `f`，回傳新陣列；可同時吃多個序列（取最短長度） |
| `mapcat` | `(mapcat f ind & inds)` | map 完再用 `array/concat` 攤平一層 |
| `filter` | `(filter pred ind)` | 留下 `(pred x)` 為真的元素 |
| `keep` | `(keep pred ind & inds)` | 留下 `(pred x)` 的**真值本身**（不是原元素），可用來邊過濾邊轉換 |
| `reduce` | `(reduce f init ind)` | 一般說的 fold-left，從 `init` 開始逐一疊代 |
| `reduce2` | `(reduce2 f ind)` | 不給初始值的版本，拿第一個元素當初始值；空序列回傳 `nil` |
| `accumulate` | `(accumulate f init ind)` | 跟 `reduce` 一樣疊代，但把**每一步**的中間結果都收進回傳的陣列 |
| `accumulate2` | `(accumulate2 f ind)` | `accumulate` 的不給初始值版本 |
| `seq` | `(seq head & body)` | 用 `loop` 語法跑迴圈，把每次 body 的值收進新陣列 |
| `tabseq` | `(tabseq head key-body & value-body)` | 同 `seq`，但收成 table（key-body 算 key、value-body 算 value） |
| `catseq` | `(catseq head & body)` | 同 `seq`，但用 `array/concat` 把每次 body 的結果攤平接起來 |
| `generate` | `(generate head & body)` | 同 `loop` 語法，但回傳一個 fiber，`resume` 一次吐一個值（惰性） |

## 篩選與尋找

| 函式 | 簽名 | 說明 |
|---|---|---|
| `count` | `(count pred ind & inds)` | 數 `(pred x)` 為真的個數 |
| `all` | `(all pred ind & inds)` | 全部為真才 true；遇到第一個假值就回傳那個假值 |
| `any?` | `(any? ind)` | 序列本身當謂詞用：全真回最後一個，否則回第一個假值 |
| `every?` | `(every? ind)` | 同 `any?` 但語意相反：全真回最後一個真值，遇到假值就回那個假值 |
| `some` | `(some pred ind & inds)` | 有任一 `(pred x)` 為真就回傳那個真值，否則 `nil` |
| `find` | `(find pred ind &opt dflt)` | 回傳第一個滿足 `pred` 的元素，找不到回 `dflt` |
| `find-index` | `(find-index pred ind &opt dflt)` | 同 `find` 但回索引 |
| `index-of` | `(index-of x ind &opt dflt)` | 反查：`x` 這個值第一次出現在哪個 key／索引 |
| `has-key?` | `(has-key? ds key)` | `ds` 是否有這個 key（索引型是位置、字典型是鍵） |
| `has-value?` | `(has-value? ds value)` | `ds` 是否含有這個值（要整個掃一遍，O(n)） |

## 聚合

| 函式 | 簽名 | 說明 |
|---|---|---|
| `sum` | `(sum xs)` | 加總，空序列回 `0` |
| `product` | `(product xs)` | 連乘，空序列回 `1` |
| `mean` | `(mean xs)` | 平均值，空序列回 `nan` |
| `geomean` | `(geomean xs)` | 幾何平均（n 個數連乘後開 n 次方根，適合看成長率而非算術平均） |
| `max` / `min` | `(max & args)` / `(min & args)` | 直接對多個引數取極值 |
| `max-of` / `min-of` | `(max-of args)` / `(min-of args)` | 對**一個序列**取極值 |
| `extreme` | `(extreme order args)` | 自訂比較函式 `order`（例如 `>`）取極值，空序列回 `nil` |

## 實測範例

```
(map + [1 2 3] [10 20 30])              # => @[11 22 33]
(keep (fn [x] (if (even? x) (* x x))) (range 10))
                                         # => @[0 4 16 36 64]  (奇數的 (if ...) 回 nil 被丟掉)
(reduce + 0 [1 2 3 4])                  # => 10
(accumulate + 0 [1 2 3 4])              # => @[1 3 6 10]       每一步都留
(seq [i :range [0 5]] (* i i))          # => @[0 1 4 9 16]
(tabseq [i :range [0 3]] i (* i i))     # => @{0 0 1 1 2 4}
(catseq [i :range [0 3]] [i i])         # => @[0 0 1 1 2 2]
```

⚠ `generate` 回傳的是 **fiber**，不是陣列：`(generate [i :range [0 3]] (* i i))` 印出來是 `<fiber 0x...>`，要 `(resume g)` 一次拿一個值，或 `(fiber/status g)` 看狀態。

```
(count even? (range 10))                # => 5
(all even? [2 4 6])                     # => true
(all even? [2 4 5])                     # => false        # 回傳的是第一個假值本身
(any? [false nil 3])                    # => 3             # any? 拿序列自己當資料，不吃 pred
(every? [1 2 false])                    # => false
(find even? [1 3 5] :none)              # => :none
(find-index even? [1 3 5 6 7])          # => 3
(index-of 5 [1 3 5 6 7])                # => 2
(has-key? [10 20 30] 1)                 # => true          # 索引型是「位置存在」不是「值存在」
```

⚠ `print` 對 array／table／tuple 不會展開內容，只印位址（`<array 0x...>`）；本檔與其它 reference 檔的範例一律改用 `pp`（pretty-print）才會印出 `@[...]` `@{...}` 這種可讀結構。

```
(sum [1 2 3 4])                         # => 10
(product [1 2 3 4])                     # => 24
(mean [1 2 3 4])                        # => 2.5
(geomean [1 2 4 8])                     # => 2.82842712474619
(max-of [3 7 2])                        # => 7
(extreme > [3 7 2])                     # => 7             # order 是「誰該排前面」的比較函式
(extreme < [3 7 2])                     # => 2
```
