> 這一份對著 `root-env` 逐一核過。**`if`／`do`／`while`／`break`／`def`／`var`／`set`／`fn`／`quote`

> 所以 `(doc if)` 也查不到說明。其餘全是巨集。

## 條件

| 名 | 形狀 | 說明 |
|----|------|------|
| `if` | `(if c 真 [假])` | **特殊形式**。只有 `nil`／`false` 是假 |
| `when` | `(when c & body)` | 真才跑，沒有 else |
| `unless` | `(unless c & body)` | `(when (not c) …)` |
| `if-not` | `(if-not c 真 [假])` | 條件反過來讀，少一層 `not` |
| `cond` | `(cond c1 v1 c2 v2 … [else])` | 由上往下第一個真的贏；奇數個參數時最後一個是 else |
| `case` | `(case x v1 b1 v2 b2 … [else])` | 拿 `=` 逐一比。⚠ 對 array／table **永遠不中**（比身分）|
| `and` `or` | `(and & forms)` | 回**值本身**不是 true／false；短路 |
| `not` | `(not x)` | 唯一的**函式**，其餘都是巨集 |

## 綁定 ＋ 判斷一次做完

| 名 | 形狀 | 說明 |
|----|------|------|
| `if-let` | `(if-let [b1 v1 …] 真 [假])` | 全部綁得到（非 nil）才走真 |
| `when-let` | `(when-let [b1 v1 …] & body)` | `(if-let … (do ;body))` |
| `when-with` | `(when-with [b ctor [dtor]] & body)` | `with` ＋ `when-let`：綁不到就跳過且不收尾 |
| `if-with` | `(if-with [b ctor [dtor]] 真 [假])` | 同上但有 else |

⚠ **由上往下、一遇 nil 就整個放棄**，後面的運算式**完全不求值**：

```janet
(when-let [a 1 b nil c (error "這行不會跑")] [a b c])   # => nil
```

## match：比形狀並綁定

`(match x 模式1 結果1 模式2 結果2 … [_ 預設])`

| 模式 | 意思 |
|------|------|
| `42` `:kw` `"s"` | 常值，用 `=` 比 |
| `x`（裸符號）| 綁定，什麼都吃 |
| `_` | 什麼都吃但不綁 |
| `[a b]` | ⚠ **前綴**比對——`[1 2 3]` 也會中 |
| `[a & rest]` | `rest` 收剩下的 |
| `{:k v}` | 字典，**子集**比對（多的鍵不影響）|
| `(x 條件)` | 守衛：先綁 `x`，再求值 `條件`，真才算中 |
| 同名出現兩次 | 要求兩處相等 |

⚠ 沒中又沒 `_` 時回 **`nil`**，不報錯。模式**要由長排到短**，否則短的會遮住長的。

## 迴圈

| 名 | 形狀 | 回傳 |
|----|------|------|
| `loop` | `(loop head & body)` | 一律 `nil`（做副作用用）|
| `seq` | `(seq head & body)` | array |
| `tabseq` | `(tabseq head 鍵 值)` | table |
| `catseq` | `(catseq head & body)` | array，**攤平一層** |
| `generate` | `(generate head & body)` | **fiber**（惰性，要多少取多少）|
| `each` | `(each x ds & body)` | `nil`；走**值** |
| `eachk` | `(eachk k ds & body)` | `nil`；走**鍵**（array 的鍵是索引）|
| `eachp` | `(eachp [k v] ds & body)` | `nil`；走**鍵值對** |
| `for` | `(for i 起 迄 & body)` | `nil`；半開區間，`i` 用 `def` 綁 |
| `forv` | `(forv i 起 迄 & body)` | 同上但 `i` 用 `var` 綁，body 裡可以改它 |
| `forever` | `(forever & body)` | 無限迴圈，靠 `break` 出來 |
| `repeat` | `(repeat n & body)` | 跑 n 次；n 為負數時**一次都不跑** |
| `while` | `(while c & body)` | **特殊形式** |
| `break` | `(break [值])` | **特殊形式**；跳出最內層 |

### `loop` 的 head：八個 verb ＋ 八個條件詞

| verb | 對象 | 走出來的 |
|------|------|---------|
| `:range` | `[起 迄 [正步長]]` | 數字，`[起, 迄)`。⚠ **負步長靜默回空** |
| `:range-to` | 同上 | 含尾 `[起, 迄]` |
| `:down` | `[起 迄 [正步長]]` | 往下，不含尾 |
| `:down-to` | 同上 | 往下，含尾 |
| `:in` | 資料結構或 fiber | **值**（字串給 byte 數字）|
| `:keys` | 資料結構 | **鍵** |
| `:pairs` | 資料結構 | `[鍵 值]` |
| `:iterate` | 運算式 | 反覆求值直到假值 |

| 條件詞 | 作用 |
|--------|------|
| `:when 條件` | 真才跑 body（過濾，不中止）|
| `:unless 條件` | 假才跑 body |
| `:while 條件` | 條件變**假**就跳出 |
| `:until 條件` | 條件變**真**就跳出 |
| `:let [綁定…]` | 圈內綁中間值 |
| `:before 式` / `:after 式` | ⚠ **每圈**都跑，不是頭尾各一次 |
| `:repeat n` | 把下一層內圈重複 n 次 |

⚠ 多組綁定＝多層巢狀迴圈；**條件詞只作用在它前面那一層**。

## 非區域跳出

| 名 | 形狀 | 說明 |
|----|------|------|
| `label` | `(label 名 & body)` | 設一個詞法作用域的跳出點 |
| `return` | `(return 到 [值])` | 跳回某個 `label`／`prompt` |
| `prompt` | `(prompt 標籤 & body)` | 動態作用域版的跳出點 |
