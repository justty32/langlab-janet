# 編碼與位元組 ・ base64／crc／utf8

[← spork 索引](README.md)｜[← reference 索引](../README.md)

這三個都是**原生模組**（C 寫的 `.so`，不是純 Janet），在這台機器上已確認能 `import`。
base64 做編碼轉換，crc 做「資料有沒有壞掉」的校驗碼，utf8 是手動處理 UTF-8 位元組的低階工具。

## base64

Base64 是把任意位元組轉成「只有英數字加 `+/=`」的文字表示法，常見於把二進位資料塞進純文字欄位（email 附件、URL、JSON 字串）。

| 函式 | 簽名 | 說明 |
|---|---|---|
| `base64/encode` | `(base64/encode x)` | 位元組序列 → base64 字串 |
| `base64/decode` | `(base64/decode x)` | base64 字串 → 原始位元組（buffer） |

```janet
(import spork/base64)
(base64/encode "hello world")   # => @"aGVsbG8gd29ybGQ="
(base64/decode "aGVsbG8gd29ybGQ=")  # => @"hello world"
```
（實測：`encode` 回傳的字面上是 `aGVsbG8gd29ybGQ=`，`decode` 還原成 `hello world`，往返正確。）

## crc

CRC（循環冗餘校驗）是一種「校驗和」：對一串位元組算出一個固定長度的數字，
用來偵測傳輸／儲存過程有沒有壞掉（不是加密，改一個位元組校驗值幾乎必變）。
不同系統（zip、乙太網路、各種韌體）用不同的 CRC 參數組合，所以 spork 用「具名變體」把常見組合包好。

| 函式 | 簽名 | 說明 |
|---|---|---|
| `crc/named-variant` | `(crc/named-variant name)` | 取一個具名 CRC 變體，回傳一個「餵位元組進去吐校驗值」的函式 |
| `crc/make-variant` | `(crc/make-variant size polynomial &opt init byte-flip xorout)` | 自訂：位元寬度、多項式、初始值、是否反轉位元、輸出前 XOR 的值 |

具名變體很多（源碼列了 crc8 系列、crc16 系列、crc32/crc32c/crc32d 等三十幾種），常用的是 `:crc32`。

```janet
(import spork/crc)
(def crc32 (crc/named-variant :crc32))
(crc32 "hello")   # => 907060870   （即 0x3610A686，跟 zlib 的 crc32("hello") 一致）

# 手動組出同一個 crc32：多項式 0x04C11DB7、初始值全 1、反轉輸入輸出、結果再 XOR 全 1
(def custom (crc/make-variant 32 0x04C11DB7 0xFFFFFFFF true 0xFFFFFFFF))
(custom "hello")           # => 907060870
(= (crc32 "hello") (custom "hello"))  # => true
```
`crc/make-variant` 拿預設參數（`init` `xorout` 都不給、`byte-flip` 不給）跟 `:crc32` 對不起來很正常——
標準 crc32 的「魔法」全在那組 init/flip/xorout 參數上，不是多項式本身。

## utf8

Janet 字串本身就是位元組序列，不天生懂 UTF-8。`spork/utf8` 提供最底層的「一個 rune（碼點）站幾個位元組」操作，
給要自己寫 UTF-8 掃描／編輯邏輯的場合用（多數情況直接用內建的 `string` 函式或 PEG 就夠，這幾個是更底層的積木）。

| 函式 | 簽名 | 說明 |
|---|---|---|
| `utf8/decode-rune` | `(utf8/decode-rune buf &opt start)` | 從 `start`（預設 0）位置解一個 rune，回傳 `[碼點值 佔用位元組數]`；解不了回 `[nil 0]` |
| `utf8/encode-rune` | `(utf8/encode-rune rune &opt buf)` | 把一個碼點編碼成 UTF-8，附加到 `buf`（不給就新建） |
| `utf8/prefix->width` | `(utf8/prefix->width c)` | 給 UTF-8 序列的第一個位元組，回傳這個碼點總共佔幾個位元組 |

```janet
(import spork/utf8)
(utf8/decode-rune "héllo" 0)      # => (104 1)   'h' 是 1-byte ASCII
(utf8/decode-rune "héllo" 1)      # => (233 2)   'é' 佔 2 bytes，233 是它的碼點
(utf8/encode-rune 233)            # => @"\xC3\xA9"  （印出來是 é）
(utf8/prefix->width (chr "h"))    # => 1
(utf8/prefix->width 0xC3)         # => 2   ('é' 開頭位元組 0xC3 宣告後面還有 1 byte）
```
