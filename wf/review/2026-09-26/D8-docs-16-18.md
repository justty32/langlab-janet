# D8 docs 16–18（marshal／image／字串與 buffer）審閱

審閱者：fable｜日期 2026-09-26｜範圍：`docs/16-marshal-與自省.md`、`docs/16b-image-存成檔.md`、`docs/16c-image-怎麼用.md`、`docs/16d-image-與-jpm.md`、`docs/18-字串與-buffer.md`

## 總評
16／16b 的程式碼與輸出幾乎全部實測相符，錯誤集中在「說法比實際嚴」（marshal 查找表何時必須給）與一處指錯篇的連結（16b→16c 應為 16d）。最值得先修：`docs/16-marshal-與自省.md:23` 的查找表規則，讀者會學到錯的心智模型。結構上 16 尾巴的 spork 清單與 27 重複、16 又預講了 16b 的 `-c`／`-i`，可以瘦身。16c／16d 多處輸出是 Windows 環境（`a\b\c.txt`、`.exe.c`）沒註明平台。18 未及審閱。

## 發現
### 16-marshal-與自省
- [中][錯誤] `docs/16-marshal-與自省.md:23` — 說存 fiber「必須給」查找表否則失敗或整個 core 被塞進去；實測 L16–20 那個 fiber 不給表照樣 `marshal`（84 bytes）且 `unmarshal` 後 `(resume)` 得 `(2 3)`。真正的規則是：閉包／fiber 碰到 **cfunction**（如 `string/ascii-upper`）沒表就 `no registry value and cannot marshal <cfunction …>`；碰到純 Janet 寫的 core 函式（如 `partial`）則整段 bytecode 被存進去（691 bytes）。— 改寫成「碰 cfunction 才必須給表；不給表的代價是……」，並把例子換成真的會失敗的 — [實測]
- [低][錯誤] `docs/16-marshal-與自省.md:9` — 註解寫 74 bytes，1.41.2 實測 75 — 改數字或寫「約 75 bytes」— [實測]
- [中][結構] `docs/16-marshal-與自省.md:102-125` — 「spork 裡還有一整櫃」整節跟 marshal／自省無關，且 `docs/27-spork-全覽.md` 已是專篇；這裡等於第二份清單，日後會不同步 — 砍掉，換一行「spork 全覽見 27」— [疑]
- [低][結構] `docs/16-marshal-與自省.md:1` — 標題「marshal、image 與自省」但檔名只有「marshal-與自省」，且 image 三支（16b/c/d）都掛在本篇下；本篇沒有前後篇導航（只有回目錄），16b 卻有 `← 16` — 補「下一篇 16b」— [實測]
- [低][範例] `docs/16-marshal-與自省.md:91-98` — 「其他」一節六樣東西各一行、無輸出（`table/weak` 印出 `@{}`、`int/s64` 印 `<core/s64 …>` 都沒說），跟本篇「自省」主題也不太貼（`table/weak`、`gccollect`）— 保留 `macex1`／`macex` 給輸出，其餘移走 — [實測]
