## 總評
23、23b、24 三篇的實測輸出跟 Janet 1.41.2／spork 現況幾乎全部吻合（`jpm test` 輸出格式、exit code、`spork/test` 的 skip-asserts 行為、`os/date` 0-based、`%F`/`%T` 拋錯、`os/mktime` 回傳值全部重跑一致）。
最值得先修的是 `docs/24-時間與日期.md:104` 的 DST 繞法：實測它算出來跟直接 `+86400` 一模一樣，並沒有「讓作業系統處理」。
其餘是小結構問題（標題數目不符、`jpm test` 會遞迴子目錄沒講）。使用者提前關機，25、26、26b 沒來得及審。

## 發現
- [高][錯誤] `docs/24-時間與日期.md:103-105` — DST 地區「用 `os/date` 拆開、`:month-day` 加一、再 `os/mktime`」的繞法無效：`os/date` 拆出來帶 `:dst false`，`os/mktime` 會照著算，跨 DST 邊界時結果跟 `(+ t 86400)` 相同（TZ=America/New_York 2026-03-07 12:00 EST +1 天 → 兩種寫法都是 03-08 13:00 EDT）。要拿到 12:00 得先把 `:dst` 改掉（實測 `:dst true` 才對；`:dst nil` 也錯） — 改寫成「拆開、加一、**並把 `:dst` 拿掉／改對**」或直接刪掉這條建議、改說「Janet 沒有安全的跨 DST 加天工具，用 UTC 存」 — [實測]
- [中][錯誤] `docs/23-測試怎麼寫.md:18` — 「`test/` 底下每一支 `.janet` 檔」少講兩件事：`jpm test` 會**遞迴進子目錄**（`test/sub/x.janet` 也跑），而且 `_helper.janet` 這類底線開頭的檔也照跑；不是同層檔案平鋪那麼簡單 — 補一句「含子目錄，只看副檔名」 — [實測，jpm `declare.janet` `run-tests` 的 `dodir` 遞迴]
- [低][結構] `docs/23b-用-spork-test-寫測試.md:40-47` — 標題寫「五種斷言」，程式碼只列四個；spork/test 匯出的斷言也只有 `assert`、`assert-not`、`assert-error`、`assert-no-error` 四個 — 改成「四種斷言」 — [實測 `(keys (require "spork/test"))`]
- [低][難懂] `docs/24-時間與日期.md:31-32` — 「第三個參數是 local … `os/date`、`os/mktime` 也一樣」：後兩者的 local 是**第二個**參數，讀者照抄會把 `true` 塞錯位置 — 改成「最後一個參數是 local」 — [實測 `(os/date &opt time local)`、`(os/mktime date-struct &opt local)`]
- [低][範例] `docs/24-時間與日期.md:115` — 「`os/clock` 回的是帶小數的秒數」漏了它有第二個參數 `format`（`:double`／`:int`／`:tuple`），要整數秒或奈秒精度的人會去別處找 — 加一行 `(os/clock :monotonic :tuple)` — [實測 doc string]
- [低][範例] `docs/23-測試怎麼寫.md:55-56` — 這段標成純文字區塊卻寫 `# =>`，實際錯誤訊息前面有 `error: ` 前綴、後面還有 stack 行；跟 62 節「失敗長什麼樣」對照會以為兩者格式不同 — 補 `error: ` 前綴 — [實測]
- [低][文風] `docs/23b-用-spork-test-寫測試.md:26,97` — 實際輸出的 `✘` 帶 ANSI 紅色碼，貼進文件時去掉了；沒問題，但建議加一句「終端裡會是紅色」，否則讀者以為自己的環境多印了亂碼 — [實測]

（以下已實測**無誤**，列出免得後人重查：23 的 `assert` 回原值／訊息格式／`protect` 回 `[false msg]`／`(/ 1 0)`=inf／`jpm test` 三檔輸出與 exit code 1；23b 的 `end-suite` exit 1、`skip-asserts` 讓 suite 變紅、`capture-stdout` 回 `(nil @"…")`、中文訊息被逃逸；24 的 `1788016918` 各項換算、`%F %T %s %D` 拋 `invalid conversion specifier`、`%j`=241 vs `:year-day`=240、`(os/mktime (os/date t true) true)`=t；`examples/time-demo.janet`、`examples/testing-demo.janet` 都 exit 0。所有連結目標都存在。）
