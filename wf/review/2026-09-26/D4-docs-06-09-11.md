# D4 docs 06/07/08/09/11 審閱

審閱者：fable｜日期 2026-09-26｜範圍：`docs/06-編輯器與-REPL.md`、`docs/07-repl.md`、`docs/08-巨集-macro.md`、`docs/09-fiber.md`、`docs/11-pipeline-signal.md`

## 總評（3～6 句）
五篇的範例大多實跑得過，08 巨集篇最紮實（每個輸出都對）。最嚴重的是 11 的 `os/proc-kill` 範例：照抄會拿到 137 不是文中寫的 143。09 fiber 篇缺了任務點名的三樣東西：`resume` 傳值給 `yield`、`fiber/status` 的完整狀態、預設遮罩是 `:y`；而且 `each` 之後再 `loop :in` 同一個 fiber 會拿到空的。06／07 的 Conjure 段落重複，06 是個人 nvim 設定備忘、沒有「下一步」導航。09 跟 11 都用「信號」一詞但指的是兩種東西（fiber signal vs POSIX signal），要點破。

## 發現
- [高][錯誤] `docs/11-pipeline-signal.md:64-67` — 先 `(os/proc-kill child)`（SIGKILL）再送 `:term`，`proc-wait` 回 137（128+9），不是文中的 143 — 刪掉第 65 行的 SIGKILL 呼叫，或拆成兩個獨立範例；單送 `:term` 實測確為 143 — [實測]
- [高][錯誤] `docs/09-fiber.md:25` — `(loop [x :in squares] ...)  # 同義` 接在 `each` 之後跑，同一個 fiber 已 `:dead`，第二次什麼都不印 — 標明「fiber 走完就死，要重新 `fiber/new`」，或另建一個 fiber 給 loop — [實測]
- [中][錯誤] `docs/11-pipeline-signal.md:70` — 「合法 signal keyword 只有 `:term :int :hup :kill :usr1 :usr2 :quit`」不對，`:chld` 等其他 POSIX 名都收；`:winch` 不支援這點是真的 — 改成「大部分 POSIX signal 名（去掉 SIG 小寫），`:winch` 例外」 — [實測]
- [中][範例] `docs/11-pipeline-signal.md:46` — `# => "apple\nbanana\ncherry"` 標在 `os/proc-wait` 那行（它回 0）；真正的 `sorted` 是 `@"apple\nbanana\ncherry\n"`（buffer、有尾端換行） — 註解搬到第 45 行並改成實際值 — [實測]
- [中][範例] `docs/09-fiber.md:6-16` — 完全沒講 `(resume f v)` 會把 v 當成 fiber 裡 `yield` 的回傳值（雙向傳值是 fiber 跟 generator 最大的差別） — 加一段：`(def got (yield 1))` + `(resume k :hello)` → fiber 裡印 `got hello` — [實測]
- [中][範例] `docs/09-fiber.md:13,59` — `fiber/status` 只出現 `:pending`、`:error` 兩種 — 補一張表：`:new`（剛建）→ `:pending`（停在 yield）→ `:dead`（函式回傳）／`:error`；第 14 行後加第四次 `resume` → `nil`、狀態 `:dead` — [實測]
- [中][難懂] `docs/09-fiber.md:54-62` — 說「`:y` 攔 yield」但第一節沒給遮罩也能 yield，讀者會問為什麼；docstring 說**預設遮罩就是 `:y`** — 明講「不寫遮罩＝`:y`，所以 generator 不用設；`try` 是 `:ie`（`i` 是繼承 env 的旗標，不是信號）」；順帶列 `:u`／`:t`／`:d` — [實測]
- [中][結構] `docs/09-fiber.md:52`、`docs/11-pipeline-signal.md:61,72` — 兩篇都叫「信號」，09 是 fiber signal（error／yield／user），11 是 POSIX signal（SIGTERM／SIGINT），讀者連讀會混 — 09 用「fiber 信號」、11 用「作業系統信號（SIGxxx）」，各在開頭 ⚠ 一句「跟第 X 篇的信號不是同一回事」 — [疑]
- [中][結構] `docs/06-編輯器與-REPL.md:17-28` 與 `docs/07-repl.md:56-63` — Conjure `,ee` 工作流兩邊都講一遍 — 07 只留一句連到 06；06 改名成「nvim／Conjure 設定」當設定備忘，07 才是教學正文 — [疑]
