# D7 docs 14/15/15b/17 審閱

審閱者：fable｜日期 2026-09-26｜範圍：`docs/14-peg.md`、`docs/15-ev-channel-net.md`、`docs/15b-net-與速查.md`、`docs/17-用-spork-http-打-api.md`

## 總評（3～6 句）
14 的每一段 `peg/match` 輸出全部實跑吻合，沒有錯。15 的問題集中在「真 OS 執行緒」一節：最醒目的「不加 `:n` 會死鎖」在該篇自己的範例（`(ev/thread-chan 10)`）下不成立，讀者照做會發現跟書上說的相反。15b 的 net 範例可跑；17 的 `localhost` 陷阱實測為真。最值得先修：15:73–74 那兩點。

## 發現
- [高][錯誤] `docs/15-ev-channel-net.md:73` — 「不加 `:n` 會死鎖」在該篇範例的 `(ev/thread-chan 10)` 下不成立：give 進緩衝就返回、執行緒結束、`ev/thread` 回 nil，接著 `(ev/take tc)` 拿到 3；只有**無緩衝** `(ev/thread-chan)`（capacity 0）才會卡死 — 改寫成「thread-chan 無緩衝或塞滿時才會互等」，並補一句真卡死時 `ev/with-deadline` 雖會丟 "deadline expired" 但那條 OS 執行緒不會消失、行程不會結束 — [實測]
- [中][錯誤] `docs/15-ev-channel-net.md:74` — 「要拿結果就加 `:n`」誤導：`ev/thread` 不論有無 `:n` 都回 nil（docstring：Otherwise, returns nil），結果只能走 channel — 改成「`:n` 只是不等它結束；結果一律用 thread-chan 傳回」 — [實測]
- [中][錯誤] `docs/15b-net-與速查.md:37` — 「`ev/spawn`（值）」不對：`ev/spawn` 就是 `(ev/go (fn [] ;body))` 的縮寫，回的一樣是 task fiber，不是 body 的值 — 改成「兩者都回 task fiber，差在 spawn 直接包 body、go 吃函式／fiber 可傳 supervisor」 — [實測]
- [中][範例] `docs/15-ev-channel-net.md:86` — `(ev/cancel task :理由)` 之後事件迴圈會把被砍 fiber 的例外當「未接住錯誤」印到 stderr（`error: 理由` 加 stack trace），讀者會以為程式壞了 — 加一句「這是預期的，要安靜就給 `ev/go` 一個 supervisor channel 或在 task 裡 `try`」 — [實測]
- [中][結構] `docs/15-ev-channel-net.md:1,4` — 標題與導言都承諾「網路／內建 net」，但 net 整節搬到 15b，本篇只剩結尾一行導向 — 標題改掉「網路」或導言直接寫「net 見 15b」 — [實測]
- [低][錯誤] `docs/15-ev-channel-net.md:33` — close 後 `(ev/count ch)` 仍是 2、`(ev/give ch :c)` 會丟 "cannot write to closed channel"；文中只講 take 回 nil — 補這兩個現象，讀者除錯時才對得上 — [實測]
- [低][範例] `docs/15-ev-channel-net.md:49` — tuple 形式 `(ev/select a [b 值])` 成功時回 `(:give <channel>)`，文中只列 `:take`／`:close` 兩種 — 補 `:give` — [實測]
- [低][範例] `docs/15-ev-channel-net.md:75` — 把普通 `ev/chan` 丟給 `ev/thread`，不報錯、執行緒端 give 也「成功」，主線 `ev/count` 一直是 0（channel 被 marshal 複製成另一個）— 明講「安靜失敗，不會有例外」比「只在同一個執行緒內有效」更能救人 — [實測]
- [低][文風] `docs/15-ev-channel-net.md:37,95` — 兩處拿 Go 當參照（「從 Go 搬過來」「Go 那句 `defer cancel()`」），沒學過 Go 的讀者拿不到資訊 — 保留一處、或改成直述 — [疑]
- [低][範例] `docs/17-用-spork-http-打-api.md:55` — `localhost` 陷阱實測為真：server 聽 `127.0.0.1`、`(net/connect "localhost" 8931)` 得 "Connection refused"，`(net/address "localhost" 8931 :stream true)` 回兩筆位址 — 可把這組實測輸出貼進去當證據，比純敘述有力 — [實測]
- [低][範例] `docs/14-peg.md` 全篇 — 13 段 `peg/match`／`peg/find`／`peg/replace-all` 輸出、地雷表 `'(...)` 挖洞得 `@[(unquote scan-number)]`、`regex/compile` 例子全部實跑吻合，無錯 — 無需動 — [實測]
