## 總評（3～6 句）
02～04 四支的程式碼與輸出絕大多數實跑吻合，錯的多是輸出貼舊值或手排版。最該先修的是 `docs/02-資料結構.md:11`「可變的不能當 table key」這句是錯的（可以，只是比身分）。其次是 04 對 `:required` 與 `:rest` 的描述跟 spork 實際行為有落差。結構上 02b 與 22 的「方法呼叫語法」一節重複，02b 真正獨有的只有兩個陷阱，建議併入 22。05 系列五支沒看到。

- [中][錯誤] `docs/02-資料結構.md:49` — `(t :a :b)` 說是「compile error」，實際是執行期 `error: <table …> expects 1 argument, got 2` — 改成「執行期報錯」 — [實測]
- [低][錯誤] `docs/02-資料結構.md:45-46` — 第 38 行剛 `(update t :age inc)` 把 age 變 31，第 45、46 行的輸出卻還寫 `30` — 改成 31 或把 update 移到後面 — [實測]
- [低][錯誤] `docs/02-資料結構.md:63` — `(merge {:a 1} {:b 2})` 實跑是 `@{:a 1 :b 2}`，不是 `@{:b 2 :a 1}`；旁邊又說「別依賴順序」，貼一個跟實際不符的順序反而讓人以為它真的亂 — 貼實測值 — [實測]

### 04 cli-argparse
- [中][錯誤] `docs/04-cli-argparse.md:54` — `:required true` 寫「沒給就報錯」，實際是印 `usage error: option must is required` ＋ usage 然後**回傳 nil**，不會 throw；要靠 25 行的 `(unless res (os/exit 1))` 才會退出 — 改成「沒給就印 usage 回 nil，跟解析失敗同一條路」 — [實測]
- [中][錯誤] `docs/04-cli-argparse.md:56` — `:rest` 不是「其餘參數」，它**包含觸發 short-circuit 的那個選項本身**，且是 tuple：`a --stop b c` → `:rest ("--stop" "b" "c")`，`:default` 只收到 `@["a"]` — 補這句，否則讀者對 `:rest` 取 `[0]` 會拿到旗標 — [實測]
- [低][範例] `docs/04-cli-argparse.md:55,58` — `:map` 連 `:default` 值也會套（`:default "7" :map scan-number` 取回 `7`）；文中沒說，讀者會以為預設值仍是字串 — 補一句 — [實測]
- 其餘（四種 kind、`-vvv`→3、`-` 靜默吃掉四例、`:args` 忽略 `[0]`、`bin/main.janet`、`examples/subcommands.janet` 輸出）實跑全吻合 — [實測]
