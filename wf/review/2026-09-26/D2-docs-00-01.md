# D2 docs 00～01 審閱

審閱者：fable｜日期 2026-09-26｜範圍：`docs/00-環境與工具鏈.md`、`docs/00b-windows-vscode.md`、`docs/01-語言速成.md`、`docs/01b-給-C++-開發者.md`、`docs/01c-解構與執行緒巨集.md`、`docs/01d-提早離開-return-break-continue.md`

## 總評

六支檔的程式碼與輸出全部在 1.41.2 實跑過，沒有一段跑不動、沒有一個輸出不符；01d 對 `return`（boot.janet 裡的普通函式）、`break`（特殊形式，只認最內層 `while`／`fn`）、`label`／`prompt` 的說法全部精確。最大的問題在 00：標題叫「環境與工具鏈」、`wf/workflows/dev-env.md:17` 也叫人「照 docs/00 從原始碼編進 ~/.local」，但 00 一行安裝步驟都沒有，只是這台機器的現狀描述，別台機器完全無法照做。最值得先修：00 補一段可複製的安裝流程（clone tag、make、`make install PREFIX=~/.local`、jpm、`jpm install spork`），並把 jpm／spork 版本填上實際值。其次 01b 少了一條給 C++ 開發者最痛的「沒有 return」導向 01d 的連結。
