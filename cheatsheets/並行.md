# 並行速查

fiber・ev・channel・真執行緒・net・子行程與信號（Janet 1.41.2 實測）

## Fiber 協程

一段可暫停/恢復的執行流。generator、例外、非同步都是它。

### generator

```janet
(def f (fiber/new (fn [] (yield 1) (yield 2))))
(resume f) (resume f)   ;=> 1 然後 2
# 直接走訪：
(each x (fiber/new (fn [] (for i 0 4 (yield (* i i)))))
  (prin x " "))       ;=> 0 1 4 9
```

### 錯誤處理（其實也是 fiber）

```janet
(try (error "boom") ([e] (string "抓到:" e)))
(protect (error "bad")) ;=> (false "bad")
(protect (+ 1 2))     ;=> (true 3)
```

### ev：非同步（單執行緒協作）

```janet
(ev/spawn (print "背景"))  # 丟去背景跑
(ev/sleep 0)              # 讓排程器運轉
# 寫起來像同步、沒有 async 染色
```

## ev：channel / 執行緒

| 要什麼 | 用哪個 |
|---|---|
| IO 等待、並行請求（九成場合） | `ev/spawn` / `ev/go`（單執行緒協作） |
| 吃滿多核的 CPU 工作 | `ev/thread` / `ev/do-thread` |
| 跑別的程式 | `os/spawn` |

### channel

```janet
(def ch (ev/chan 10))   # 容量 10；(ev/chan) = 無緩衝
(ev/give ch v) (ev/take ch)
(ev/select a b)         ;=> (:take <chan> v) 誰先來聽誰的
(ev/gather e1 e2)       ;=> @[r1 r2] 等一批全做完
```

> ⚠ **★ 大坑**：`(ev/chan-close ch)` 之後**緩衝區裡的東西一個都拿不到**（`ev/count` 還是 2，但 `ev/take` 回 nil）。Go 那套「producer close、consumer 讀到 nil」在這裡會安靜掉資料——改用結束哨兵值。

### 真 OS 執行緒

```janet
(ev/do-thread …)              # 擋著等它做完
(def tc (ev/thread-chan 10))   # ★ 跨執行緒要 thread-chan
(ev/thread f tc :n)           # ★ 沒 :n 會死鎖
(ev/take tc)
```

執行緒之間的值是 **marshal 複製**，不共享 table——所以沒有 data race，也不能靠共用狀態溝通。

### 逾時 / 取消

```janet
(protect (ev/with-deadline 0.05 (ev/sleep 10)))
;=> (false "deadline expired")
(def t (ev/go f)) (ev/cancel t :理由)
```

> ⚠ **取消是合作式的**：只在對方進入 ev 操作（sleep／channel／網路）時生效，純 CPU 迴圈砍不掉。另外**還在睡的計時 fiber 會讓程式不肯結束**——用完記得 `ev/cancel`（＝ Go 的 `defer cancel()`）。

## ✦ 內建 net

不用任何外部庫，配 ev 天生併發、寫起來像同步。

```janet
(def s (net/listen "127.0.0.1" 8931))
(ev/spawn
  (net/accept-loop s
    (fn [conn]
      (defer (:close conn)
        (def req (:read conn 1024))
        (:write conn (string "收到 " (length req) " bytes\n"))))))
```

```janet
# client
(with [c (net/connect "127.0.0.1" 8931)]
  (:write c "hello")
  (string (:read c 100)))
```

另有 `net/server`（listen+accept-loop 合一）、`net/accept`、UDP 用 `:datagram`。

## 行程 / 管線 / 信號

```janet
(os/execute ["echo" "hi"] :p) # exit code；:p=用PATH :x=非零報錯
(import spork/sh)
(sh/exec-slurp "git" "rev-parse" "HEAD") # 抓輸出
```

### 管線

```janet
# 法一：Janet 中轉（好控制）
(def p (os/spawn ["sort"] :p {:in :pipe :out :pipe}))
(:write (p :in) "b\na\n") (:close (p :in))
(:read (p :out) :all) ;=> "a\nb"
# 法二：多段交給 shell
(os/execute ["sh" "-c" "a | b | c"] :p)
```

> ⚠ **坑**：別把 proc1 的 `:out` 直接接 proc2 的 `:in`——`:pipe` 是非阻塞 fd，對方讀會 `EAGAIN`。用上面兩法之一。

### 信號

```janet
(os/proc-kill child false :term) # signal 是 keyword
(os/sigaction :int (fn [] (print "bye")))
# ★ handler 要有 ev loop 在跑才會觸發
```

signal：`:term :int :hup :kill :usr1 :usr2 :quit`。
