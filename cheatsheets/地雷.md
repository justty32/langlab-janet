# 地雷速查

「這行為怪怪的，是不是已知的坑？」——全部實測過，每條標了出處（Janet 1.41.2 實測）

## ★ 最常咬人的五個

> ⚠ **`(:port cfg)` 不是取值，而且靜默回 `nil`**
> `(:k obj)` 是**方法呼叫**，展開成 `((get obj :k) obj)`。值不是函式時就變成
> 「拿那個值當函式去索引 obj」——整條鏈都不報錯。取值要寫 `(cfg :port)`。
> ——docs/02b

> ⚠ **只有 `nil` 和 `false` 是假**
> `0`、`""`、`@[]` 全都是**真**。跟 C／C++ 相反。
> ——docs/32

> ⚠ **迴圈裡用 `string` 累積字串，慢 300 倍**
> 每次都造新字串再整個抄過去 → O(N²)。改用 `buffer/push-string`。
> 同理「每圈造一個新 array」比 `array/push` 慢**一千倍以上**。
> ——docs/37

> ⚠ **`=` 對可變容器比的是「同一個物件嗎」**
> `(= @[1 2] @[1 2])` 是 `false`；tuple／struct 才比內容。
> 比內容用 `deep=`；**array／table 也因此當不了字典的鍵**。
> ——docs/02、docs/23

> ⚠ **尾呼叫會把堆疊那一層吃掉**
> 「我的函式沒出現在 stacktrace 裡」不代表沒被呼叫。行尾的 `(tail call)` 就是線索。
> ——docs/34

## 不報錯、但算錯的

這一組最危險：沒有任何錯誤訊息，只是答案不對。

| 你寫的 | 實際發生什麼 | 出處 |
|---|---|---|
| `(match [1 2 3] [a b] …)` | **會中**——tuple 模式是**前綴**比對。模式要由長排到短 | 32 |
| `(loop [i :range [3 0 -1]] …)` | 靜默**一圈都不跑**。`:range` 步長必須是正的，倒著走用 `:down`（但函式 `(range 3 0 -1)` 正常） | 32b |
| `(sorted xs compare)` | `compare` 回 −1/0/1 而 **0 是真** → 排序邏輯亂掉，報的卻是陣列索引越界。要傳「小於」或 `compare<` | 36 |
| `(->> 2 (- 10))` | `8`；而 `(-> 2 (- 10))` 是 `-8`。減、除、`get` 這類要想清楚塞哪，不確定就 `macex1` | 01c |
| `(def [x y z] [1 2])` | `z` 是 `nil`，不報錯。**解構不能當形狀檢查** | 01c |
| `(blshift 1 40)` | `256`——位元運算是 **32-bit**，位移量被 mod 32（C++ 給 1099511627776） | 21 |
| `(os/chmod f 0644)` | `0644` 是**十進位 644**。Janet 沒有八進位字面值，要寫 `8r644`（`0o644` 連 parse 都過不了） | 39 |
| `(= 1 (os/shell "exit 1"))` | 永遠 false——`os/shell` 回的是 **exit code × 256**。判斷成敗用 `os/execute` | 39 |
| `(dyn :ouy)` | 打錯名字靜默回 `nil`。用 `*星號*` 版（`(dyn *ouy*)`）編譯期就擋下 | 40 |
| `(rawterm/size)` | 非終端機時回**未初始化的記憶體**（每次跑都不同），不是 nil、不報錯。先問 `isatty`，再把 0 當未知 | 41 |
| `(loop [… :before x :after y] …)` | `:before`／`:after` 是**每圈**都跑，不是頭尾各一次 | 32b |
| `(match v …)` 漏寫分支 | 沒中又沒 `_` 時回 `nil`，不報錯 | 32 |
| argparse 收單獨的 `-`（unix 的 stdin 慣例） | **靜默吃掉**——進不了 `:default` 也不報錯，於是你的工具接不進管線。要自己從 `(dyn *args*)` 撿回來 | 04 |
| `(def [ok _] (protect …))` 之後靠「錯誤是不是 nil」判斷成敗 | 重試迴圈裡會出錯：第 3 次成功時上一次的錯誤還留著。用明確的成功旗標 | snippets/retry-timeout |

## 卡死，不是報錯

| 操作 | 結果 | 出處 |
|---|---|---|
| `(freeze 有循環參照的東西)` | **無限遞迴卡死**（不報錯）。循環參照要用 `marshal`／`unmarshal` | 35 |
| `prewalk` 的函式換出可再比對的節點 | 它會走進自己換出來的東西 → **無限重入**。不確定用哪個就用 `postwalk` | 35b |
| `(channel/from-each …)` 沒喝完 | 卡住。它**回傳**一個 channel，不是往既有的塞 | 30 |
| `(length (m/primes))` | `spork/math` 的 `primes` 是**無界 fiber**，用 `(take n …)` | 42 |

## 錯誤訊息看不出真正的原因

| 訊息 | 真正的意思 | 出處 |
|---|---|---|
| `expected string, symbol, keyword, array, tuple, table, struct or buffer, got 1` | **你呼叫的東西是 `nil`**。`(f 1)` 被當成 `(get 1 nil)`，所以它抱怨的是參數 | 34 |
| `could not find method :+ for 1` | 型別錯（`(+ 1 "a")`）。運算子對非數字會去找 `:+` 方法 | 02 |
| `cannot set constant`（在巨集裡） | 巨集的臨時變數**跟使用者的撞名**。用 `with-syms`；先 `macex1` 看展開 | 08 |
| `splice can only be used in function parameters…` | 你把 `;` 當註解了。**Janet 的註解是 `#`**；`;` 是 splice | 08 |
| `expected array, table or buffer, got <tuple>` | 該函式會原地改，只吃可變版——**加個 `@`** | 42 |
| `expects at least N arguments` | arity 錯是 **compile error**，`try` 攔不到；訊息裡的 `expected N` 報的是**最大** arity | 33 |
| `could not print to jdn format` | 那個值沒有合法的字面寫法（例如 `(keyword "有 空格")`）。用 `%s` 印 | 13 |
| `unknown method :close invoked on` | `with` 的對象沒有 `:close`——給第三個參數指定收尾函式 | 20b |

## 型別與拷貝

| 以為 | 其實 | 出處 |
|---|---|---|
| `(table/clone t)` 是拷貝 | 只有**一層**。深拷貝＝`(thaw (freeze x))`；`array/slice` 也是淺的 | 35 |
| `(def b a)` 複製一份 | 只是多一個名字。Janet **沒有值語意複製** | 01b |
| `(= "abc" @"abc")` | `false`——buffer ≠ string。先 `(string buf)` | 13 |
| `(int? 1.0)` 是 false | `true`。而 `(int? 3000000000)` 是 **false**——問的是「塞不塞得進 32-bit」 | 38 |
| `(bytes? :kw)` 是 false | `true`。`bytes?` 含 string／buffer／symbol／**keyword** | 38 |
| `(length "中文")` 是 2 | `6`（byte 數）。顯示寬度是 `4`，要用 `rawterm/monowidth` | 18、41 |
| `merge` 給 struct 回 struct | 一律回 **table**。要不可變自己 `freeze` | 35b |
| `(arr -1)` 拿最後一個 | 報錯。負索引只有 `array/slice` 吃；要最後一個用 `(last arr)` | 02 |
| 整數是精確的 | 全部是 double，**精度只到 2^53**——連字面值 `9007199254740993` 都存不住 | 21 |
| `(/ 1 0)` 會報錯 | 回 `inf`；`(/ 0 0)` 回 `-nan` 且**連自己都不等於自己**。用 `(nan? x)` | 21 |

## 印出來不是你要的

| 寫法 | 結果 | 正解 |
|---|---|---|
| `(print @[1 2 3])` | `<array 0x…>` 位址 | `pp` 或 `%q`／`%p` |
| `(printf "%j" "你好")` | `"\xE4\xBD\xA0…"` | 給人看用 `%s`（`%j`／`%q` 要保證 parse 得回去） |
| `%j` 是 JSON | 不是——是**單行 Janet 表示法** | 真 JSON 用 `(json/encode x)` |
| `(printf "%-10j" x)` | 寬度旗標對 `%j` **無效**，靜默失敗 | 先 `string/format "%j"` 轉字串再排 |
| `(debug/stacktrace f e)` | 少了 `error:` 那一行 | 第三個參數傳 `""` |
| `$<`（spork/sh-dsl）回字串 | 回的是 **buffer** | `(string (sh/$<_ …))` |

## 名字找不到

| 你以為叫 | 實際叫 | 出處 |
|---|---|---|
| `spork/math` 的 `mean` | **不存在**。自己算 `(/ (sum xs) (length xs))`；`z-score` 也要你餵平均 | 42 |
| `binomial-coefficient` | `binominal-coeficient`（多一個 n、少一個 f）。搜正確拼法一個都找不到 | 42 |
| `callable?` | 沒有這個。要「真的是函式」用 `(or (function? f) (cfunction? f))` | 38 |
| 可以 `(import spork)` 一次拿全部 | 會把 707 個 binding 灌進 env。**一個一個 import** | 27 |
| argparse 的 `:count` | 沒有這個 kind，會拿到 `unknown option kind`。四種是 `:flag` `:multi` `:option` `:accumulate` | 04 |

查 spork 模組有什麼，先列一次再用：

`(import spork/math :as m) (filter |(string/has-prefix? "m/" (string $)) (keys (curenv)))`
