## 檔案資訊：os/stat

```janet
(os/stat "x.txt")             # 整包資訊 table，檔案不存在回 nil
(os/stat "x.txt" :size)       # => 12          只要一項時直接指定，比較省
(os/stat "x.txt" :mode)       # => :file / :directory / :link
(os/stat "x.txt" :modified)   # => 秒數（number）
```

`os/stat` 回 `nil` 就是**判斷檔案存在**的標準寫法——Janet 沒有 `file/exists?`：

```janet
(defn exists? [p] (truthy? (os/stat p)))
(defn dir? [p] (= :directory (os/stat p :mode)))
```

## 目錄與路徑操作

```janet
(os/cwd)                    # 目前工作目錄
(os/dir ".")                # => @["a.txt" "sub"]  只有名字，不含路徑、不遞迴
(os/mkdir "newdir")         # 已存在回 false，不會拋錯
(os/rm "x.txt")             # 刪檔案 / 空目錄
(os/cd "sub")
(os/which)                  # => :windows / :linux / :macos
```

⚠ `os/dir` **不遞迴**、回傳的也只是檔名。要走整棵樹得自己遞迴，或用
`spork/sh` 的 `sh/list-all-files`：

```janet
(import spork/sh)
(pp (sh/list-all-files "docs"))    # 遞迴列出所有檔案（含路徑）
```

### 用 spork/path 組路徑，不要自己接字串

```janet
(import spork/path)
(path/join "a" "b" "c.txt")   # => "a\\b\\c.txt"（Windows）/ "a/b/c.txt"（Linux）
(path/basename "a/b/c.txt")   # => "c.txt"
(path/dirname "a/b/c.txt")    # => "a/b/"   ⚠ 尾巴帶分隔符
(path/ext "a/b/c.txt")        # => ".txt"   ⚠ 帶點
(path/abspath "x")            # => 以目前 cwd 展開的絕對路徑
```

`path/join` 會用當前平台的分隔符。如果你要處理的是**固定平台**的路徑字串
（例如解析 Linux 產生的 log），改用 `path/posix/*` 或 `path/win32/*` 明確指定。

## 一個實際的小工具

把某個目錄下所有 `.md` 的行數加總——這段涵蓋了上面全部：

```janet
(import spork/path)

(defn count-lines [p]
  (with [f (file/open p :rb)]
    (var n 0)
    (while (file/read f :line) (++ n))
    n))

(defn main [& _]
  (var total 0)
  (each name (os/dir "docs")
    (when (= ".md" (path/ext name))
      (def n (count-lines (path/join "docs" name)))
      (printf "%-32s %4d" name n)
      (+= total n)))
  (printf "%-32s %4d" "TOTAL" total))
```
