# 寫熟之後才會踩到的 · 32–39

[← docs 目錄](README.md)

[README](README.md) 收的是**依序讀**的基礎篇（00–06）與**要做事就會用到**的日常篇（18–26b）。
這份收第三層：**開始寫比較大的東西之後**才撞得到的語言細節。

每一篇的 ⚠ 都是**實測出來、文件沒寫或猜不到**的行為——不急著讀，但撞到時要知道來這裡翻。
每篇都附一支可跑範例，跑一次比讀十遍有用。

## 這一區為什麼獨立成冊

這七篇有個共同點：**它們講的都不是「怎麼做某件事」，而是「這件事跟你以為的不一樣」**。
所以它們不適合照順序讀完，適合當成一份「踩到再翻」的清單——
跟 [主題與 spork 索引](主題與-spork-索引.md) 收的那兩區性質相同，只是這區屬於語言核心。
