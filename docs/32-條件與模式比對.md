# 32 · 條件與模式比對

[01 語言速成](01-語言速成.md) 教了 `if`／`when`／`cond` 怎麼寫。這篇補完剩下的：
**`case` 和 `match` 差在哪**、`match` 的模式語法，以及 `when-let` 那一整家。

`match` 是這篇的重點——**C++ 沒有對應物**，但 Janet 的程式碼裡到處都是它。

## 先講真假值：只有 `nil` 和 `false` 是假

```janet
(if 0 :真 :假)    # => :真     ⚠ 不是 :假
(if "" :真 :假)   # => :真
(if @[] :真 :假)  # => :真
(if nil :真 :假)  # => :假
(if false :真 :假)# => :假
```

⚠ **從 C 或 C++ 過來的人一定會踩這個**：`0` 是真、空字串是真、空陣列也是真。
Janet 只有兩個假值。要判斷「空的」就明講：`(empty? x)`、`(zero? n)`。

`and`／`or` 回傳的**不是 true／false，是那個值本身**：

```janet
(and 1 2 3)     # => 3        全真時回最後一個
(and 1 false 3) # => false    回第一個假值
(or nil false 7)# => 7        回第一個真值
```

所以 `(or 使用者給的值 預設值)` 就是「預設值」慣用法——這在 Janet 原始碼裡隨處可見。

## 四個選擇形式，怎麼挑

| 形式 | 拿什麼比 | 什麼時候用 |
|------|---------|-----------|
| `if` | 一個條件 | 兩條路 |
| `cond` | **一串條件**，由上往下第一個真的贏 | 條件彼此無關（`(> x 100)`、`(string? x)`…）|
| `case` | 一個值，用 `=` 逐一比 | 拿同一個值比一串**常值**（像 C 的 `switch`）|
| `match` | 一個值，比**形狀**並**綁定**內容 | 值有結構（tuple、字典），你要拆開它 |

```janet
(cond (< x 0) :負 (zero? x) :零 :正)          # 最後一格沒配對 = else
(case kind :dog "汪" :cat "喵" "不認識")       # 同上，最後一格是 else
```

`cond` 和 `case` 沒中又沒有 else 時**回 `nil`**，不會報錯。

### ⚠ `case` 用 `=` 比，所以 array 永遠不中

```janet
(case [1 2]  [1 2] :中了 :沒中)   # => :中了    tuple 比內容
(case @[1 2] @[1 2] :中了 :沒中)  # => :沒中  ← ⚠ array 比「是不是同一個物件」
```

這是 [23 測試](23-測試怎麼寫.md) 那條 `=` 規則的延伸：**tuple／struct 不可變，比內容；
array／table 可變，比身分**。所以 `case` 只適合拿來比 keyword、數字、字串、tuple。
要比 array 的內容，用下面的 `match`——它兩種都吃。

## match：比形狀，順便把內容綁出來

一個 `match` 是「值 ＋ 一串 `模式 結果` 配對」。模式裡的**裸符號會綁定**，其他東西是常值：

```janet
(defn 描述 [x]
  (match x
    0                "零"                        # 常值
    [:add a b]       (+ a b)                    # :add 是常值，a b 綁定
    {:kind k}        (string "kind=" k)         # 字典：只比列出來的鍵
    (s (string? s))  (string "字串 " s)          # 守衛：綁 s，再檢查 (string? s)
    _                "都不是"))                  # _ = 什麼都吃

(描述 [:add 1 2])   # => 3
(描述 {:kind :dog :age 3})  # => "kind=dog"   ⚠ 多的鍵不影響，是子集比對
(描述 "hi")         # => "字串 hi"
(描述 99)           # => "都不是"
```

四件值得記的事：

1. **字典模式是子集比對**——`{:kind k}` 比得中 `{:kind :dog :age 3}`。
2. **守衛寫成 `(名字 條件)`**：先把值綁到 `名字`，再求值 `條件`，真才算中。
3. **同一個名字出現兩次 = 要求相等**：

   ```janet
   (match [1 1] [a a] :兩格相同 _ :不同)   # => :兩格相同
   (match [1 2] [a a] :兩格相同 _ :不同)   # => :不同
   ```
4. **沒中又沒 `_` 時回 `nil`**，跟 `cond` 一樣不報錯——所以漏寫一個分支會變成靜默的 `nil`。

`&` 收尾拿剩下的，巢狀模式可以一路拆下去：

```janet
(match [1 2 3 4] [a & rest] [a rest])   # => (1 (2 3 4))
(match {:pos [3 4]} {:pos [x y]} (+ x y))  # => 7
(match @[1 2] [a b] [a b])              # => (1 2)   ← array 也吃，跟 case 不同
```

### ⚠ 最大的坑：tuple 模式是「前綴」比對，不是長度相符

```janet
(match [1 2 3] [a b] :兩格 [a b c] :三格)   # => :兩格   ⚠ 不是 :三格！
(match [1 2 3] []    :空的)                 # => :空的   ⚠ 空模式吃掉一切
```

模式比值**短**照樣算中（只比前面幾格）；比值**長**才會不中。所以**模式要由長排到短**，
排反了短的會把長的全部遮住——而且不會有任何錯誤訊息，只是走錯分支。

真的要「剛好 N 格」就用守衛講明白：

```janet
(match v (t (and (indexed? t) (= 2 (length t)))) :剛好兩格 _ :不是)
```

## when-let 家族：綁定 ＋ 判斷一次做完

```janet
(when-let [x (get 設定 :port)] (* x 2))     # 綁得到才跑 body，否則 nil
(if-let  [x (get 設定 :port)] x 8080)       # 有 else 分支
(if-not  壞掉? :繼續 :中止)                  # 把條件反過來讀，少一層 not
```

`when-let` 可以綁**多個**，而且**由上往下、一遇到 `nil` 就整個放棄**——
後面的運算式**完全不會求值**：

```janet
(when-let [a 1 b nil c (error "這行不會跑")] [a b c])   # => nil，沒有爆
```

這等於是免費的短路檢查，串一連串「拿得到才繼續」的步驟時很好用。
資源要收尾（開檔、鎖）用 `when-with`，它是 `when-let` ＋ [20 的 `with`](20-錯誤處理與資源管理.md)。
