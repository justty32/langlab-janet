# 35b · 走訪與改寫巢狀資料

[← 35 拷貝與凍結](35-拷貝與凍結.md)

拿到一包巢狀的東西（JSON 解出來的設定、API 回應），要**每一層都動一下**——
`map` 只走一層，這篇講走到底的工具。

## `walk`：只走一層

```janet
(walk (fn [x] (if (number? x) (* 2 x) x)) [1 [2 3]])
# => (2 (2 3))      ⚠ 裡面的 2 3 沒有變
```

`walk` 把**每個直接子元素**交給函式，換掉，組回同型別的容器。它**不遞迴**——
`[2 3]` 整個被當成一個子元素傳進去，函式看它不是數字就原樣還回來。

`walk` 是底層積木，日常直接用下面兩個。

## `postwalk` / `prewalk`：走到底

兩個都會遞迴走完整棵樹，差別只在**先處理誰**：

```janet
(postwalk f [1 [2 3]])
# f 的拜訪順序：1 → 2 → 3 → (2 3) → (1 (2 3))     由內往外，葉子先

(prewalk f [1 [2 3]])
# f 的拜訪順序：(1 (2 3)) → 1 → (2 3) → 2 → 3     由外往內，根先
```

單純換值時兩者結果一樣：

```janet
(postwalk |(if (number? $) (* 2 $) $) {:a 1 :b [2 3]})   # => {:b (4 6) :a 2}
```

**差別在函式會改變結構的時候**：

- **`postwalk`**：子節點已經處理完了，你拿到的是**新的**子節點。想「由下往上重建」用它——
  例如把一棵運算式樹求值成一個數字。**這是預設選擇。**
- **`prewalk`**：你拿到的是**原始的**節點，換掉之後**換出來的東西還會再被走一遍**。
  想「由上往下展開」（巨集展開、把縮寫換成完整結構）才用它。

### ⚠ `prewalk` 很容易寫成無限遞迴

```janet
(defn f [n] (if (and (indexed? n) (= :x (get n 0))) [:y [:x]] n))
(prewalk f [:a [:x]])    # ⚠ 永遠跑不完
```

`f` 看到 `[:x]` 換成 `[:y [:x]]`，`prewalk` 接著往下走**換出來的東西**，
又看到一個 `[:x]`，再換一次……**這不會報錯，就是卡在那裡**（實測跑到 timeout）。

`postwalk` 沒有這個問題——它處理一個節點時，子節點已經定案了，不會回頭再走。
**所以：不確定要哪個就用 `postwalk`。**

## `next`：底層的迭代協定

`each`／`loop` 底下就是它。要自己控制走訪節奏（走一半停下、兩個結構交錯走）時才直接用：

```janet
(def t {:p 1 :q 2})
(var k (next t nil))          # nil 表示「從頭開始」
(while k
  (printf "%j → %j" k (t k))
  (set k (next t k)))         # 傳目前的鍵，回下一個鍵
# => :p → 1
#    :q → 2
```

規則兩條：**`(next 集合 nil)` 給第一個鍵**，**走到底回 `nil`**。
陣列的「鍵」是索引，所以它對 array 一樣能用。

⚠ 字典的走訪順序是 **hash 順序，不是插入順序**——
跟 [25 序列工具](25-序列工具.md) 講的是同一件事，別依賴它。

## 字典的日常操作

| 想做的事 | 寫法 | 回傳 |
|----------|------|------|
| 合併多個字典 | `(merge {:a 1} {:b 2} {:a 9})` | `@{:b 2 :a 9}` **後面蓋前面** |
| 合併進既有的 | `(merge-into t 其他)` | 改 `t` 本身 |
| 鍵值對調 | `(invert {:a 1 :b 2})` | `@{1 :a 2 :b}` |
| 對某個鍵套函式 | `(update @{:n 1} :n inc)` | `@{:n 2}` |
| 深層取值＋預設 | `(get-in {:a {}} [:a :zz] :預設)` | `:預設` |
| 深層塞值（沿路建） | `(put-in @{:a @{}} [:a :b] 5)` | `@{:a @{:b 5}}` |

⚠ **`merge` 一律回 `table`**，即使你餵給它的全是 `struct`。要不可變的結果自己再
`freeze` 一次（見 [35](35-拷貝與凍結.md)）。

⚠ **`update` 與 `put-in` 改的是原物件**，不是給你新的一份。名字沒有驚嘆號但有副作用，
這是 [25 序列工具](25-序列工具.md) 那條「驚嘆號＝原地改」規則的例外，記一下。

## 一個實際場景

從 API 拿回來的設定，要把所有字串裡的 `${HOME}` 換成真實路徑：

```janet
(defn 展開 [設定]
  (postwalk
    (fn [x]
      (if (string? x)
        (string/replace-all "${HOME}" (os/getenv "HOME") x)
        x))
    設定))
```

`postwalk` 一行走遍每一層，不管巢狀多深、也不管是 array 還是 table。
自己寫遞迴要處理型別分支、要記得組回同型別——這就是它省下來的東西。
