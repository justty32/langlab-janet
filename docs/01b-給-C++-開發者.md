# 01b · 給 C++ 開發者的對照

你已經會 C++，缺的不是「程式設計」，是**把既有概念對到 Janet 的名字**。
這篇就是那張對照表，外加五個你一定會誤會的地方。讀完再回頭看 01～02 會快很多。

## 一張對照表

| C++ | Janet | 備註 |
|-----|-------|------|
| `const int x = 1;` | `(def x 1)` | 預設就是不可變 |
| `int y = 1; y = 2;` | `(var y 1) (set y 2)` | 要寫 `var` 才能改 |
| `{ int a = 1; ... }` | `(let [a 1] ...)` | 區塊區域綁定 |
| `int f(int a, int b)` | `(defn f [a b] ...)` | 不寫型別 |
| `void f(int a = 3)` | `(defn f [&opt a] (default a 3) ...)` | 預設參數 |
| `f(std::vector<int>)` | `(defn f [& xs] ...)` | 可變參數 |
| `[](int x){ return x*2; }` | `(fn [x] (* x 2))` 或 `\|(* $ 2)` | lambda |
| `std::vector<T>` | `@[1 2 3]` array | 可變、連續 |
| `const std::array` | `[1 2 3]` tuple | 不可變 |
| `std::unordered_map` | `@{:a 1}` table | 可變 |
| `struct`（純資料） | `{:a 1}` struct | 不可變 |
| `std::string` | `@"abc"` buffer | 可變，見 [18](18-字串與-buffer.md) |
| `std::string_view` / `const char*` | `"abc"` string | 不可變 |
| `enum class` | `:red` `:green` keyword | 見 [13](13-symbol-keyword-字串.md) |
| `namespace` / `#include` | 模組 + `(import ...)` | 見 [05](05-jpm-與專案.md) |
| `template<...>` | 巨集 `defmacro` | 見 [08](08-巨集-macro.md) |
| RAII 解構子 | `defer` / `with` | 見 [20](20-錯誤處理與資源管理.md) |
| `try/catch/throw` | `try` / `error` | 同上 |
| `std::optional` 的空 | `nil` | 沒有 `std::nullopt` 這層 |
| 迭代器 for 迴圈 | `each` / `loop` / `seq` | 見 [01](01-語言速成.md) |
| `co_yield` 協程 | fiber `yield` | 見 [09](09-fiber.md) |
| `std::thread` | `ev/thread` | 見 [15](15-ev-channel-net.md) |

## 五個一定會誤會的地方

### ① `=` 有兩套語意：不可變比值，可變比身分

這是最容易吃悶虧的一條。C++ 的 `==` 一律走 `operator==`；Janet 分成兩套：

```janet
(= [1 2] [1 2])       # => true    tuple 不可變 → 比內容
(= {:a 1} {:a 1})     # => true    struct 同理
(= @[1 2] @[1 2])     # => false   array 可變 → 比「是不是同一個物件」
(deep= @[1 2] @[1 2]) # => true    要比內容得用 deep=
```

心法：**可變容器的 `=` 相當於 C++ 的 `&a == &b`（比指標）**，要比內容請用 `deep=`。
用 array/table 當 table 的 key 也會因此踩雷——請改用 tuple/struct 當 key。

### ② 變數傳遞永遠是「複製一個參考」，沒有值語意複製

C++ 預設 `std::vector<int> v2 = v1;` 是深拷貝；Janet 的 `(def b a)` 只是多一個名字指向同一份資料。

```janet
(def a @[1 2 3])
(def b a)
(array/push b 4)
(pp a)                # => @[1 2 3 4]   a 也變了
```

要真的拷貝：`(array/slice a)`（淺拷貝 array）、`(table/clone t)`（淺拷貝 table）、
`(freeze x)`（深拷貝成不可變版）、`(thaw x)`（深拷貝成可變版）。

```janet
(def c (array/slice a))   # 獨立的一份
(freeze @{:a @[1 2]})     # => {:a (1 2)}   整棵樹變不可變
```

不可變的 tuple/struct 不必操心這件事——這也是慣例上「優先用不可變」的理由。

### ③ 不寫型別，但型別是真的存在（動態強型別）

Janet 不做隱式轉型，比 C++ 還嚴格：

```janet
(+ 1 "2")          # 直接錯：could not find method :+ for 1 ...
(string "a" 1)     # => "a1"   字串串接只有這條路
(type 3)           # => :number
(type @[1])        # => :array
```

C++ 的 `int` 和 `double` 在 Janet 都是同一個 `:number`（IEEE 754 double）。
這對你很重要，細節見 [21 數字與位元](21-數字與位元.md)——`1 << 40` 的結果會讓你意外。

### ④ 沒有函式重載、沒有 template，取而代之的是巨集

Janet 只憑名字找函式，同名後定義的會蓋掉前一個。想做「同一段邏輯套不同型別」，
方向不是泛型，而是：動態型別本來就不挑型別；真的需要「產生程式碼」時才寫巨集。

巨集跟 template 的差別在於：template 在型別系統裡繞，巨集是**編譯期直接改寫語法樹**——
比較像威力加強版的 `#define`，但它操作的是結構化的程式碼而不是字串，所以不會有括號地獄。

### ⑤ 記憶體是 GC，但「資源」還是要你收

沒有 `new`／`delete`、沒有智慧指標，記憶體交給垃圾回收。
但檔案 handle、socket、子行程這些**非記憶體資源**沒人幫你關，這時用 `defer`／`with`：

```janet
(with [f (file/open "x.txt" :r)]   # 離開區塊自動 close，出錯也會關
  (print (file/read f :all)))

(defer (print "一定會跑") (do-something))   # 像 Go 的 defer
```

`with` 就是你熟悉的 RAII，只是作用域寫成明確的區塊，而不是綁在物件生命週期上。

## 幾個語法上的心理調適

- **前綴運算**：`(+ 1 2 3)` 不是 `1 + 2 + 3`。多讀幾天就順了，好處是 `+` 天然吃多個參數。
- **括號不是雜訊，是結構**：`()` 是呼叫、`[]` `{}` 是資料。編輯器會幫你配對，見 [06](06-編輯器與-REPL.md)。
- **`->` `->>` 是你的救星**：把巢狀攤成由上而下的管線，讀起來像 shell pipe。
- **REPL 是主要工具**：不是「跑一次看結果」，是開著 REPL 一句一句試，比 gdb 順手，見 [07](07-repl.md)。
- **只有 `nil` 和 `false` 為假**：`0`、`""`、空陣列全都是真。這跟 C++ 相反，很常踩。

## 心態上最大的一個差別

C++ 的做法是「先設計型別，再讓資料符合型別」。Janet 反過來：**資料就是那幾種通用結構
（array / table / tuple / struct），函式直接作用在資料上。** 你不會為了一個三欄的回傳值去
定義 struct，就直接回一個 `{:ok true :code 200 :body "..."}`。

一開始會覺得少了型別檢查很不安。實務上補救的方式是：REPL 隨時驗、`assert` 卡前提、
測試寫密一點（見 [05](05-jpm-與專案.md) 的 `jpm test`）。

## 可跑範例

```sh
janet examples/cpp-vs-janet.janet
```

上面那五個誤會全部做成「**C++ 直覺說 X → Janet 實際上 Y**」的並排實驗，
Y 是真的跑出來的。其中一個補上了本篇只說「會讓你意外」而沒給數字的：

```janet
(blshift 1 40)   # => 256      C++ 的 1 << 40 是 1099511627776
```

位元運算是 **32 位元**的，位移量被 mod 32——`40 → 8`，所以答案是 `1 << 8`。
不報錯、不警告（見 [21 數字與位元](21-數字與位元.md)）。
