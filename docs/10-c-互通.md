# 10 · 與 C 互通（FFI / native 模組 / 嵌入）

Janet 和 C 有三種接法，用途不同：

| 方式 | 一句話 | 要不要編 C | 何時用 |
|------|--------|-----------|--------|
| **FFI** | 執行期直接呼叫現成的 `.so` | 不用 | 想用系統 / 第三方共享庫，手邊只有 `.so` |
| **native 模組** | 用 C 寫一個 `(import ...)` 得到的模組 | 用 jpm 編 | 要寫高效能 / 貼近 C API 的 Janet 函式 |
| **嵌入** | 把 Janet runtime 塞進你的 C 程式 | 編 C | 主程式是 C，想拿 Janet 當腳本 / 設定語言 |

---

## 一、FFI：不編譯，直接呼叫共享庫

Janet 內建 `ffi` 模組，載入 `.so`、描述簽名、直接呼叫。三步：

```janet
(def libm (ffi/native "libm.so.6"))                 # 1) 載入共享庫
(def sig  (ffi/signature :default :double :double)) # 2) 描述簽名：回傳 double、收 double
(ffi/call (ffi/lookup libm "cos") sig 0.0)          # 3) 查符號 + 呼叫 => 1.0
```

`ffi/signature` 形狀：`(ffi/signature 呼叫慣例 回傳型別 & 參數型別)`。常用型別關鍵字：

`:void :bool :int :uint :long :size :float :double :ptr :string`（`:string` = 傳給 C 的
`const char*`）。

再一例，libc 的 `strlen`：

```janet
(def libc (ffi/native "libc.so.6"))
(def sig  (ffi/signature :default :size :string))
(ffi/call (ffi/lookup libc "strlen") sig "hello")   # => 5
```

完整可跑：[`examples/ffi-demo.janet`](../examples/ffi-demo.janet)。

> FFI 是**執行期**綁定：不需要編譯步驟，但你得自己把簽名寫對——寫錯型別會直接 segfault，
> 沒有編譯器幫你擋。所以拿它接穩定的 C API 最好。

### `ffi/defbind`：少寫一半樣板

每個函式都寫 `signature` + `lookup` + `call` 很煩。設一次 context，之後一行一個函式：

```janet
(ffi/context "libm.so.6")
(ffi/defbind cos :double [x :double])
(ffi/defbind pow :double [x :double y :double])
(cos 0.0)     # => 1
(pow 2 10)    # => 1024
```

`(ffi/context 路徑 &named map-symbols lazy)`：`:lazy true` 改成第一次呼叫才查符號
（庫可能不在時有用），`:map-symbols` 給函式做 Janet 名 → C 符號名的轉換。
