# 38 · 型別全表

教了四種「名字」。這篇把**全部型別**攤在一張表上，並講清楚那些「傘狀」判斷函式各罩住誰。

## `(type x)` 會回什麼：19 種

```janet
(type @[1])   # => :array
(type stdout) # => :core/file
```

| 分層 | 型別 | 字面值／取得方式 |
|------|------|-----------------|
| **單值** | `:nil` `:boolean` `:number` | `nil`、`true`／`false`、`1`／`1.5` |
| **byte 序列** | `:string` `:buffer` `:symbol` `:keyword` | `"s"`、`@"b"`、`'sym`、`:kw` |
| **索引容器** | `:tuple` `:array` | `[1]`、`@[1]` |
| **字典容器** | `:struct` `:table` | `{:a 1}`、`@{:a 1}` |
| **可呼叫** | `:function` `:cfunction` | 自己寫的 `(fn [] …)`；C 寫的內建（`print`）|
| **執行** | `:fiber` | `(fiber/new …)`（見 [09](09-fiber.md)）|
| **abstract** | `:core/file` `:core/peg` `:core/rng` `:core/s64` `:core/u64` … | `stdout`、`(peg/compile …)`、`(math/rng)`、`(int/s64 1)` |

⚠ **`nil` 有自己的型別 `:nil`**，不是「沒有型別」。`(type nil)` 回 `:nil`，不會爆。

### abstract 型別：`core/` 前綴就是識別特徵

**abstract type ＝ C 那邊實作、Janet 這邊只拿到一個把手的東西**——檔案、PEG、
亂數產生器、64 位元整數都是。它們的共同點是 `(type x)` 帶 **`core/` 前綴**，
而且 `(abstract? x)` 為真：

```janet
(abstract? stdout)          # => true
(abstract? @[1])            # => false
```

實務上你不用管它是 abstract，只要知道兩件事：
**它們不能 `marshal`**（除非該型別自己支援，見 [16](16-marshal-與自省.md)），
而且**要自己收尾**（`file/close`，或用 `with`，見 [20](20-錯誤處理與資源管理.md)）。

## 傘狀判斷函式：一個罩一整組

每個型別都有自己的 `array?`／`table?`／`string?`，但**寫函式時通常該用傘狀的那組**——
你關心的是「能不能走訪」，不是「是不是恰好 array」：

| 傘狀函式 | 罩住 | 什麼時候用 |
|---------|------|-----------|
| `bytes?` | string、buffer、symbol、keyword | 「這是一串 byte 嗎」——這四個都能 `length`、能索引 |
| `indexed?` | tuple、array | 「這是有順序的清單嗎」 |
| `dictionary?` | struct、table | 「這是鍵值對嗎」 |
| `lengthable?` | 上面全部八個 | 「`(length x)` 不會爆嗎」 |
| `abstract?` | 所有 `:core/…` | 「這是 C 那邊來的把手嗎」 |

```janet
(bytes? :kw)        # => true    ⚠ keyword 也算 byte 序列
(indexed? {:a 1})   # => false   字典不是 indexed
(lengthable? 5)     # => false   數字沒有長度
```

⚠ **`bytes?` 包含 keyword 和 symbol**，這常常出乎意料。要「真的是字串」就用
`string?`，要「字串或 buffer」就 `(or (string? x) (buffer? x))`。

## ⚠ 沒有 `callable?`——而且「可呼叫」比 `function?` 廣

```janet
(function? "abc")   # => false
("abc" 1)           # => 98      ⚠ 但它真的可以被呼叫
```

[34 讀錯誤訊息](34-讀錯誤訊息.md) 講過：**資料結構本身可呼叫，效果是索引自己**。
所以「這東西能不能拿來當函式用」沒有單一的判斷函式：

- 要「真的是函式」→ `(or (function? f) (cfunction? f))`。
- 要「能放在呼叫位置」→ 上面那組再加 `bytes?`、`indexed?`、`dictionary?`。

實務上直接照你的意圖檢查就好，不要試圖寫一個通用的 `callable?`。

## ⚠ 數字的三個判斷會騙你

Janet **全部數字都是 double**（[21 數字與位元](21-數字與位元.md)），所以：

```janet
(int? 1.0)            # => true    ⚠ 1.0 是整數值，型別上跟 1 沒差別
(int? 1.5)            # => false
(int? 3000000000)     # => false   ⚠ 超過 32-bit 有號範圍
(nat? 3000000000)     # => false   同上
(nat? 0)              # => true    「非負」含 0
```

**`int?` 與 `nat?` 問的不是「型別是不是整數」**，是「這個值能不能塞進
32 位元有號整數」。三十億塞不進去所以是 `false`，即使它明明是個整數。

要判斷「數學上是整數」用 `(= x (math/floor x))`；要大整數用 `int/s64`／`int/u64`。

## 型別轉換

| 從 → 到 | 怎麼做 |
|---------|--------|
| 任何值 → 顯示用字串 | `(string/format "%q" x)`（見 [18](18-字串與-buffer.md)）|
| 字串 → 數字 | `(scan-number "42")`，失敗回 `nil`（**不是拋錯**）|
| 數字 → 字串 | `(string 42)` |
| 字串 ↔ symbol ↔ keyword | `(symbol "s")`／`(keyword "s")`／`(string :kw)`（見 [13](13-symbol-keyword-字串.md)）|
| 可變 ↔ 不可變 | `(freeze x)`／`(thaw x)`（見 [35](35-拷貝與凍結.md)）|
| buffer → string | `(string buf)` |
| 字典 → 鍵／值清單 | `(keys d)`／`(values d)`／`(pairs d)` |

⚠ **Janet 不會自動轉型**：`(+ 1 "1")` 不會變成 2，會報
`could not find method :+ for 1`（[02](02-資料結構.md) 那條規則）。要轉就明講。
