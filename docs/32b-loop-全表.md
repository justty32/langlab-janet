# 32b · loop 全表

[← 32 條件與模式比對](32-條件與模式比對.md)

`loop` **不是一個迴圈語法，是一個小 DSL**——它的靈感來自 Common Lisp 的 `loop`，
但刻意做小。你可以在一個 `loop` 裡疊多層、加過濾、綁中間值、設定前後動作。

形狀固定是**一個 head tuple ＋ body**：

```janet
(loop [綁定 :verb 對象  綁定 :verb 對象  :條件詞 運算式] body...)
```

`loop` **永遠回傳 `nil`**（它是拿來做副作用的）。要收集結果用 `seq`／`tabseq`／`catseq`，
head 的寫法**完全一樣**——所以這篇學會的 verb，那三個推導直接照用。

## 八個 verb（決定「走什麼」）

| verb | 對象 | 走出來的是 | 實測 |
|------|------|-----------|------|
| `:range` | `[起 迄]` 或 `[起 迄 步長]` | 數字，**半開區間 `[起, 迄)`** | `[0 3]` → `0 1 2`；`[0 7 2]` → `0 2 4 6` |
| `:range-to` | 同上 | 同上但**含尾** `[起, 迄]` | `[0 3]` → `0 1 2 3` |
| `:down` | `[起 迄]` 或 `[起 迄 步長]` | 數字，往下走、**不含尾** | `[3 0]` → `3 2 1`；`[6 0 2]` → `6 4 2` |
| `:down-to` | 同上 | 往下走、**含尾** | `[3 0]` → `3 2 1 0` |
| `:in` | 任何資料結構或 fiber | **值** | `{:p 1 :q 2}` → `1 2`；`"ab"` → `97 98` |
| `:keys` | 任何資料結構 | **鍵**（陣列的鍵是索引）| `{:p 1 :q 2}` → `:p :q`；`[10 20 30]` → `0 1 2` |
| `:pairs` | 任何資料結構 | `[鍵 值]` 兩格 tuple | `{:p 1}` → `(:p 1)` |
| `:iterate` | 一個運算式 | 反覆求值並綁定，**直到它是假值** | 用來包「還有下一個嗎」這種 API |

⚠ **`:in` 走字串拿到的是 byte 數字不是字元**（`"ab"` → `97 98`），
跟 [18 字串與 buffer](18-字串與-buffer.md)、[25 序列工具](25-序列工具.md) 是同一條規則。

### ⚠ `:range` 的負步長會**靜默給你空的**

```janet
(seq [i :range [3 0 -1]] i)   # => @[]      ⚠ 沒有錯誤訊息，就是空的
(range 3 0 -1)                # => @[3 2 1] ← 同名的「函式」卻正常
```

`loop` 的 `:range` 步長**必須是正數**（docstring 明講 optional **positive** step），
給負的它不報錯、直接一圈都不跑。而內建函式 `range` 吃負步長。
**同一個名字、兩套規矩**——要倒著走一律用 `:down`／`:down-to`。

## 八個條件詞（決定「怎麼走」）

| 條件詞 | 作用 | 記法 |
|--------|------|------|
| `:when 條件` | 條件為真才跑 body | 過濾，**不中止** |
| `:unless 條件` | 條件為假才跑 body | `:when` 的反面 |
| `:while 條件` | 條件變**假**就跳出 | 提前中止 |
| `:until 條件` | 條件變**真**就跳出 | `:while` 的反面 |
| `:let [綁定…]` | 在圈內綁中間值 | 跟 `let` 同語法 |
| `:before 運算式` | 進入下一層內圈**之前**跑 | 見下方 ⚠ |
| `:after 運算式` | 內圈跑完**之後**跑 | 同上 |
| `:repeat n` | 把下一層內圈重複 n 次 | 不需要計數變數時用 |

```janet
(seq [i :range [0 6] :when (even? i)] i)      # => @[0 2 4]
(seq [i :range [0 9] :while (< i 3)] i)       # => @[0 1 2]
(seq [i :range [0 3] :let [sq (* i i)]] sq)   # => @[0 1 4]
(loop [:repeat 3] (print "x"))                # 印三次
```

### ⚠ `:before` / `:after` 是**每圈都跑**，不是頭尾各一次

```janet
(def a @[])
(loop [i :range [0 2] :before (array/push a :b) :after (array/push a :a)]
  (array/push a i))
a   # => @[:b 0 :a :b 1 :a]     ⚠ 不是 @[:b 0 1 :a]
```

名字聽起來像「迴圈開始前／結束後」，實際上是**每一輪的內圈前後**。
要真的頭尾各一次，就寫在 `loop` 外面。

## 多層與條件詞的作用範圍

**每多一組綁定就多一層巢狀迴圈**，而條件詞**只作用在它前面那一層**：

```janet
(seq [i :range [0 3] :when (odd? i)  j :range [0 2]] [i j])
# => @[(1 0) (1 1)]
```

`:when (odd? i)` 卡在 `i` 那一層，所以 `i` 是偶數時**連內層的 `j` 迴圈都不會開**。
把它移到最後面就變成過濾每一個 `[i j]` 組合——位置決定效率，也決定語意。

## 什麼時候不要用 loop

`loop` 很萬能，但**單純走一圈時它比較吵**。這幾個短形式更好讀：

| 想做的事 | 短形式 | 等價的 loop |
|----------|--------|-------------|
| 走每個值 | `(each x 集合 …)` | `(loop [x :in 集合] …)` |
| 走每個鍵 | `(eachk k 集合 …)` | `(loop [k :keys 集合] …)` |
| 走每對 | `(eachp [k v] 集合 …)` | `(loop [[k v] :pairs 集合] …)` |
| 數 i 從 0 到 n | `(for i 0 n …)` | `(loop [i :range [0 n]] …)` |

`forv` 跟 `for` 一樣，差別只在它用 `var` 綁，body 裡可以改那個計數變數。
`break` 在這些形式裡都能用，跳出最內層那圈。

**收集結果**就換成推導，head 語法不變（見 [25 序列工具](25-序列工具.md)）：

```janet
(seq    [i :range [0 4] :when (odd? i)] i)   # => @[1 3]      收成 array
(tabseq [i :range [1 3]] i (* i i))          # => @{1 1 2 4}  收成 table
(catseq [i :range [1 3]] [i i])              # => @[1 1 2 2]  收完攤平
```
