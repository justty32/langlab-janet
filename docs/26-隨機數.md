# 26 · 隨機數

Janet 給你**三套**隨機數，用途完全不同，選錯會出事：

| 你要的 | 用 | 一句話 |
|--------|-----|--------|
| 隨手要個亂數 | `math/random` | 全域共用一顆，最短 |
| **可重現**的亂數（測試、模擬） | `math/rng` 系列 | 自己拿一顆，餵種子就每次一樣 |
| **密碼、token、salt** | `os/cryptorand` | 作業系統的安全亂數 |

## 先講清楚：「偽隨機」是什麼意思

`math/random` 和 `math/rng` 產生的是 **PRNG（偽隨機數）**——它其實是一條**完全確定的
數列**，只是看起來很亂。給它一個起點（**種子 seed**），後面每一個數就都定死了。
這聽起來像缺點，其實是**最有用的性質**：同種子 → 同一串數字 → **bug 重現得出來**。

```janet
(def r1 (math/rng 42))
(map (fn [_] (math/rng-int r1 100)) (range 5))   # => @[30 62 19 17 22]

(def r2 (math/rng 42))                            # 同樣的種子
(map (fn [_] (math/rng-int r2 100)) (range 5))   # => @[30 62 19 17 22]  一模一樣
```

⚠ 但也正因為「確定」，**PRNG 絕對不能拿來做密碼相關的事**——知道種子的人可以算出你之後所有的「亂數」。那種場合看最後一節。

## 一、math/random：最短的那條路

```janet
(math/random)          # => 0.487181187691715   ← 永遠是 [0, 1) 的小數
```

只有這一個函式，不吃參數，**回傳 0 到 1 之間的小數**（含 0、不含 1）。要別的範圍自己乘：

```janet
(math/floor (* 6 (math/random)))          # 0..5
(inc (math/floor (* 6 (math/random))))    # 1..6，擲一顆骰子
```

## ⚠ 這篇最大的坑：預設**每次跑都一樣**

從別的語言過來的人都會假設 `math/random` 每次執行程式都給不同的數。**Janet 不是。**
實測連跑三次同一支程式：

```sh
$ janet -e '(print (math/random))'   # 0.487181187691715
$ janet -e '(print (math/random))'   # 0.487181187691715   ← 一樣！
$ janet -e '(print (math/rng-int (math/rng) 1000000))'   # 213634，再跑還是 213634
```

**全域那顆產生器、以及不給種子的 `(math/rng)`，都是從一個固定起點開始的**，
沒有人幫你用時間去種。所以「隨機取一句問候語」的程式，每次跑都會給你同一句。

要真的每次不同，**你得自己種**：

```janet
(math/seedrandom (os/time))              # 全域那顆；同一秒內起動的行程仍會相同
(math/rng (get (os/cryptorand 4) 0))     # 自己那顆；連同一秒都不會撞
```

> 這其實是個好的預設——**預設可重現**代表你的測試天生就是穩的，
> 要不確定性才需要明講。只是它跟直覺相反，不知道會找很久。

⚠ **全域狀態的老問題**：你的函式庫呼叫 `math/seedrandom`，就把**整個程式**的隨機性
綁死了，包括別人的程式碼。**寫函式庫請用下面的 `math/rng`**，別動全域那顆。

## 二、math/rng：自己拿一顆產生器

```janet
(def r (math/rng 2026))     # 給種子 => 可重現
(def r (math/rng))          # 不給 => 也是固定起點！見上面那個坑
```

`math/rng` 回一個 `:core/rng` 型別的**物件**，之後所有取數都對它要。
好處是**它是你的**，跟全域無關，兩顆 rng 互不干擾。

三個取數的方法：

```janet
(math/rng-int r 6)        # => 0..5 的整數（不含 6）
(math/rng-int r)          # 不給上限 => 0..約 21 億的整數（32-bit 範圍）
(math/rng-uniform r)      # => [0, 1) 的小數，等同 math/random 但用你這顆
(math/rng-buffer r 8)     # => @"_\xF5\x1A\x03\xD6h\xE8\x02"  八個隨機 byte
```

⚠ `math/rng-int` 的上限是**不含**的：`(math/rng-int r 6)` 給你 `0`–`5`。
要 1–6 記得 `inc`。這是最常見的差一錯誤。

## 四、要安全的亂數：os/cryptorand

密碼、session token、salt、API key——這些場合**必須**用作業系統的密碼學亂數源：

```janet
(os/cryptorand 8)    # => @"\xA4\xAFD\x19\xFA\xAA\xAE\xEC"  回一個 buffer
```

它**沒有種子、不可重現**，這正是重點：沒有人能從先前的輸出推出下一個。
代價是比 PRNG 慢，而且沒辦法拿它寫可重現的測試。

> **一句話判斷**：這個亂數被人猜到會不會有安全後果？
> 會 → `os/cryptorand`；不會（洗牌、模擬、抽樣、測資）→ `math/rng`。

## 可重現的測試怎麼寫

這是 `math/rng` 最實際的用途——把種子當參數傳進去，測試就變成確定的：

```janet
# 生產程式碼：rng 從外面給（shuffle! 的實作在 26b）
(defn 發牌 [rng] (take 5 (shuffle! (array ;(range 52)) rng)))

# 測試：餵固定種子，結果每次都一樣
# （take 回的是 tuple，所以期望值寫 [...] 不是 @[...]，見 25 的「規則一」）
(assert (deep= [42 25 39 43 38] (發牌 (math/rng 2026))) "同種子要給同樣的牌")
```

⚠ 反過來說，**函式裡直接呼叫 `math/random` 的程式碼是沒辦法測的**。
把 rng 當參數傳進去（依賴注入）就解決了。測試怎麼寫見
[23 測試怎麼寫](23-測試怎麼寫.md)。
