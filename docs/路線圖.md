# 教學路線圖 · 先讀哪一篇

[← docs 目錄](README.md)

[README](README.md) 是**有哪些篇**的索引；這份是**該照什麼順序讀**。
不知道從哪開始就照下面走。

> **先講一件事**：教學裡幾乎每篇都配一支**可跑的範例**，跑法寫在該篇的「可跑範例」段。
> 那些範例不是裝飾——⚠ 標記的坑幾乎都在裡面**當場印出來**給你看。
> 讀到覺得「真的假的」的地方，就去跑那一支。

## 最快上手路線

> 沒碰過 Lisp、想被人牽著一課一課走？先上 [course/ 從零課程](../course/README.md)，這條路線是給有底子的人。

1. `janet` 開 REPL（[07](07-repl.md)），把 [01](01-語言速成.md) 的片段貼進去玩。
   配 `janet examples/quickstart.janet` 一起看。
2. [02 資料結構](02-資料結構.md) 建立 array / table 的手感（`examples/data-structures.janet`）。
3. 最常用的兩個庫：[03 JSON](03-json.md) 和 [04 argparse](04-cli-argparse.md)（含子命令）。
4. 開始寫比較大的東西時，[語言細節那一區](語言細節索引.md)（32–40）就是你會撞到的清單。
5. 進階招牌：[14 PEG](14-peg.md)、[09 fiber](09-fiber.md) ＋ [15 ev/net](15-ev-channel-net.md)、
   [08 macro](08-巨集-macro.md)、[10 C 互通](10-c-互通.md)。

## 從 C++ 過來的路線

先 [01 語言速成](01-語言速成.md)，再 [**01b 給 C++ 開發者的對照**](01b-給-C++-開發者.md)
——一張概念對照表加五個一定會誤會的地方，讀完之後 02 以後會快非常多。
**那五個誤會有一支並排實驗**：`janet examples/cpp-vs-janet.janet`，左邊是 C++ 直覺、
右邊是 Janet 真的跑出來的結果。

之後照這個順序，全部都是「跟 C++ 差最多、早點看少踩坑」的：

1. [01d 提早離開](01d-提早離開-return-break-continue.md)——第一天就會撞到：**沒有 `return`／`continue`**
2. [43 從 C／C++ 過來](43-從-C-C++-過來.md)（＋43b、43c）——日常語法逐條對照，一次問完
   「我熟的那招怎麼寫」（Lua 走 [44](44-從-Lua-過來.md)、Go 走 [45](45-從-Go-過來.md)）
3. [01c 解構與執行緒巨集](01c-解構與執行緒巨集.md)——壓縮樣板碼的兩招，之後到處會用到
4. [02 資料結構](02-資料結構.md) → [02b 方法呼叫語法與 prototype](02b-方法與-prototype.md)
   （Janet 全部的 OOP 就這麼多）
5. [21 數字與位元](21-數字與位元.md)——**數字模型差最多**：全是 double、位元運算只有 32 位元
6. [20 錯誤處理](20-錯誤處理與資源管理.md) → [20b 資源管理](20b-資源管理.md)（`with` 就是 RAII）
7. [33 函式參數與閉包](33-函式參數與閉包.md)——閉包捕獲的是綁定，接近 C++ 的 `[&]` 但沒有懸空參考
8. [35 拷貝與凍結](35-拷貝與凍結.md)——「沒有值拷貝，那我怎麼拿一份自己的」
9. [34 讀錯誤訊息](34-讀錯誤訊息.md)——⚠ **尾呼叫會吃掉堆疊那一層**，不知道會找很久
10. [18 字串](18-字串與-buffer.md) ＋ [19 檔案](19-檔案與檔案系統.md)（開始真的寫東西）
11. [08 巨集](08-巨集-macro.md)（template 的替代品）、[10 C 互通](10-c-互通.md)（把重活丟回 C）

## 標記與慣例

- **⚠ 標記**＝實測踩過的坑，不是理論上的注意事項。**幾乎每個都在對應範例裡跑得到。**
- **★ 標記**（目錄裡）＝這篇最值得記住的一件事。
- 每篇結尾都有「下一步」連結，可以一路讀下去。
- 想查**某個領域完整有哪些函式** → [`reference/`](../reference/README.md)；
  想**一眼掃完** → [`cheatsheets/`](../cheatsheets/README.md)（瀏覽器開 `html/index.html` 可全文搜尋）；
  想**抄一段來改** → [`snippets/`](../snippets/README.md)。
- 環境／API 的踩坑記錄另外收在 [`FINDINGS-踩坑.md`](../FINDINGS-踩坑.md)（LLM 與模組）
  與 [`FINDINGS-踩坑b-工具鏈.md`](../FINDINGS-踩坑b-工具鏈.md)（jpm／import）。
