# 47e · 圖像輸入

**圖不是另外開一個欄位。** 你只是把那則 `user` 訊息的 `content` 從「一個字串」
換成「一個 parts 陣列」，圖以 data URI 的形式當成其中一個 part。

前一篇：[47d 自己寫一個 agent loop](47d-自己寫-agent-loop.md)。
可跑範例（離線）：[`../examples/agent-tutorial/47e-vision.janet`](../examples/agent-tutorial/47e-vision.janet)。

## 兩種 content

```janet
(llm/user-message "What colour is it?")
# @{:role "user" :content "What colour is it?"}

(llm/user-message "What colour is it?" ["red.png"])
# @{:role "user" :content [@{:type "text"      :text "What colour is it?"}
#                          @{:type "image_url" :image_url @{:url "data:image/png;base64,…"}}]}
```

純文字那條路**刻意保持是字串**，不要為了統一改成單元素陣列——
所有後端都吃字串，parts 陣列反而有後端挑剔。

文字 part 放前面、圖依序在後。一則訊息可以帶多張圖。

## data URI

`data:<mime>;base64,<內容>`，三段接起來就是一個字串。

```janet
(llm/data-uri "red.png")
# "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg…"
```

實測（範例第 ③ 段，16×16 的紅色 PNG）：

```
前綴   = data:image/png;base64
mime   = image/png（副檔名猜的，認不出來就當 image/png）
原檔   = 79 bytes
編完後 = 130 字元   ← base64 膨脹約 4/3，整份塞進 JSON body 送出去
```

⚠ **圖是整份塞進 JSON body 的**。base64 膨脹約 4/3，幾 MB 的照片會讓一次請求變成
十幾 MB 的字串，慢、貴、而且可能撞到後端的 body 上限。**大圖自己先縮。**

⚠ mime 是**依副檔名猜**的（`.png`／`.jpg`／`.jpeg`／`.gif`／`.webp`），認不出來一律當
`image/png`。多數後端會自己看 magic bytes，所以猜錯通常不致命，但別依賴這點。

圖也可以直接給網址，那時就不會去讀本機檔案：

```janet
(llm/image-part "https://example.com/a.png")
# @{:type "image_url" :image_url @{:url "https://example.com/a.png"}}
```

判斷規則很簡單：開頭是 `http` 或 `data:` 就原樣用，否則當本機路徑去 `slurp`。

## 送出去

`ask` 的第三個參數就是圖檔陣列（不要 system 的話第二個給 `nil`）：

```janet
(llm/ask cfg "What colour is it?" nil ["red.png"])
```

範例第 ④ 段裡假後端把它看到的講了出來，證明圖真的到了 wire 上：

```
(fake) I got 2 parts: text, image_url
後端收到的 content 形狀：陣列
```

## ⚠ 不是每個模型都吃圖

這是最容易吃悶虧的一點：**送圖給純文字模型，行為從報錯到靜默無視都有**。
靜默無視最難查——你會拿到 exit 0 加一段看起來像答案的東西，
模型只是把文字讀一讀就自己掰了。

所以 endpoint 設定有一個 `:vision?` 欄位，專門標這件事：

```janet
(llm/endpoint {:model "…" :url "…" :vision? true})
```

| 這台後端 | 吃圖嗎 |
|----------|--------|
| LM Studio 上的 gemma-4 系列 | 可以（本 repo 實測過） |
| DeepSeek 現行的純文字模型 | 不行 |
| Claude、GPT-4o 這類 | 可以 |
| OpenRouter | 看你選的 slug |

判斷方法只有一個：**看你要打的那顆模型的文件**，不要靠試。
CLI 在 `--image` 搭配 `:vision? false` 的 endpoint 時會先在 stderr 警告。

## 這裡沒講的

音訊、影片、圖像**生成**、`modalities` 參數——都不在這條路上。
本 repo 的 `llm-http` 只做「圖當輸入」這一件事。
