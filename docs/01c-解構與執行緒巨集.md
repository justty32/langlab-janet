# 01c · 解構與執行緒巨集

解構（destructuring）與執行緒巨集（`->` `->>`）都是把樣板碼壓短的慣用寫法，
從 [01 語言速成](01-語言速成.md) 拆出來自成一篇。

## 解構（destructuring）

`def` / `var` / `let` / 函式參數 / `each` 的綁定位置，都可以直接寫成結構的形狀：

```janet
(def [a b & rest] [1 2 3 4])            # a=1 b=2 rest=(3 4)
(def {:name n :age g} {:name "Al" :age 3})  # n="Al" g=3
(def [x [y z]] [1 [2 3]])               # 巢狀也行

(defn f [[a b] {:k k}] [a b k])         # 參數位置直接拆
(f [1 2] {:k 9})                        # => (1 2 9)

(defn g [&keys {:host h :port p}] [h p])   # 具名參數
(g :host "x" :port 80)                     # => ("x" 80)

(each [k v] (pairs {:a 1}) (pp [k v]))     # 走訪 key-value
```

會少寫非常多 `(x 0)` `(x 1)` 這種索引。

## 執行緒巨集（把巢狀攤平）

```janet
(-> 5 (+ 3) (* 2))                 # 前一個結果塞「第一個」參數 => 16
(->> [1 2 3] (map inc) (filter even?))  # 塞「最後一個」參數 => @[2 4]
(-?> nil (get :a))                 # 遇到 nil 就短路，不再往下 => nil
(as-> 5 $ (+ $ 1) (* $ $))         # 自己指定塞哪 => 36
```

慣例：資料處理鏈（`map`/`filter` 這種資料在最後的）用 `->>`，
物件式的（資料在最前的）用 `->`。
