# 19 · 檔案與檔案系統

檔案操作分兩層：**整個檔案一次讀寫**（`slurp`／`spit`）跟 **file handle**（`file/*`）。
路徑與目錄相關的在 `os/*`，跨平台路徑組合用 `spork/path`。

## 九成情況：slurp / spit

```janet
(spit "out.txt" "hello\n")            # 寫入（整個蓋掉），回傳 nil
(spit "out.txt" "more\n" :ab)         # 附加。⚠ 用 :ab 不要用 :a，理由見下方換行陷阱
(def s (slurp "out.txt"))             # 讀成一個 string
```

`slurp` 讀不到檔案會**拋錯**（不是回 nil），所以要嘛先確認存在、要嘛包 `try`：

```janet
(if (os/stat "out.txt")
  (print (slurp "out.txt"))
  (print "檔案不在"))

(def content (try (slurp "maybe.txt") ([_] nil)))   # 讀不到就當 nil
```

## 需要逐行 / 串流時：file handle + with

```janet
(with [f (file/open "big.log" :r)]     # 離開區塊自動 close，出錯也會關
  (while (def line (file/read f :line))
    (prin line)))
```

`with` 就是 RAII——不用寫 `file/close`，也不會因為中途 `error` 而漏關。細節見
[20-錯誤處理與資源管理.md](20-錯誤處理與資源管理.md)。

`file/read` 的第二個參數：

| 寫法 | 讀什麼 |
|------|--------|
| `:line` | 一行（含換行字元），沒了回 `nil` |
| `:all` | 剩下全部 |
| `1024` | 最多 1024 bytes |

⚠ **`file/read` 回傳的是 buffer 不是 string**。要拿去當 table 的 key、或做 `=` 比較，
先 `(string ...)` 轉一次，理由見 [18](18-字串與-buffer.md)。

### 開檔模式

`:r` 讀、`:w` 寫（清空）、`:a` 附加，後面加 `b` 是二進位（`:rb` `:wb` `:ab`），加 `+` 是讀寫。

也可以用方法呼叫語法，跟 `file/xxx` 完全等價，看你喜歡哪種：

```janet
(with [f (file/open "x.txt" :w)]
  (:write f "abc\n")        # 等於 (file/write f "abc\n")
  (:flush f))
```

## ⚠ Windows 上的換行陷阱（實測）

文字模式開檔（`:w`／`:a`／`:r`）在 Windows 會**自動把 `\n` 翻成 `\r\n`**，`spit` 則不會：

```janet
(with [f (file/open "a.txt" :w)] (:write f "x\n"))
(slurp "a.txt")     # => @"x\r\n"   ← 多了 \r

(with [f (file/open "b.txt" :wb)] (:write f "x\n"))
(slurp "b.txt")     # => @"x\n"     ← 二進位模式不翻譯

(spit "c.txt" "x\n")
(slurp "c.txt")     # => @"x\n"     ← spit 預設就是二進位，不翻譯

(spit "d.txt" "x\n" :a)     # ⚠ 但附加模式寫 :a 就變文字模式了
(slurp "d.txt")     # => @"x\r\n"   ← 又冒出 \r，要寫 :ab 才對
```

所以「同一份內容用兩種方式寫出來，檔案不一樣大」。要跨平台一致（尤其是雜湊比對、
二進位格式、跟外部工具對接），**一律明寫 `b`：`:rb` `:wb` `:ab`**。
