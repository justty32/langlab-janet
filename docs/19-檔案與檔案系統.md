# 19 · 檔案與檔案系統

檔案操作分兩層：**整個檔案一次讀寫**（`slurp`／`spit`）跟 **file handle**（`file/*`）。
路徑與目錄相關的在 `os/*`，跨平台路徑組合用 `spork/path`。

## 九成情況：slurp / spit

```janet
(spit "out.txt" "hello\n")            # 寫入（整個蓋掉），回傳 nil
(spit "out.txt" "more\n" :ab)         # 附加。⚠ 用 :ab 不要用 :a，理由見下方換行陷阱
(def s (slurp "out.txt"))             # 讀成一個 string
```

`slurp` 讀不到檔案會**拋錯**（不是回 nil），所以要嘛先確認存在、要嘛包 `try`：

```janet
(if (os/stat "out.txt")
  (print (slurp "out.txt"))
  (print "檔案不在"))

(def content (try (slurp "maybe.txt") ([_] nil)))   # 讀不到就當 nil
```

## 需要逐行 / 串流時：file handle + with

```janet
(with [f (file/open "big.log" :r)]     # 離開區塊自動 close，出錯也會關
  (while (def line (file/read f :line))
    (prin line)))
```

`with` 就是 RAII——不用寫 `file/close`，也不會因為中途 `error` 而漏關。細節見
[20-錯誤處理與資源管理.md](20-錯誤處理與資源管理.md)。

`file/read` 的第二個參數：

| 寫法 | 讀什麼 |
|------|--------|
| `:line` | 一行（含換行字元），沒了回 `nil` |
| `:all` | 剩下全部 |
| `1024` | 最多 1024 bytes |

⚠ **`file/read` 回傳的是 buffer 不是 string**。要拿去當 table 的 key、或做 `=` 比較，
先 `(string ...)` 轉一次，理由見 [18](18-字串與-buffer.md)。

### 開檔模式

`:r` 讀、`:w` 寫（清空）、`:a` 附加，後面加 `b` 是二進位（`:rb` `:wb` `:ab`），加 `+` 是讀寫。

也可以用方法呼叫語法，跟 `file/xxx` 完全等價，看你喜歡哪種：

```janet
(with [f (file/open "x.txt" :w)]
  (:write f "abc\n")        # 等於 (file/write f "abc\n")
  (:flush f))
```

## ⚠ Windows 上的換行陷阱（實測）

文字模式開檔（`:w`／`:a`／`:r`）在 Windows 會**自動把 `\n` 翻成 `\r\n`**，`spit` 則不會：

```janet
(with [f (file/open "a.txt" :w)] (:write f "x\n"))
(slurp "a.txt")     # => @"x\r\n"   ← 多了 \r

(with [f (file/open "b.txt" :wb)] (:write f "x\n"))
(slurp "b.txt")     # => @"x\n"     ← 二進位模式不翻譯

(spit "c.txt" "x\n")
(slurp "c.txt")     # => @"x\n"     ← spit 預設就是二進位，不翻譯

(spit "d.txt" "x\n" :a)     # ⚠ 但附加模式寫 :a 就變文字模式了
(slurp "d.txt")     # => @"x\r\n"   ← 又冒出 \r，要寫 :ab 才對
```

所以「同一份內容用兩種方式寫出來，檔案不一樣大」。要跨平台一致（尤其是雜湊比對、
二進位格式、跟外部工具對接），**一律明寫 `b`：`:rb` `:wb` `:ab`**。

## 檔案資訊：os/stat

```janet
(os/stat "x.txt")             # 整包資訊 table，檔案不存在回 nil
(os/stat "x.txt" :size)       # => 12          只要一項時直接指定，比較省
(os/stat "x.txt" :mode)       # => :file / :directory / :link
(os/stat "x.txt" :modified)   # => 秒數（number）
```

`os/stat` 回 `nil` 就是**判斷檔案存在**的標準寫法——Janet 沒有 `file/exists?`：

```janet
(defn exists? [p] (truthy? (os/stat p)))
(defn dir? [p] (= :directory (os/stat p :mode)))
```

## 目錄與路徑操作

```janet
(os/cwd)                    # 目前工作目錄
(os/dir ".")                # => @["a.txt" "sub"]  只有名字，不含路徑、不遞迴
(os/mkdir "newdir")         # 已存在回 false，不會拋錯
(os/rm "x.txt")             # 刪檔案 / 空目錄
(os/cd "sub")
(os/which)                  # => :windows / :linux / :macos
```

⚠ `os/dir` **不遞迴**、回傳的也只是檔名。要走整棵樹得自己遞迴，或用
`spork/sh` 的 `sh/list-all-files`：

```janet
(import spork/sh)
(pp (sh/list-all-files "docs"))    # 遞迴列出所有檔案（含路徑）
```

### 用 spork/path 組路徑，不要自己接字串

```janet
(import spork/path)
(path/join "a" "b" "c.txt")   # => "a\\b\\c.txt"（Windows）/ "a/b/c.txt"（Linux）
(path/basename "a/b/c.txt")   # => "c.txt"
(path/dirname "a/b/c.txt")    # => "a/b/"   ⚠ 尾巴帶分隔符
(path/ext "a/b/c.txt")        # => ".txt"   ⚠ 帶點
(path/abspath "x")            # => 以目前 cwd 展開的絕對路徑
```

`path/join` 會用當前平台的分隔符。如果你要處理的是**固定平台**的路徑字串
（例如解析 Linux 產生的 log），改用 `path/posix/*` 或 `path/win32/*` 明確指定。

## 一個實際的小工具

把某個目錄下所有 `.md` 的行數加總——這段涵蓋了上面全部：

```janet
(import spork/path)

(defn count-lines [p]
  (with [f (file/open p :rb)]
    (var n 0)
    (while (file/read f :line) (++ n))
    n))

(defn main [& _]
  (var total 0)
  (each name (os/dir "docs")
    (when (= ".md" (path/ext name))
      (def n (count-lines (path/join "docs" name)))
      (printf "%-32s %4d" name n)
      (+= total n)))
  (printf "%-32s %4d" "TOTAL" total))
```

[`snippets/list-dir.janet`](../snippets/list-dir.janet)。
