# 26b · 隨機數配方

[← 26 隨機數](26-隨機數.md) 講的是「哪一套、為什麼」；這篇是**照抄就能用的四段**：
擲骰、抽一個、洗牌、隨機 ID。每段都實測過，餵固定種子所以輸出可對照。

### 擲骰子 / 抽一個

```janet
(defn 擲骰 [rng] (inc (math/rng-int rng 6)))
(defn 抽一個 [rng xs] (xs (math/rng-int rng (length xs))))
(抽一個 (math/rng 2026) [:剪刀 :石頭 :布])   # => :布
```

### 洗牌：spork 已經有現成的

**先講結論：不用自己寫。**`spork/misc` 有一支 `randomize-array`，就是 Fisher-Yates：

```janet
(import spork/misc)
(misc/randomize-array @[1 2 3 4 5])                 # 原地洗，回傳同一個陣列
(misc/randomize-array (array ;(range 10)) (math/rng 2026))  # 給 rng => 可重現
```

⚠ 值得注意的是它**不給 rng 時的預設是 `(math/rng (os/cryptorand 8))`**——
所以它跨行程真的每次都不一樣，**跟裸的 `math/random` 相反**（見 [26 那個坑](26-隨機數.md)）。

下面自己寫的版本留著是為了**看懂它在做什麼**（面試也常考），實務上用上面那行就好：

```janet
(defn shuffle! [arr rng]
  (for i 0 (dec (length arr))
    (def j (+ i (math/rng-int rng (- (length arr) i))))   # 從 i..結尾 挑一個
    (def tmp (arr i))
    (put arr i (arr j))
    (put arr j tmp))
  arr)

(shuffle! (array ;(range 10)) (math/rng 2026))   # => @[8 1 3 0 2 5 6 9 7 4]
```

⚠ **不要用 `(sort-by (fn [_] (math/random)) xs)` 洗牌。**看起來很聰明，但結果
**不是均勻分布**的（比較函式前後不一致，排序演算法的行為未定義），而且會慢很多。
Fisher-Yates 是十行內寫得完的正確解，抄上面那段就好。

### 隨機字串 / ID

```janet
(defn hex-id [rng n]
  (string/join (map |(string/format "%02x" $) (math/rng-buffer rng n)) ""))

(hex-id (math/rng 7) 6)   # => "5ff51a03d668"
```

⚠ 這樣做出來的 ID **可以拿來當檔名、當測試資料，不能拿來當 session token**。原因見下。


（最後那句「原因見下」指的是 [26 的「要安全的亂數：os/cryptorand」那節](26-隨機數.md)：
PRNG 產的 ID 只要種子被猜到就全被算出來，所以不能當 session token。）

**可跑範例**：`janet examples/random-demo.janet`——洗牌均勻性的實測驗證、
`os/cryptorand`，以及 ⚠「預設每次跑都一樣」那個坑。
（上面四段配方本身也重跑驗證過，輸出與文件所載逐字相符。）
