# 45 · 從 Go 過來：逐條對照

[01b](01b-給-C++-開發者.md) 是給 C++ 的概念表；這篇是給 **Go 使用者**的。Go 跟 Janet 都是「小語言、少概念」，
所以最需要對照的不是語法，是**慣例**：錯誤怎麼傳、slice 是不是共用、goroutine 對到什麼。分兩支：

- **本篇**：變數、錯誤與 `err` 慣例、`defer`、slice、map、struct 與 method、interface、`fmt` 動詞、`for range`、`main`
- [45b](45b-從-Go-goroutine-與-channel.md)：goroutine、channel、`select`、`context`、真執行緒、`go build`

`return`／`break`／labeled break 的對照在 [01d](01d-提早離開-return-break-continue.md)。

## 變數

| Go | Janet | 說明 |
|----|-------|------|
| `x := 1`／`const x = 1` | `(def x 1)` | 不可重新指派 |
| `var x int; x = 2` | `(var x nil) (set x 2)` | 要改就得 `var` |
| 零值 `0`／`""`／`nil` | 一律 `nil` | ⚠ 沒宣告值就是 `nil`，`(or x 0)` 補預設 |
| `x++` | `(++ x)` | 對 `def` 用會編譯錯 `cannot set constant` |
| `_ = f()` | `(def [_ b] (f))` | `_` 在解構裡一樣能用 |
| 未使用變數是編譯錯 | 不是錯 | 少一個煩惱 |

## 多重回傳與 err 慣例

Go 的 `val, err := f()` 在 Janet 有三種寫法，按嚴重程度挑（[20](20-錯誤處理與資源管理.md) 講怎麼選）：

```janet
# ① 照 Go 的樣子回 [值 錯誤]，用解構接
(defn parse-int [s] (if-let [n (scan-number s)] [n nil] [nil (string "not a number: " s)]))
(parse-int "12")               # => (12 nil)
(def [n err] (parse-int "x"))
err                        # => "not a number: x"
# ② 拿不到就回 nil（Go 裡常被罵、Janet 裡是慣例）
(scan-number "x")          # => nil
# ③ 真的錯就 error，呼叫端 protect：形狀就是 (ok? 值)
(protect (error "boom"))   # => (false "boom")
(protect 42)               # => (true 42)
```

`panic`／`recover` 對到 `error`／`try`。`errors.Is`／`errors.As` 對到「丟 table、`match` 它」；
error wrapping 就是多包一層 table：

```janet
(try (error {:code 404 :msg "no"}) ([e] (match e {:code 404} :not-found _ :other)))   # => :not-found
(try (try (error "底層") ([e] (error {:msg "outer" :cause e})))
     ([e] (e :msg)))                                                                 # => "outer"
```

## defer：有，但參數順序相反

Go 是「先寫 body、`defer` 在中間」；Janet 是「收尾寫第一格、body 在後面」（[20b](20b-資源管理.md)）：

```janet
(def log @[])
(defer (array/push log :第三)
  (defer (array/push log :第二)
    (array/push log :第一)))
log   # => @[:第一 :第二 :第三]     巢狀就是 LIFO，跟 Go 多個 defer 一樣
```

`defer f.Close()` 這種最常見的用法直接用 `with`：`(with [f (file/open …)] …)`。

## slice：`array/slice` 是拷貝，不是 view

⚠ Go 的 `s[1:3]` 跟原陣列**共用**記憶體；Janet 的 `array/slice` 是**新的一份**：

```janet
(def a @[1 2 3 4])
(def s (array/slice a 1 3))
(put s 0 :改)
[a s]                      # => (@[1 2 3 4] @[:改 3])   a 沒動
(def b a) (array/push b 5)
a                          # => @[1 2 3 4 5]           要共用就直接多一個名字
```

| Go | Janet |
|----|-------|
| `append(s, x)` | `(array/push s x)`，原地改，不用接回傳值 |
| `append(s, t...)` | `(array/concat s t)` |
| `make([]int, 3)` | `(array/new-filled 3 0)`；⚠ `(array/new 3)` 是預留容量，`len` 是 0 |
| `len(s)` | `(length s)`；沒有 `cap` |
| `copy(dst, src)` | `(array/slice src)` 直接拿一份新的 |

## map

```janet
(def m @{:a 1})
(get m :b)          # => nil     Go 給零值，這裡給 nil
(get m :b 0)        # => 0       要零值自己給第三個參數
(has-key? m :b)     # => false   v, ok := m[k] 的 ok
(put m :a nil)      # 就是 delete(m, k)
(length m)          # => 0
```

走訪順序兩邊都不保證。`(keys m)`／`(values m)`／`(pairs m)` 拿整份。

## struct ＋ method → table ＋ prototype；interface → 鴨子型別

```janet
(def Dog @{:speak (fn [self] (string (self :name) ": woof"))})
(defn new-dog [n] (table/setproto @{:name n} Dog))
(:speak (new-dog "rex"))          # => "rex: woof"   呼叫方法，等於 Go 的 d.Speak()
(def Cat @{:speak (fn [self] "meow")})
(map |(:speak $) [(new-dog "a") (table/setproto @{} Cat)])   # => @["a: woof" "meow"]
(:speak @{:name "x"})             # 錯：unknown method :speak invoked on <table …>
```

Go 的 interface 是「有這些方法就算」；Janet 連宣告都不用，有 `:speak` 就能叫，沒有就在呼叫時報錯。
embedding 對到「prototype 再掛 prototype」（[22](22-原型與方法.md)）。

## fmt 動詞

| Go | Janet | 備註 |
|----|-------|------|
| `%d` `%s` `%f` `%.2f` `%x` `%5s` `%-5s` | 同名 | |
| `%v` | `%j`（可讀回）或 `%p`（含 `@`） | ⚠ Janet 的 `%v` 等於 `string`，table 印成 `<table 0x…>` |
| `%q` | `%q` | 加引號 |
| `%t`（bool） | `%j` | ⚠ **Janet 的 `%t` 印型別名**，`(string/format "%t" true)` → `"boolean"`，是 Go 的 `%T` |
| `Println` | `print`／`pp` | `pp` 才會把 table 印成看得懂的 |

## for range

```janet
(def r @[])
(eachp [i v] [:a :b] (array/push r [i v]))   # for i, v := range xs
(each v [:c] (array/push r v))               # for _, v := range xs
(for i 0 2 (array/push r i))                 # for i := range 2   (Go 1.22)
r                                            # => @[(0 :a) (1 :b) :c 0 1]
(def bs @[]) (each c "hé" (array/push bs c))
bs                                           # => @[104 195 169]
```

⚠ Go `range` 字串走的是 rune；Janet 走的是 **byte**（`é` 變兩個數字）。UTF-8 見 [18](18-字串與-buffer.md)。
`for cond {}` 是 `while`，`for {}` 是 `forever`，`switch` 是 `case`／`cond`，
type switch 是 `(case (type x) :number … :string …)`。

## init()／main()／os.Args

頂層程式碼就是 `init()`：由上往下跑。`main` 是 `(defn main [& args] …)`，跑完整支檔案後**自動被叫**
（[05b](05b-建立新專案.md)），`args` 第 0 格是檔名。`os.Args` 隨時用 `(dyn *args*)` 拿；
`os.Exit(n)` 是 `(os/exit n)`。`strings.Builder` 是 buffer `@""`，`[]byte(s)` 是 `(buffer s)`，
`strconv.Atoi` 是 `(scan-number s)`（失敗 `nil`，不回 err）。
