## switch → case／match

`switch` 比常值用 `case`；要拆結構用 `match`（[32](32-條件與模式比對.md)）。**沒有 fallthrough**，
一個分支只有一格；「多個 case 共用一段」寫成 `cond` 加 `or`。

```janet
(defn f [x] (case x 1 :one 2 :two :other))     # 最後一格沒配對 = default
(map f [1 2 9])                                # => @[:one :two :other]
(defn g [x] (cond (or (= x 1) (= x 2)) :小 :大))   # case 1: case 2: 共用
(map g [1 5])                                  # => @[:小 :大]
```

⚠ 沒有 default 又沒中時回 `nil`，不報錯。`case` 用 `=` 比，對 array／table 永遠不中（比身分）。

## 三段式 for → for／loop :range／forv

| C | Janet | 實測 |
|---|-------|------|
| `for (i=0; i<5; i++)` | `(for i 0 5 …)` | 半開區間 `[0,5)` |
| `for (i=0; i<10; i+=3)` | `(loop [i :range [0 10 3]] …)` | 步長是第三格 |
| `for (i=5; i>0; i--)` | `(loop [i :down [5 0]] …)` | ⚠ `:range` 給負步長會**靜默回空**（[32b](32b-loop-全表.md)） |
| body 裡改 `i` | `(forv i 0 10 … (+= i 2))` | `for` 的 `i` 是 `def`，改不了；`forv` 才是 `var` |
| 完全自由的三段 | `(var i 0) (while (< i n) … (++ i))` | 跟 C 一模一樣 |

```janet
(seq [i :range [0 10 3]] i)   # => @[0 3 6 9]
(seq [i :down [5 0 2]] i)     # => @[5 3 1]
(def r @[])
(forv i 0 10 (array/push r i) (+= i 2))
r                             # => @[0 3 6 9]
```

## do-while：先跑一次再判斷

Janet 沒有 `do { } while (c)`。寫成無限迴圈＋尾端判斷：

```janet
(var i 10)
(def r @[])
(while true (array/push r i) (++ i) (unless (< i 3) (break)))
r   # => @[10]
```

body 至少跑一次（`i` 從 10 開始，條件一開始就是假）。

## 三元運算子 → if

`c ? a : b` 就是 `(if c a b)`——`if` 本來就是運算式，有回傳值。
「沒值就用預設」的 `x ? x : d` 可以寫 `(or x d)`，但：

```janet
(def x 5)
(if (> x 3) :大 :小)   # => :大
(or nil :預設)          # => :預設
(or 0 :預設)            # => 0      ⚠ 0 是真值，跟 C 相反；只有 nil 與 false 是假
```

## 位元運算：32 位元，名字不是符號

| C | Janet | 實測 |
|---|-------|------|
| `a & b` | `(band a b)` | `(band 6 3)` → `2` |
| `a \| b` | `(bor a b)` | `(bor 6 3)` → `7` |
| `a ^ b` | `(bxor a b)` | `(bxor 6 3)` → `5` |
| `~a` | `(bnot a)` | `(bnot 0)` → `-1` |
| `a << n` | `(blshift a n)` | `(blshift 1 4)` → `16` |
| `a >> n`（算術） | `(brshift a n)` | `(brshift -16 2)` → `-4` |
| `(unsigned)a >> n` | `(brushift a n)` | ⚠ 給負數會報錯，見下 |
| `0xFF` | `0xFF` | 十六進位字面值一樣 |
| `printf("%x")` | `(string/format "%x" 255)` | `"ff"` |

```janet
(brushift 0xFFFFFFF0 2)   # => 1073741820
(brushift -16 2)          # 錯：value -16 out of range for 32-bit unsigned integers
(blshift 1 33)            # => 2     ⚠ 位移量 mod 32，不是 0 也不報錯
```

運算元是 **32 位元**的（[21](21-數字與位元.md)），`1 << 40` 在這裡是 `256`。
要 64 位元把運算元換成 `int/u64`，同一批函式就變 64 位元。沒有八進位字面值（`0644` 是十進位 644）。

## enum → keyword

```janet
(def 顏色 [:red :green :blue])       # enum { RED, GREEN, BLUE }
(index-of :green 顏色)               # => 1      要整數值就查表
(get 顏色 1)                          # => :green
(= :red :red)                         # => true   keyword 比較是 O(1)，跟比整數一樣快
```

keyword 不是字串：`(= :a "a")` 是 `false`（[13](13-symbol-keyword-字串.md)）。

## typedef struct → 一個建構函式

C 的 `typedef struct { int x, y; } Point;` 加上 `Point make_point(int x, int y)`，
在 Janet 只剩後半：

```janet
(defn point [x y] {:x x :y y})
(def p (point 1 2))
[(p :x) (get p :y)]   # => (1 2)
```

要「型別名」就在資料裡放一個 tag：`{:type :point :x 1 :y 2}`，`match` 拿它分派。
要方法就掛 prototype（[22](22-原型與方法.md)）。

## 函式指標與 callback → 函式就是值

C 要寫 `int (*f)(int)`；Janet 的函式本來就是一等公民，直接傳：

```janet
(defn twice [f x] (f (f x)))
(twice inc 3)                # => 5
(map |(* 2 $) [1 2])         # => @[2 4]     `|(...)` 是短 lambda，$ 是參數
(= (fn []) (fn []))          # => false      函式比身分，跟比函式指標一樣
```

`qsort` 的比較函式對到 `(sort arr <)`／`(sort-by f arr)`（[36](36-排序與比較.md)）。
