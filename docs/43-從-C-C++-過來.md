# 43 · 從 C／C++ 過來：日常語法逐條對照

[01b](01b-給-C++-開發者.md) 給的是概念對照表與五個誤會。這篇是**逐條的日常語法**：
你在 C 裡會這樣寫，Janet 對應的是這個，後面接實測輸出。分三支：

- **本篇**：變數與作用域、整數與浮點、字串、陣列與 struct、指標

- [43c](43c-從-C-函式模組與-IO.md)：可變參數、預設參數、static、模組、main 與 argv、exit code、stdin／stdout／stderr、assert、sizeof

## 變數與作用域

| C | Janet | 說明 |
|---|-------|------|
| `const int x = 1;` | `(def x 1)` | 預設不可重新指派 |
| `int y = 1; y = 2;` | `(var y 1) (set y 2)` | 要改就得宣告成 `var` |
| `{ int t = 1; … }` | `(let [t 1] …)` | 區塊作用域，離開就沒了 |
| 同名遮蔽 | `(let [x 1] (let [x 2] x))` | 內層蓋外層，跟 C 一樣 |

⚠ 兩個都是**編譯錯**，不是執行期才炸：

```janet
(do (def x 1)) x        # compile error: unknown symbol x   （do 也是一個作用域）
(def y 1) (set y 2)     # compile error: cannot set constant
```

## 整數與浮點：全部是 double

C 分 `int`／`long`／`float`／`double`；Janet 只有一種 `:number`，就是 IEEE 754 double。
後果與 64 位元整數的做法見 [21](21-數字與位元.md)，這裡只列日常會撞到的：

```janet
(/ 7 2)      # => 3.5    C 的 7/2 是 3；Janet 的 / 永遠是浮點除
(div 7 2)    # => 3      要 C 的整數除法用 div
(% -7 2)     # => -1     跟 C 一樣，餘數跟被除數同號
(mod -7 2)   # => 1      數學上的 mod，跟 C 不一樣
(= 3 3.0)    # => true   沒有 int 與 double 之分
(+ 9007199254740992 1)                       # => 9007199254740992   ⚠ 2^53 之後加一沒反應
(string (+ (int/s64 9007199254740992) 1))    # => "9007199254740993"  要真的 64 位元用 int/s64
```

⚠ `printf("%d", 3.5)` 在 C 是 UB；Janet 的 `%d` 遇到非整數直接報錯：
`can not convert number 3.5 to 64 bit signed integer`。

## 字串：不可變的 string，可變的 buffer

C 的 `char[]` 一個型別兩種用法；Janet 拆成兩個：`"…"` 是不可變 string，`@"…"` 是可變 buffer
（像 `std::string`）。完整說明在 [18](18-字串與-buffer.md)。

| C | Janet | 實測 |
|---|-------|------|
| `printf("%3d\|%-3d\|%05.1f\|%x\|%s", …)` | `string/format` 動詞幾乎同名 | 見下 |
| `strcat`／`sprintf` 串接 | `(string a b …)`，什麼型別都吃 | `(string "a" 1 :k 2.5)` → `"a1k2.5"` |
| `strcpy` 進可變緩衝 | `(buffer/push buf "…")` | 原地改 |
| `strlen(s)` | `(length s)` | **byte 數**，`(length "中")` 是 3 |
| `s[0]` | `(get s 0)` | 拿到 byte 數字 `97`，不是字元 |
| `strncpy`／取子字串 | `(string/slice s 起 迄)` | 半開區間，負數從尾算 |

```janet
(string/format "%3d|%-3d|%05.1f|%x|%s" 42 42 3.14159 255 "hi")   # => " 42|42 |003.1|ff|hi"
(string "a" 1 :k 2.5)          # => "a1k2.5"
(buffer/push @"ab" "cd")       # => @"abcd"
(length "中")                   # => 3
(get "abc" 0)                  # => 97
(string/slice "hello" 1 3)     # => "el"
(string/slice "hello" -3)      # => "lo"
(put "abc" 0 65)               # 錯：expected array, table or buffer, got "abc"
```

沒有 `'a'` 字元字面值：`(chr "A")` → `65`，反過來 `(string/from-bytes 65)` → `"A"`。

## 陣列與 struct

| C | Janet | 說明 |
|---|-------|------|
| `int a[3] = {1,2,3};` | `@[1 2 3]` array | 可變、可長大 |
| `const int a[] = {…}` | `[1 2 3]` tuple | 不可變 |
| `int a[5] = {0};` | `(array/new-filled 5 0)` | ⚠ `(array/new 5)` 是**預留容量**，長度 0 |
| `struct { int x, y; } p;` | `@{:x 1 :y 2}` table | 可變，`(put p :x 9)` |
| 純資料、不改 | `{:x 1 :y 2}` struct | 不可變 |
| `p.x` | `(get p :x)` 或 `(p :x)` | ⚠ `(:x p)` 是**呼叫方法**，不是取值（[02b](02b-方法與-prototype.md)） |
| `a[5]` 越界 | `(get a 5)` → `nil` | 不會 segfault |

```janet
(get @[1 2 3] 5)            # => nil
(in @[1 2 3] 5)             # 錯：expected integer key for array in range [0, 3), got 5
(length (array/new 5))      # => 0
(array/new-filled 3 0)      # => @[0 0 0]
(def p {:x 1 :y 2})
[(get p :x) (p :y)]         # => (1 2)
(put {:x 1} :x 2)           # 錯：expected array, table or buffer, got <struct …>
```

`get` 拿不到給 `nil`，`in` 拿不到報錯。要「有預設值」寫 `(get p :z 0)`。

## 指標與參考：沒有指標，傳的本來就是參考

Janet 沒有 `&`、`*`、`->`。傳 table／array 給函式，函式改它，呼叫端看得到，等於 C 傳指標：

```janet
(defn bump! [t] (put t :n (inc (get t :n))))
(def counter @{:n 0})
(bump! counter)
counter                     # => @{:n 1}
```

數字、字串、tuple、struct 是不可變的，改不了，所以「傳值還是傳參考」的問題對它們不存在。
要一份獨立的拷貝：`(array/slice a)`、`(table/clone t)`，深拷貝見 [35](35-拷貝與凍結.md)。

`NULL` 對到 `nil`。`(put nil :a 1)` 會報錯 `expected array, table or buffer, got nil`，不是 segfault。
