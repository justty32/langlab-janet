# 拆檔與限制

[← 回 llm-http README](../README.md)

## 拆檔

一個檔一個職責；`init.janet` 與另外兩支只做 re-export。

| 檔案 | 管什麼 |
|------|--------|
| `init.janet` | **門面**，把下面全部 re-export 出來 |
| `endpoints.janet` | endpoint 那一塊的門面（＋**觸發設定檔自動載入**這個唯一的副作用） |
| ├ `defaults.janet` | 預設位址／金鑰、`chat-url` 怎麼組（唯一讀 `LITELLM_*` 的地方） |
| ├ `builtin.janet` | 內建四筆 endpoint 的**純資料**，沒有任何行為 |
| ├ `spec.janet` | 一份設定**合不合法**：`normalize-spec`（純函式驗證，錯誤訊息只有這一種寫法） |
| ├ `registry.janet` | **表裡有誰**：`define-endpoint`／`undefine-endpoint!`／`reset-endpoints!`／查來源 |
| ├ `resolve.janet` | **組成可以打的 cfg**：`endpoint`／`env-ready?`（`:url` 與金鑰的決定順序在這） |
| └ `config.janet` | **設定檔 IO**：`load-endpoints!`／`autoload-endpoints!`（只 parse 不 eval） |
| `client.janet` | HTTP 那一塊的門面 |
| ├ `transport.janet` | HTTP／JSON 收送（`post-chat`／`headers-for`），不認識 messages |
| └ `chat.janet` | **對話語意**：`build-payload`／`chat`／`ask`／取答案／參數合併 |
| `media.janet` | 圖像輸入：圖檔 → base64 data URI → content parts |
| `tools.janet` | 多輪 tool loop（`tool-spec`／`with-tools`／內建示範工具） |
| `cli.janet` | CLI 的**門面＋主流程**（`run`） |
| ├ `cli-flags.janet` | usage 文字與旗標定義、`parse-args` |
| ├ `cli-args.janet` | 命令列字串 → Janet 值：`parse-kv`／`param-table`／`resolve-endpoint`（**純函式，離線可測**） |
| └ `cli-list.janet` | `--list` 那一大段輸出（回字串，不 print） |
| `main.janet` | CLI 進入點，只有一句 `(cli/run args)` |
| `endpoints.example.janet` | 設定檔範本（含中文註解），複製去改 |
| `lite.yaml` | litellm proxy 的設定檔 |

只想要某一層也可以直接 import 個別檔案，例如 `(import ../modules/llm-http/tools)`。
`endpoints.janet` 與 `client.janet` 純粹是相容門面——舊寫法 `(import ./endpoints :as ep)`
之後照舊。

## 沒做的事

- **串流（`stream: true`）不支援**。SSE 要逐行解析 `data: {...}`，spork/http 的 client 是
  「讀完整份 response 再回」的形狀，對 SSE 支援有限。需要串流請另外想辦法。
- **音訊、圖像生成、modalities 不做**（用不到，見 FINDINGS.md 第一節）。
- **`https://` 打不通**：spork/http 沒有 TLS。要打外部服務請讓 litellm proxy 代打。

## 幾個實測踩過的點

- `(res :body)` 是 **buffer**，丟給 `json/decode` 前要先 `(string …)` 包一層。
- `json/decode` 第二個參數給 `true`，key 才會變 keyword（否則 `get-in` 全部落空）。
- `:function :arguments` 是一段 **JSON 字串**，要再 `json/decode` 一次才是參數 table。
- 有 `tool_calls` 時要把**整則 assistant message 原樣接回 messages**，只留 content 會讓後面的
  `role:"tool"` 找不到錨點。
- `spork/json` 會把非 ASCII **逃逸成 `\uXXXX`**（合法 JSON，對端解得開，但自己 debug 時別嚇到）。
- ⚠ **HTTP header 的值只能是 ASCII**：`:headers` 放中文會被伺服器擋成 400（實測 spork/http 的
  server 就是這樣）。要帶中文請放進 body。
- ⚠ 連本機**一律寫 `127.0.0.1`**，不要寫 `localhost`（`::1` 陷阱，見 FINDINGS.md 第五節）。
