# 當函式庫用

[← 回 pi-shell README](../README.md)


**怎麼 import（路徑規則、`:as`、裝起來用裸名字）→ 見 [`../README.md`](../../README.md#怎麼-import-這些模組)。**
下面假設你的檔案在根目錄下一層（`test/`、`bin/` 那種）：

```janet
(import ../modules/pi-shell/init :as agent)

# 核心：跑任何「<cmd> -p <args...>」形狀的 agent CLI
(agent/run-agent "pi" ["--no-tools" "回 ok"])       # → @{:out "ok\n" :code 0}
(agent/agent-argv "pi" ["--no-tools"])              # → @["pi" "-p" "--no-tools"]（不執行，好 debug）

# 兩個便利包裝
(agent/run-pi ["--no-tools" "用一句話總結"] "要總結的長文…")
(agent/run-claude ["--disallowedTools" "Bash,Edit,Write" "回 ok"]
                  nil                               # stdin，可省略
                  "claude-haiku-4-5-20251001")      # model，可省略

# claude 的 JSON 信封版：順便拿到花了多少錢
(def r (agent/run-claude-json ["--disallowedTools" "Bash,Edit,Write" "回 ok"]))
(r :ok)                                             # 成功?（exit 0 且 is_error 為假）
(r :text)                                           # 答案本文
(get-in r [:envelope :total_cost_usd])              # 這次花了多少

# 探測（只問 --version，不請它做事）
(agent/pi-available?) (agent/claude-available?) (agent/agent-available? "qwen-cli")

# 更底層：跑任何指令，不墊 -p
(agent/run ["cat"] "餵進去的內容")                    # → @{:out "餵進去的內容" :code 0}
```

⚠ **`import` 這個模組的副作用**：會自動探測一次你的 agent 設定檔（見上面 ③）。
沒有設定檔是正常狀態，不會有任何輸出。

### 公開 API 一覽

| 分類 | 函式／值 |
|------|----------|
| 子行程管線 | `run` `drain` `feed-file` `available?` |
| agent registry | `agent-specs`（活的）`builtin-agents`（不可變）`define-agent` `undefine-agent!` `reset-agents!` `agent-names` `agent-spec` `agent-source` `builtin-agent?` `normalize-spec` `spec-keys` `pi-cmd` `claude-cmd` `default-claude-model` `claude-models` |
| 設定檔 | `load-agents!` `autoload-agents!` `config-candidates` `parse-agents` `loaded-files` |
| 跑 agent | `agent-argv` `run-agent` `run-pi` `run-claude` `run-claude-json` `agent-available?` `pi-available?` `claude-available?` |

**相容性**：舊有的公開 API 全部照舊，簽名與行為都沒變——`run-agent`、`run-pi`、`run-claude`、
`run-claude-json`、`pi-available?`、`claude-available?`、`run`、`drain`、`feed-file`、
`available?`、`pi-cmd`、`claude-cmd`、`default-claude-model`、`claude-models`。
`run-agent` 多了一個可省略的第四參數 `model`，不影響既有呼叫。

## 拆檔

| 檔案 | 管什麼 |
|------|--------|
| `proc.janet` | 子行程管線（`os/spawn`／`drain`／`run`／`available?`），**不認識任何 agent** |
| `spec.janet` | 一份 agent 設定**合不合法**：`normalize-spec`（純函式驗證，欄位說明也在這） |
| `agents.janet` | agent registry：內建 pi／claude 的旗標形狀 ＋ `define-agent` ＋ 驗證 |
| `config.janet` | agent 設定檔載入（`load-agents!`／`autoload-agents!`，只 parse 不 eval） |
| `run.janet` | 把 registry 組成指令交給 proc：`agent-argv`／`run-agent`／`run-pi`／`run-claude` |
| `cli.janet` | CLI 的旗標消化規則（`take-flags`／`list-text`，**純函式，離線可測**） |
| `init.janet` | **門面**，把上面 re-export 出來（＋**觸發設定檔自動載入**這個唯一的副作用） |
| `main.janet` | CLI 進入點 |
| `agents.example.janet` | 設定檔範本（含中文註解），複製去改 |
